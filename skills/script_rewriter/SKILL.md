# 剧本改写指南

> **分工**：输出格式（场景头 / 动作 / 对白 / 旁白）、输出硬性要求、说话人划分铁律
> 由系统提示词给出，单一来源是 `backend/src/shared/prompt-blocks.ts` 的 `SCREENPLAY_FORMAT_RULES`。
> **本文件不重复它们**，只补系统提示词不覆盖的**创作层面判断**。

## 改写原则

1. **保留核心情节**：不改变主线故事和角色关系
2. **增强画面感**：把叙述性文字转化为可视化的场景描写
3. **对话驱动**：用对白推动情节，减少旁白
4. **节奏把控**：每场戏 30-60 秒，适合短视频
5. **不写镜头语言**：景别 / 角度 / 运镜属于分镜拆解步骤，剧本正文里不出现

## 叙述文本的处理

| 原文形态 | 处理方式 |
|---|---|
| 心理描写 | 转化为角色表情 / 动作，或写成画外音 |
| 长段叙述 | 按情绪转折拆成多个短场景 |
| 概括性交代（如「三年后」） | 转成场景头的时间标记，或一句动作描写 |
| 作者视角议论 / 评论 | 删除（破坏剧本体裁） |
| 环境 / 外貌铺陈 | 压缩成 1-2 句动作描写，细节留给分镜与美术 |

## 场景切分

- 每个场景要有明确的情绪转折点；没有转折的段落应合并，不要为分段而分段
- 场景编号连续递增（S01、S02、S03…），不跳号
- 时间段尽量具体（黄昏 / 深夜 / 清晨）；笼统时段（白天 / 夜晚）可接受

## 内容量参考

格式化剧本比原文增加约 20-30%，增量来自场景头与对白分行，**不是扩写**。
若增量明显超过 30%，说明在替作者加戏 —— 停手，回到原文。

## 注意事项

- 保持每个角色的语言风格一致（口头禅、称呼、语气）
- 不新增原文没有的角色、场景、情节
- 工具调用顺序以系统提示词的工作流程为准
