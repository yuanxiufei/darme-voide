# 音色分配指南

## 分配原则

1. **性别匹配**：男性角色用男声，女性角色用女声
2. **年龄匹配**：少年/青年/中年/老年对应不同音色
3. **性格匹配**：
   - 活泼开朗 → 明亮有活力的音色
   - 沉稳内敛 → 低沉稳重的音色
   - 温柔体贴 → 柔和甜美的音色
   - 威严霸气 → 浑厚有力的音色
4. **角色定位**：主角用辨识度高的音色，配角用中性音色

## 硬规则（最高优先级，违反即返工）

1. **一角色一音色**：每个角色只能有一个音色，**禁止两个角色共用同一个 voice_id**。系统会强制校验，共用会被拒绝。
2. **跨集锁定**：`get_characters` 返回 `current_voice` 非「未分配」的角色，**音色已经确定，不要再改**，直接跳过（或仅补 `speaker_id`）。
3. **speaker_id 全局唯一**：给每个角色分配一个全局说话人编号（按出场/重要性排序 `S1`/`S2`/`S3`…），**一人一号、跨集不变**。已有 `speaker_id` 的角色不要改号。
4. **编号与音色一起锁**：`speaker_id` 和 `voice_id` 在 `assign_voice` 里一次性绑定，保证后续分镜的「谁在说话」和「谁的声音」严格对应。

## 说话人编号（speaker_id）分配

- 主角 = `S1`，其余按戏份重要性依次 `S2`/`S3`…
- 已分配过（`get_characters` 里 speaker_id 非空）的角色，沿用原号。
- 编号贯穿全剧所有集，同一角色永远同一个 speaker_id。

## 音色角色类型标签（role_tag）

- 每个音色带 `role_tags`（旁白 / 主角 / 反派 / 配角），由 AI 打标并持久化到音色库（无标签时前端回退正则推断）。
- `list_voices` 支持传 `role_tag` 按角色类型筛选，例如为反派角色找音色时可传 `role_tag: '反派'`。
- 匹配时优先参考 `role_tags` 判断音色适合的角色类型，再结合性别、性格做最终选择。

## 使用步骤

1. 调用 `list_voices` 查看可用音色列表
2. 调用 `get_characters` 获取所有角色信息
3. 分析每个角色的性格、年龄、性别等特征
4. 为每个角色调用 `assign_voice` 分配合适的音色，**同时传入 `speaker_id`**（S1/S2/...）
5. 已锁定音色的角色跳过重分配，只在其缺 speaker_id 时补传
6. 汇总分配结果给用户
