# 分镜拆解指南

> **分工**：字段清单与取值（含 `scene_type` 路由表）、视频提示词格式与标签、
> `speaker_id` / `scene_id` / `character_ids` 的绑定铁律，均由系统提示词给出。
> **本文件不重复它们**，只写需要判断力的**操作细则与质量下限**。

## 一镜一人说的操作细则

铁律本身（一个镜头只允许一个说话人）见系统提示词，以下是落地时的具体做法：

- **双人对白** → 拆成正反打：A 说一句是一个镜头，B 说一句是下一个镜头，交替切
- **多人会议 / 群戏** → 每一句台词单独成镜，谁说话镜头就给谁；可切旁人反应镜，但反应镜**无人说话**
- **长对白**（连续 4 句以上）→ 按 5-8 秒切片，不要让一个角色在 10-15 秒里说一长串
- **旁白 / 画外音** → 用 `<voice>角色名</voice>` 标记，且旁白镜头里**不再出现另一个角色说话**

## 时长取舍

- 动作 / 空镜 / 纯环境：10-15 秒
- 含对话镜头：5-8 秒，只装 1-2 句台词 —— 宁可多切几个镜头，也不要让台词被剪断

## 拆解粒度

每个镜头聚焦**单一动作**，描述要详尽具体：

- 一个镜头里主角完成了两件独立的事 → 拆成两个镜头
- 动作有明确的起止过程（起身→走到窗边→推开窗）→ 可按「起点 / 中间态 / 终点」拆，分别对应首帧、关键帧、尾帧
- 纯环境镜头也要有信息量（交代空间、时间推进、情绪留白），不能只是"空镜一秒"

## 质量下限

- `description` 要适合人读，`video_prompt` 要适合模型生成，**二者不要互相替代**
- `image_prompt` 突出单帧构图、角色外观、环境与光线
- `video_prompt` 突出时间推进、动作变化、镜头语言
- `bgm_prompt` / `sound_effect` 用简洁短语，但不能空泛到只有「紧张」「悲伤」这种无指向的词
- 有旁白时统一写入 `dialogue`，格式为 `旁白：内容`

## 自检清单（保存前过一遍）

1. 每个镜头是否只有一个说话人？
2. 含对话的镜头是否都在 5-8 秒内、只装 1-2 句台词？
3. 每个镜头的 `start_state` 是否等于上一镜的 `end_state`（同实体状态不跳变）？
4. 首帧与尾帧描述是否有**明确差异**（否则视频会没有动势）？
5. `scene_type` 是否与镜头实际内容一致（决定参考图策略，填错会导致人物不一致）？
