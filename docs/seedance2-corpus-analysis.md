## 2. 结构特征实测（重要：与现有 skill §6 有分歧）

| 结构特征 | 命中数 | 占比 |
|---|---|---|
| 文内出现 `X-Y秒` 时间码 | 1249 | **14%** |
| 以 `X-Y秒：` 作为**分段标题** | 285 | **3%** |
| 出现「镜头N / 分镜N」 | 906 | 10% |
| 出现「图N / Image N」图片引用 | 900 | 10% |
| 使用 `⏱️` 标记 | 23 | 0% |
| 使用 `【】` 段落标题 | 629 | 7% |
| 使用 `Chapter N` | 0 | 0% |

### 关键结论

**「时间码段落化」在这个语料里不是主流写法（仅 14%）。**

主流是**散文式多段结构** —— 见下方 §4 的十段骨架：

```
① 身份锚定段   ② 画面类型 + 场景   ③ 摄影美学   ④ 主体外形/服装
⑤ 动作姿态     ⑥ 镜头器材         ⑦ 环境光线   ⑧ 情绪《Mood》
⑨ 构图          ⑩ 负面提示
```

**为什么与现有 skill §6 不冲突**：§6 的素材来源是 **PromptMart 的国内短剧/漫剧作者**，
那批人确实以时间码分段为主；本语料是**平台通用短视频**（含纪实、广告、内容创作），
以散文式为主。**这是两个不同创作人群的写法，不是谁对谁错。**

→ 结论：skill 应**同时覆盖两类**，并给出**场景适配规则**（见 §5）。
**已落地**：skill §6 现为 `6.0 选写法速查 → 6.1–6.9 时间码向（6.3/6.4/6.5/6.6/6.7/6.9 两类共用）
→ 6.10 散文式十段`。

### 3.3 三个值得注意的「反向发现」

1. **「一镜到底」并非主流**（323 次 / 8755 条）。
   原 skill §6.1 把「单镜头：一镜到底，无剪辑」写成固定骨架，**与数据不符**。
   真正高频的是 **旋转 / 手持 / 环绕 / 推进 / 定格 / 跟随** 这套「可动的机位词」。
   → **已修正**：skill §6.1 改为可选项，默认「稳定机位 + 呼吸感手持」。
2. **「杜绝美化」「百分百还原」在语料中极罕见**（各 2 次）。
   高频的是 **「一致 / 身份 / 全程保持 / 无变形 / 无漂移 / 无伪影」**。
   → 锚定句应保留 §6.3 的「杜绝美化」（它确实有效，因为是**对抗模型默认磨皮**的指令），
   但**不要指望它是行业通用写法**；通用写法是**部位清单式**（见 §4）。
3. **「反 AI 感」有一整套词族，原 skill 完全没覆盖**：
   `不完美的自然构图`、`自动对焦不完美`、`逼真的环境瑕疵`、`可信的瑕疵`、
   `轻微手持不稳`、`细微的压缩伪影`、`自然高ISO颗粒`、`细微传感器噪点`、`自动对焦呼吸`。
   → 这是「像实拍而不像 AI」的关键，**已补入** skill §6.4 / §6.10。

## 4. 样例骨架（可套用形态）

> 按项目红线（skill §6.9），语料正文**不搬入仓库**。本节给的是**归纳出的骨架** +
> **按骨架自写的原创示例**，用来说明「每一段该写什么」；套用时把 `<>` 换成自己的题材即可。

### 骨架 A：散文式 10 段（平台通用向主力写法）

| # | 段职能 | 该段写什么 | 语料中的典型措辞 |
|---|---|---|---|
| ① | 身份锚定 | 逐部位锁定同一张脸 | 保持准确的面部比例、眼型、下颌线、嘴唇、发型轮廓、发色分布和逼真的皮肤质感 |
| ② | 画面类型 | 像什么片 + 明确排除 | 超写实的`<题材>`照片，必须像是`<真实来源>`——而不是`<要排除的方向>` |
| ③ | 摄影美学 | 反 AI 感词族 | 不完美的自然构图，扎实的现实主义，轻微手持不稳，自动对焦不完美，逼真的环境瑕疵 |
| ④ | 主体外形 | 面容 + 服装材质 | `<眼神 / 皮肤质感>`；`<材质 + 款式 + 配件 + 色彩>` |
| ⑤ | 动作姿态 | 姿态 + 视线 + 手位 | 姿势自然地拍到，微微转头朝向镜头，不对称的肩膀，身体平衡可信 |
| ⑥ | 镜头器材 | **具体焦段** + 器材缺陷 | 200mm–400mm 视角、压缩背景透视、浅层自动对焦不一致、自然高 ISO 颗粒 |
| ⑦ | 环境光线 | 环境清单 + 光型混合 | `<环境元素清单>`；自然光与实用光源的混合，逼真的阴影衰减 |
| ⑧ | 情绪定调 | 书名号命名情绪 | 《Mood》是`<一句话情绪>`——`<补充画面感>` |
| ⑨ | 构图画幅 | 比例 + 构图法 | 垂直 9:16，偏心构图，部分遮挡前景元素 |
| ⑩ | 负面提示 | **独立末段** + 顿号并列 | AI艺术、CGI、美妆滤镜、塑料皮肤、娃娃脸、完美对称、动漫、奇幻灯光 |

**自写示例（情绪向可只留 ①②③⑥⑩ 五段）**：

```
① 作为严格锁定的身份引用。保持准确的面部比例、眼型、下颌线、嘴唇、发型轮廓、
   发色分布和逼真的皮肤质感。没有风格化、美化或人工增强。

② 超写实的都市夜景短片，拍摄一名外卖骑手在雨后的窄巷里停下电动车、抬头看一眼
   楼上还亮着的窗。这张画面必须像是纪录片随手抓拍，而不是广告棚拍，
   也不是 CG 概念图。

③ 原始的纪实摄影美学，不完美的自然构图，扎实的现实主义，轻微手持不稳，
   自动对焦不完美，逼真的环境瑕疵。

⑥ 使用 35mm 视角、轻微运动模糊、自然高 ISO 颗粒、细微传感器噪点。

⑩ 负面提示：AI艺术、CGI、美妆滤镜、过度处理的HDR、塑料皮肤、完美对称、
   摄影棚摄影、动漫、奇幻灯光、过度锐化、不真实的眼睛。
```

### 骨架 B：时间码分段式（长镜头 / 特效向）

长镜头拆段时，语料中的成熟作品会**三层叠加**：

```
Chapter N: <章标题>                          ← 章（仅超长作品用）
⏱️ 0-4 seconds | <情绪化段落名>              ← 段：时间码 + 段落名（段落名谱见 skill §6.2）
[Camera Movement and Scene Setting] ...      ← 段内键 1：镜头与场景常量
[Timeline and Action Description] ...        ← 段内键 2：动作时间线
...（Perfectly connecting to Image 1）        ← 段尾：跨段衔接声明 + 图引用
```

**关键点**：

- 段落名走**情绪递进**（`凝视 → 启动 → 撕裂 → 生长 → 完成`），不是「动作1 / 动作2」。
- 拆段**必须在段尾显式写衔接声明**，并同步更新 `@图N` 编号，否则模型会当成无关的新画面。
- `⏱️` 这类写法在语料里**仅 23 条（0%）**，但**复杂度高的作品明显偏向它** ——
  它是「长镜头拆段」的一种解法，**不是通用骨架**。

## 6. 复用方式

```bash

data/prompt-corpus/seedance2/metadata.jsonl

# 提取中文提示词
python -c "
import json
for l in open('data/prompt-corpus/seedance2/metadata.jsonl', encoding='utf-8'):
    r = json.loads(l)
    z = r['i18n']['zh']
    print(z['t'], '|', z['p'][:80])
"

# 重跑统计（词频 / 结构 / 标签）
# 脚本自解析仓库根；也可用 SEEDANCE2_CORPUS=/abs/path/metadata.jsonl 覆盖
python backend-py/app/scripts/corpus/analyze3.py > data/prompt-corpus/analyze3.log
```

- 语料 **CC BY 4.0**，可商用，**需署名**（署名到 `docs/video-prompt-data-sources.md` 或项目 README）。
- 但按本项目既定红线：**只提炼范式，不搬运提示词正文进仓库**（skill §6.9）。
  语料留在 gitignored 的 `data/prompt-corpus/` 内做参考，`docs/` 只放**归纳后的词表与模板**。
