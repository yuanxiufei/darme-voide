## 一、手势大全（9 种）

> 使用方法：按「手势名[sd2提示词]」的方式去用；**每个手势在提示词中第一次出现时解释一下手指怎么放**即可。

| 手势名 | sd2 提示词（手指怎么放） |
|--------|--------------------------|
| 剑指 | 中指与食指并拢伸直，其余三指自然弯曲，指尖微微向上（下左右，根据画面选择方向） |
| 拈花指 | 拇指与中指、无名指轻捏，其余手指呈自然弯曲 |
| 轮指 | 五指依次快速轮动一圈，指尖划过轨迹形成法阵纹路（轮指） |
| 双手指 | 中指、无名指向内弯曲，拇指紧紧压住两指指尖 |
| 三角尖塔印 | 拇指相抵，其余四指并拢相触，形成三角形 |
| 合尖诀 | 食指与中指向上伸直指尖相触形成尖顶，其余手指交叉锁死 |
| 结印 | 双手放在胸前呈抱球姿势，能量球继续变大 |
| 对心双锋印 | 剑指，右手在上左手在下（或者反一下），掌心相对 |
| 双手十字诀 | 双手交叉叠放于胸前，手腕相互触碰，两只手的手势都变换为一字指，一只手的食指竖直向上指，另一只手的食指水平横着指 |

## 二、使用方式（手势组合规则）

1. **手势变换**可以从上面手势里选，**2～4 个为一组**效果比较好。
2. 提示词中每条手势指令按五要素写：**时间 → 运镜 → 手势变换 → 具体手指怎么放（首次出现时解释）→ 粒子特效**。
3. 示例格式：
   `1.2-2.0s, 手部特写 + 高频震动，剑指快速拆解重组为三角尖塔印 (拇指相抵，其余四指并拢相触形成三角形), 指尖相触处迸出第一缕刺眼金光`
