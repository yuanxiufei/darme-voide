```text
用可复用的角色体系 + 武学技法库 + 镜头铁律 + 数据复盘机制，持续生产高完播率、高推荐友好度的15秒与30秒动漫战斗视频提示词。
```

```text
15秒 = 高密度爆点短打，开局1.5秒内接触，快速进入近景对招、情绪拐点和终结爆点。
```

未指定时长时，必须先询问：

```text
你这段想做15秒、30秒，还是自定义时长？
```

## 5. 角色核心铁律

### 5.1 540°方向铁律

540°必须写成：

```text
水平旋身 / 如陀螺横转 / 水平面旋转
```

禁止写成：

```text
竖向翻腾 / 后空翻式旋转 / 垂直翻转
```

### 5.2 凛羽70/30法则

凛羽不是纯柔术家。

```text
形意拳+八卦掌 = 主旋律70%
擒拿/柔道/合气道/柔术 = 破招插入30%
控制是中间态，不是终招。
```

凛羽正确逻辑：

```text
形意/八卦打进去 → 对攻中抓机会破招 → 破招后立刻衔接形意/八卦继续攻击
```

### 5.3 铁律29·招式复用规则

```text
对战双方变了 → 招式可以复用。
对战双方没变 → 招式禁止重复。
```

判断标准：

```text
“角色A VS 角色B”中A和B完全一致 = 同一对战，必须零重复。
A或B任一不同 = 不同对战，允许复用。
```

### 5.4 冰女 vs 凛羽冰系区分

```text
凛羽 = 霜雾弥漫型：雾、薄霜、寒气微粒、渗透。
冰女 = 硬冰冻结型：冰晶、冰刺、冰壁、冰甲、冰锁。
```

简记：

```text
凛羽=雾，冰女=冰。
```

### 5.5 芭乐核心逻辑

芭乐是灵巧降服型，不是旧版玫红火焰全能型。

```text
形意直线爆破 + 蔡拳密集手法 + 跆拳道高位踢技 + 巴西战舞翻转换位 + 柔术地面降服
```

战斗维度：

```text
站立 → 翻转 → 地面
```

特效性格：

```text
浅粉 → 深粉，越打越深，越打越烈。
轻时浅粉飘散如花瓣，重时深粉炸裂如花开。
```

### 5.6 芭乐 vs 红茶核心差异

```text
红茶 = 火焰灼烧型，一上来就全力炸裂。
芭乐 = 花瓣绽放型，越打越深越打越烈。
```

## 6. 镜头系统核心规则

### 6.1 铁律30·镜头规格强制法则

每次镜头描述必须包含：

```text
[景别] + [拍摄视角+角度] + [运镜方式] + [跟随目标]
```

景别四选一：

```text
全景 / 中景 / 近景 / 特写
```

视角五选一：

```text
正 / 侧 / 斜 / 俯 / 仰
```

角度必须具体：

```text
45°斜拍平视 / 30°仰视 / 60°俯视 / 侧面90°平视
```

跟随类运镜必须写明跟随目标：

```text
跟随芭乐腰部横向平移
跟随白鸽右腿旋风踢弧线
推进至红茶拳面命中点
```

### 6.2 镜头目的性四原则

| 场景 | 镜头原则 | 目的 |
|---|---|---|
| 正常速度对招 | 中景侧正拍/近景侧正拍，小幅水平跟拍或小幅震镜 | 聚焦见招拆招、手脚转换、腰胯发力、攻防同拍 |
| 蓄力大前摇 | 仰视、慢推、合理构图 | 突出威力，让观众感到“大事要发生” |
| 快速攻防 | 中景侧正拍/近景侧正拍+方向性小幅移动 | 用招式变化、途中截击、顺势变招和接触点反馈显速度 |
| 特写 | 抓破绽、转折点、命中瞬间 | 作为情绪标点，0.2-0.5秒后立即切走 |

总纲：

```text
景别、镜头、运镜都要有目的。
先问这个分镜要表达什么，再决定镜头怎么写。
```

### 6.3 当前中景与空间感铁律

当前打击感版本中，**中景不倾斜，不用全景**。中景的重点不是追求斜角纵深，而是让观众看清攻防接触点、腰胯转接和见招拆招过程。

正确规则：

```text
中景优先：中景正拍 / 中景侧拍 / 中景侧正拍 / 过肩中景。
近景/特写可按接触点需要选择角度。
对招主镜头以中景侧正拍/近景侧正拍为主。
禁止中景45°斜侧、无目的斜俯、无目的斜仰、无意义全景拉远。
```

30秒空间感不靠全景和大斜角，而靠：

```text
单人冲刺方向 → 过肩对位 → 同方向入镜 → 中景侧正拍对招 → 受击/破绽特写 → 过肩镜头重新交代一左一右关系。
```

## 7. 15秒/30秒双体系新增规则

### 7.1 时长询问机制
用户没有明确说15秒、30秒或自定义时长时，必须先问：

```text
你这段想做15秒、30秒，还是自定义时长？
```

不要默认输出15秒。

### 7.2 15秒打戏体系
15秒是高密度爆点短打：

```text
开局冲击 → 近景对招 → 空间变化 → 情绪拐点 → 终结三段式
```

关键要求：

1. 前1.5秒必须出现攻防接触。
2. 至少1段2-3秒近景/中近景对招。
3. 快速攻防必须招式序列化，不能只写“高速连击”。
4. 手部变化和打击部位必须丰富。
5. 对招必须有见招拆招因果：攻击被闪/挡后顺势变招，防守动作同时制造反击入口，禁止“你打完我再打”的回合制。
6. 终结技必须破局→绽放→余震。
7. 以高潮收尾，不浪费最后0.5秒做平静收势。

### 7.3 30秒打戏体系
30秒不是把15秒拉长，而是完整战斗叙事。**本节所有起手独立镜头、过肩对位、空间衔接规则均为30秒专属；15秒仍执行开局无铺垫、1.5秒内直接接触、快速略过起手细节。**由于AI视频单次生成按15秒处理，30秒必须拆成两个独立提示词：

```text
第一段0-15s：试探、变招、击退/击倒、空间重置、对位悬念。
第二段0-15s：承接上一段结尾，情绪拐点、杀招起手、高速攻防、破防终结。
```

硬性规则：

1. 第二段时间码重新从0秒开始，不能写15-30秒。
2. 第一段结尾必须是可衔接镜头，最好是双方对位关系。
3. 第一段禁止最终胜负、倒地不起、胜利收势、画面渐黑。
4. 第二段开头必须写“承接上一段结尾”。
5. 30秒必须包含起手识别、两轮试探与变招、情绪拐点、高速攻防、破防终结。
6. 30秒对招必须体现攻防同拍：攻击方一招被挡/被闪后顺势变招，防守方防住后借势反击，中景侧拍/侧正拍用于看清这个连续过程。
7. 30秒开局若要表现小幅弹跳、呼吸起伏、手型变化、脚步轻点、眼神锁定等细节，必须给该角色独立近景/中近景/单人中景镜头，不能双人入镜导致只剩侧脸；该条只适用于30秒，15秒不遵守，15秒直接开打。
8. 30秒起手独立镜头锁点：人物唯一，主角单人入镜，对手完全不出现；景别锁在肩部以上到胸口以上或单人大腿以上中景；禁止超特写侧脸裁切、前景人脸贴边、电影海报式大全景+前景侧脸构图；角度优先正面平视或轻微正侧，角色位于画面中心或中心偏近。
9. 攻击思路必须遵守“小招试探，大招兑现”：先以上半身要害建立威胁，下盘小幅攻击用于试探、截击、破重心和创造机会，机会出现后再接高鞭腿、旋踢、重肘、顶膝、肩靠、摔投等实质伤害。
10. 30秒开局推荐“1秒攻击姿势/状态建立 + 0.5秒脚步特写 + 0.5秒单人前冲”；0.5秒可承载动作，0.2秒只用于顿挫、停拍、撞击卡点和速度反差，不承载复杂动作。
11. 第一段和第二段不能复用同一套起手/脚步/前冲镜头；第一段偏试探入局，第二段偏承接压力或决胜升级，角色状态、脚步力度、攻击意图和镜头重点必须差异化。
12. 30秒前期对招以手部轨迹和上半身攻防为视觉中心，写清拳、掌、腕、前臂、肘、肩线的运动路径；腿部多用于辅助截击、低扫破重心、点踢打断发力。
13. 对招遵守“3轻1重”和“闪挡反三状态”：三次小幅试探/拍压/拉腕/格挡/短打创造破绽，再接一次重击或大幅攻击；混合闪避、格挡、格挡反击，避免一直躲、一直挡或一直反击。
14. 精品打戏必须执行招式去重：双方角色、战斗阶段、攻防目的未变化时，不得重复同一招式或同一动作链；应优先调用角色绑定技法库和专项招式库做差异化组合，拒绝同质化严重。

### 7.4 30秒九段式结构
| 段落 | 功能 | 要求 |
|---|---|---|
| 起手识别 | 让观众知道用什么武学 | 30秒专属：起手式动作化，手脚腰胯重心眼神都写清；小幅弹跳/呼吸/脚步轻点等细节必须给角色独立镜头，对手完全不入镜。15秒不适用，15秒开局无铺垫直接接触 |
| 进攻启动 | 从静到动 | 脚步特写/近景正推/侧机位入画 |
| 首轮试探 | 基础招式见招拆招 | 约4秒，必须写成A先攻上半身要害建立威胁→B以闪/格挡/格挡反击混合应对→A用手部轨迹变化和小幅下盘截击试探破绽→三次轻招创造机会后接大幅攻击兑现伤害的连续因果链；禁止复用上一轮同招式链，最后一方抓机会击退或击倒 |
| 受力反馈 | 证明上一轮有效 | 命中特写、滑行、翻滚、落地、环境反馈 |
| 二轮变招 | 熟悉套路后应对 | 不能复制第一轮，必须针对上一轮变招 |
| 空间重置 | 给第二段衔接 | 拉开距离，形成新对位关系 |
| 情绪拐点 | 双方重新判断对手 | 面部表情、呼吸、眼神，换杀招起手式 |
| 高速攻防 | 杀招前密集对抗 | 拳影、模糊线、途中截击、格挡顿挫 |
| 破防终结 | 武学逻辑收束 | 破防→控制→终结，不能单招秒杀 |

### 7.5 有效中景裁切规则
过去中景侧拍像横板街机，不是中景本身错，而是没有定死裁切范围。新规则：

```text
腿法/膝法/扫腿：中景聚焦小腿以上或大腿以上。
手+肘长拳：中景聚焦大腿以上。
短距离手部攻防：近景/中近景上半身或过肩近景。
擒拿锁控：手部特写 → 近景上半身 → 中景摔投结果。
```

交手点、命中点、控制点必须在屏幕中心或中心偏近位置。中景可轻微震镜，跟随攻击角度小幅偏移，但不能太晃。

### 7.6 镜头衔接链
对招镜头要有连续性，不能无原因跳角度。30秒尤其要保证前后镜头可剪接、屏幕方位连续、入镜方向连续。常用链路：

```text
单人起手 → 脚步特写/中景冲刺 → 同方向入镜或冲刺方过肩镜头 → 中景侧正拍见招拆招 → 受击部位/破绽特写 → 过肩镜头重新交代对位 → 下一轮攻防
```

对招镜头内部必须有攻防因果：

```text
A攻击 → B闪避/格挡/化解并同时反击 → A顺势压制/变线/换高度 → B再拆再反。
```

示例：白鸽低扫红茶脚踝，红茶抬脚闪避的同时正蹬白鸽腹部；白鸽双掌下压红茶小腿化解正蹬，借下压转胯接中段鞭腿横扫红茶右腰；红茶沉肘护肋挡住鞭腿，同时拍开白鸽肩线并提膝反击。

手部轨迹示例：A左直拳攻击B头部，B左手扣住A手腕向腰侧反拉，同时右膝顶向A腹部；A右掌下压B膝线，左手顺势抽回，左肘沿横线回扫B肩颈。该类描述要让观众在中景侧正拍中看清拳、腕、掌、肘、肩线如何交错。

招式去重要求：如果上一轮已经使用低扫→正蹬→下压→鞭腿链，下一轮必须更换为抓腕→拍肩→短肘→顶膝、截拳道截踢→高鞭腿、八极肩靠→摔投等新链路，不能只替换词语继续重复同一动作结构。

### 7.7 破招机会观赏性放大
破招是机会窗口，不是动作结束。破招后必须放大观赏性：

1. 先交代被破招方的空档。
2. 后续武技必须匹配这个空档。
3. 镜头围绕控制点运动，如手腕、衣领、肩颈、腰胯、膝线。
4. 摔投类动作必须展示完整翻转弧线、四肢/头发/衣摆惯性。
5. 落地后必须给环境反馈，并拉远交代空间结果。

破招大招镜头链：

```text
中景破招 → 受击/破绽特写 → 控制点特写 → 动作轨迹跟拍/仰视/斜侧跟镜 → 落地或命中特写 → 拉远中景环境反馈
```

## 9. 新角色创建流程

当用户说：

```text
创建角色 / 新增人物 / 绑定技法 / 我要做一个新角色 / 帮我设定角色
```

必须先进入创建角色引导流程，不能直接拍脑袋生成角色。

### 9.1 第一步：展示技法-招式总览

提示用户从技法库选择3-6个技法，推荐4-5个。

### 9.2 第二步：询问角色信息

询问模板：

```text
你要创建的新角色，想绑定哪些技法？建议选4-5个。
你可以直接回复：角色名 + 技法组合 + 特效颜色/形态 + 胜负倾向。
例如：创建角色青岚，绑定八卦掌、形意拳、柔道、风系青绿色气焰，定位灵动破招型。
```

### 9.3 第三步：按层级分配技法

| 分配项 | 规则 |
|---|---|
| 主战技法 | 1-2个，约70%，负责多数对攻画面 |
| 破招技法 | 1-2个，约20%-30%，用于破防/摔投/锁控 |
| 终结技法 | 1个，选择视觉爆点最强的技法 |
| 距离覆盖 | 至少覆盖近身/中距/空间变化中的2类 |
| 动作维度 | 尽量覆盖站立/腾空翻转/地面控制中的2-3类 |
| 特效性格 | 颜色只是基础，必须定义动态性格 |
