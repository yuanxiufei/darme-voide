| 第一段2.2~6s | 爪扫→压低躲避→横肘回扫→竖臂格挡+蛇拳反击→后仰闪避→按肩下压→直拳→摇闪腹拳→抓腕卸力→下砸肘→托臂阻肘→顶膝→交叉按膝 | 近身试探不是单招，而是连续因果链；手部攻击形态变化足够多：爪/肘/拳/蛇拳/抓腕/托臂/顶膝 |
| 第一段6~7.5s | 白鸽被震退后不是停顿，而是近景拉远形成受力反馈，再用推掌重新上手 | 受击退开=节奏重置点，必须立刻转入下一轮攻击思路 |
| 第一段7.2~9s | 第二轮试探从手部近战切换为腿法：里合大摆腿→中扫腿→屈膝炮弹踢→腾空二连踢 | 两轮试探必须改变攻击语言：第一轮爪拳肘近身，第二轮旋腰拧胯腿法 |
| 第一段9~9.5s | 太极肩部以上近景，眉头微蹙、嘴巴微张、太阳眩光、碎屑飞散 | 0.5秒表情受力/惊讶帧能放大上一段连踢的威胁，不是废镜头 |
| 第一段9.5~11s | 过肩中景重建对位，再进入手部拆招：外摆、直拳、摆拳、抓小臂、爪扫腰、抓腕 | 过肩镜头适合承接双方关系，并让观众看清“谁压谁、谁反制” |
| 第一段11~15s | 太极横拽拉近、白鸽顺势砸肘、太极横肘抵挡、白鸽挑肘、定心肘、爪扫、太极四两拨千斤、白鸽腾空失衡后空翻落地，最后固定对位 | 第一段不一定要终结，关键是结尾给第二段留下清晰空间关系、身位差和情绪悬念 |
| 第二段0~2s | 两个独立1秒近景：白鸽由玩味变认真，太极呼气后眼神坚定 | 第二段必须从0秒开始，但承接第一段情绪升级；不是15~30秒连续时间轴 |
| 第二段2~5s | 3秒内连续完成探掌、下沉闪避、腹拳硬格、下砸肘、托肘、提膝、勾拳、截停、扣腕、换腕、顶心肘、双侧夹攻、双托掌、水平一字马踢下巴 | 第二段前3秒攻防密度要显著高于第一段，进入“认真后升级”状态 |
| 第二段2~2.5s | 镜头随手臂交缠/格挡接触线性推进0.3秒，弹开分离时后拉0.2秒 | 新增精品镜头法：近身对招镜头推拉呼吸，接触推进、分离后拉 |
| 第二段4.5~5s | 一字马水平踢下巴写到脚背、速度线、皮肤泛白转红、牙齿咬合、唾液飞沫、扇形冲击波、颈部肌肉拉伸 | 命中反馈颗粒度极高：命中点、皮肤、牙齿、唾液、颈部、冲击波全部可视化 |
| 第二段5~6.5s | 白鸽后仰失衡近景 + 脚部极特写后退稳身 | 重击后必须给“失衡→稳身”的可视恢复过程，否则力道不成立 |
| 第二段6.5~9s | 白鸽改变策略扬沙遮眼，再低身高速冲出，形成攻击思路变化 | 第二段中后段不能继续同一套拳脚，应允许环境战术改变攻击思路 |
| 第二段9~12s | 太极极特写抓腕上举，手掌点到喉前1cm，随后拉远定格胜负 | 终结不是必须爆炸轰飞，也可以是“控制线定格”；点到为止更适合太极气质 |

### 5. 问题标注

### 7. 可复用词库条目

#### 词条1：30秒精品骨架·两段独立15秒

```text
类型：30秒结构 / 双15秒拼接
适用：所有30秒打戏
精修表达：
第一段15秒负责建立角色状态、完成两轮试探、制造阶段性破招，并在结尾留下清晰对位关系；第二段15秒重新从0秒开始，承接第一段结尾的屏幕方位、距离、情绪和受击状态，先用单人近景确认双方认真升级，再进入更高密度拆招与最终胜负。
禁止误写：
禁止写成0~30秒连续时间轴；禁止第二段写15~30秒；禁止第二段不承接第一段结尾。
推荐强度：S级
```

#### 词条2：第一段两轮试探结构

```text
类型：节奏结构 / 攻击思路变化
适用：30秒第一段
精修表达：
第一轮用爪、拳、肘、掌等上半身近身招式快速试探头部与上半身；受力退开后，不重复同一套手部攻击，第二轮改用腿法、旋腰拧胯、里合摆腿、中扫腿、腾空二连踢等不同攻击语言压迫对手，最后由胜方抓住破招机会收尾。
禁止误写：
禁止第一段15秒从头到尾同一种攻击形式；禁止两轮试探没有攻击思路差异。
推荐强度：S级
```

#### 词条3：近身对招镜头推拉呼吸

```text
类型：镜头词 / 近景对招
适用：拳掌爪肘、黐手、擒拿、格挡交缠
精修表达：
镜头随双方手臂接触关系做推拉呼吸：每次手臂交缠、格挡、硬碰时线性推进0.3秒；每次弹开、分离、拉开半步时匀速后拉0.2秒，形成接触压迫与分离喘息的节奏。
禁止误写：
禁止近身对招镜头完全固定不动；禁止无意义乱晃导致动作看不清。
推荐强度：S级
```

#### 词条4：命中反馈五层颗粒度

```text
类型：打击反馈 / 受击反馈
适用：重击、踢下巴、腹部托击、肘击、膝撞
精修表达：
命中反馈必须写清命中点、皮肤/肌肉形变、骨骼或关节受力方向、飞散物或体液细节、冲击波/后仰/脚步失衡五层反馈，让观众看见力道从接触点传到全身。
示例：
脚背精准命中下颌骨左侧，皮肤受力泛白再转红，牙齿因撞击脱开又猛然咬合，唾液飞沫呈弧线飞散，冲击波向后扇形爆开，头部后仰至极限。
禁止误写：
禁止只写“重重踢中”“被打飞”，缺少接触点与身体反馈。
推荐强度：S级
```

#### 词条5：受击后稳身恢复镜头

```text
类型：受击反馈 / 节奏重置
适用：角色被重击后没有立刻倒下，需要稳住继续战斗
精修表达：
角色上半身后仰失衡后，切脚部极特写，支撑脚猛地踩入地面定住，另一只脚向后撤出半步，在沙地或碎石上留下拖痕，用脚步恢复重心再进入下一轮攻防。
禁止误写：
禁止重击后瞬间无代价继续攻击；禁止没有稳身过程。
推荐强度：A级
```

#### 词条6：环境战术改变攻击思路

```text
类型：战术变化 / 空间环境利用
适用：第二段中后段、角色改变进攻策略
精修表达：
角色发现正面对拼不占优势后，不继续重复拳脚硬打，而是利用场景环境制造短暂遮挡或逼防，例如抓起沙地扬沙遮眼、踢起碎石扰乱视线、借墙面反蹬换轴，再趁对手防御迟滞发起低身突进。
禁止误写：
禁止环境动作变成无伤害无后续的花活；环境战术必须服务下一次有效攻击。
推荐强度：A级
```

#### 词条7：控制线终结

```text
类型：终结技 / 胜负定格
适用：太极、凛羽、擒拿/防反型角色，不需要轰飞爆炸的胜利
精修表达：
胜方抓住对手手腕上举，另一只手掌或指尖停在对手喉前、胸线前或下颌线前1厘米，点到为止；镜头从极近景缓慢拉远到中景侧拍，让观众看清双方姿势与胜负关系。
禁止误写：
禁止所有终结都写成爆炸击飞；防反型角色可用“控制线定格”体现压制。
推荐强度：A级
```

#### 词条8：顺势续招链

```text
类型：动作衔接 / 连招惯性 / 落空后续招
适用：近身连招、腿法连段、爪肘拳掌转换、第一段两轮试探
精修表达：
攻击落空后不停止，角色借原本动作惯性顺势转换下一招，让观众看见“落空以后下一步干什么”。例如爪击扫过头顶后顺势横肘回扫，直拳被摇闪后顺势抓腕转身卸力，扫腿落空后以支撑腿为轴顺势转入另一腿中扫，第一脚踢空后顺势腾空旋身接第二脚，身体被带动后顺势下砸肘反压。
核心功能：
顺势不是口头连接词，而是动作物理惯性的桥。它负责消除“一招一停”的回合制感，让连续攻防像同一股力一路转换方向。
禁止误写：
禁止“攻击落空→停顿→重新起手”；禁止每一招都像独立回合；禁止落空后角色原地重置再发新招。
推荐强度：S级
```

#### 词条9：同时反击链

```text
类型：防守反击 / 同步攻防 / 招架后续
适用：格挡、摇闪、托臂、接掌、卸力、截击、防反型角色
精修表达：
招架、格挡、摇闪、卸力不是动作终点，而是反击入口；角色在防守成立的同一拍，用另一只手、另一条腿或身体重心完成反击。例如竖臂格挡的同时蛇拳点脸，摇闪躲开直拳的同时腹拳反打，托住下砸肘的同时提膝上顶，接掌后拉卸力的同时横扫顶住小臂上推，曲臂格挡腿法的同时另一臂拳顶膝部破坏对方发力线。
核心功能：
同时用于把“挡住了”升级成“挡住并反打”，让防守不再是等待下一回合，而是同一镜头里的攻防交换。
禁止误写：
禁止“先挡完，停一拍，再攻击”；禁止防守镜头没有后续；禁止只写格挡成功却不写反制方向、反制部位和反制工具。
推荐强度：S级
```

#### 词条10：有来有回动作因果链

```text
类型：对招结构 / 因果链 / 近身拆招
适用：所有近身对招、30秒第一段初探、第二段高密度拆招
精修表达：
每一个动作都必须回答上一个动作留下的问题：A攻击落空后顺势变线，B格挡/摇闪/卸力的同时反击，A再借受力或被带动的惯性切换下一招，B再拆再反。写法上优先使用“落空后顺势”“格挡的同时”“卸力的同时”“不收势”“借拉扯惯性”“被带动身体后”等词，让攻防持续咬合。
示例链：
爪扫头部落空 → 顺势横肘回扫 → 竖臂格挡同时蛇拳反击 → 后仰闪避 → 按肩下压 → 顺势曲臂蓄拳 → 摇闪同时腹拳 → 抓腕转身卸力 → 被带动身体后顺势下砸肘 → 托臂阻肘同时提膝。
禁止误写：
禁止A打一招、B挡一招、双方各自归位；禁止“你一下我一下”的回合制拆招；禁止没有因果的招式堆叠。
推荐强度：S级
```

#### 词条11：中景侧拍目的性增强

```text
类型：镜头规则 / 中景对招 / 画面可读性
适用：中景侧拍、左45°中景、过肩中景、横板街机感对招
精修表达：
中景侧拍可以连续使用，但每个镜头必须明确拍摄范围、动作中心和移动目的，例如“聚焦双方上半身”“聚焦双方大腿以上”“肩部以上入镜”“小腿以上入镜”；同时用轻微震动、线性平移、水平跟拍、跟随手部动作上移、接触点微颤，让正在使用的招式始终处于屏幕中心。这样中景不靠乱切镜头也能有激烈感、清晰度和节奏变化。
核心功能：
镜头丰富度不是盲目增加景别，而是让每个镜头知道自己拍什么、跟谁、为什么动。中景侧拍只要配合微颤和平移，也能很好看。
禁止误写：
禁止只写“中景侧拍”但不说明拍哪里以上入镜；禁止动作跑出画面中心；禁止无目的乱晃导致招式看不清；禁止连续中景完全固定无震动、无平移、无接触反馈。
推荐强度：S级
```

#### 词条12：受力特写插入

```text
类型：镜头节奏 / 情绪反馈 / 受击放大
适用：连续中景对招后的0.3-0.6秒情绪点、重击前后的威胁放大
精修表达：
在连续中景对招后插入短促低近景或肩部以上特写，聚焦角色后仰、眉头微蹙、嘴巴微张、短暂惊讶或受力表情，配合太阳眩光、碎屑飞散、发丝/马尾被爪风带动、背景动态模糊，放大上一击威胁并形成节奏呼吸。
示例：
低近景聚焦太极肩膀以上带镜头眩光，太极后仰眉头微蹙、嘴巴微张，露出短暂惊讶/受力感，背景带太阳眩光，周围飞散碎屑。
禁止误写：
禁止特写无功能；禁止纯表情停顿超过1秒无攻防承接；禁止特写不说明拍摄范围和情绪反馈。
推荐强度：A级
```
