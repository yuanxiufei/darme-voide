## 0. 武学导览卡

- **一句话理解**：泰拳不是单纯“膝肘很重”，而是以拳、肘、膝、胫骨扫腿、锁颈缠抱、硬格挡、压步推进和身体碰撞为核心的近中距离压迫体系。
- **战斗气质**：凶狠、直接、硬朗、压迫、抗打、连续消耗、贴身破防、身体武器化。
- **主战距离**：中距离拳腿扫踢、近距离肘膝、贴身锁颈缠抱；可通过美式竞技泰拳扩展组合拳腿节奏，通过Muay Khao强化贴身膝法压制。
- **适合角色气质**：强攻型、硬派型、压迫型、冷酷处刑型、擂台斗士型、力量型女战士、以攻代守角色。
- **适合战斗定位**：开局压迫、近身破防、膝肘重击、硬格挡反击、终结前承接、贴身连续消耗、对抗腿法或拳法角色。
- **画面识别点**：高架护头、胫骨硬挡、低扫/中扫/高扫、肘击切线、膝撞折身、锁颈控制、压步顶进、身体碰撞、汗雾与冲击气爆。
- **适合15秒**：适合“压步接触→硬挡反击→膝肘重击→锁颈破重心→终结”的高密度压迫；不适合长时间试探或完整擂台回合铺垫。
- **适合30秒**：适合从拳腿试探、扫腿削弱、硬挡互换、贴身锁颈、膝肘处刑到终结的完整压迫叙事。
- **不适合方向**：轻盈空翻游走、远程气功、纯拳击连拳、纯摔跤地面缠斗、过度武器化、现实危险教学式细节。
- **推荐绑定方式**：可作为红茶、将军、冰女等硬派角色的主战或副战模块；创建新角色时可按“泰系共核 + 1-2个分支标签”绑定，不必把四个分支全部塞入同一角色。

## 1. 泰拳统一总定位

本专项统一包含四类泰系/泛泰系近身打击资料：古泰拳 Muay Boran、缅甸拳 Lethwei、美式竞技泰拳、Muay Khao 坎波缠抱泰拳。它们不拆成四个独立专项，而是在一个泰拳专项中作为风格模块动态调用。

### 1.1 泰系共核

所有泰拳相关动作必须围绕以下共核：

1. **八肢武器化**：拳、肘、膝、腿胫都可作为打击点，但执行层要根据安全和画面需要净化为二次元打戏表现。
2. **高架护头与硬格挡**：双臂护头、肘臂架挡、胫骨硬挡必须可见，不能只写挨打或无防御硬吃。
3. **压步推进**：泰拳强在持续向前压迫，通过小步顶进、重心压低、肩胸逼近让对手退无可退。
4. **膝肘近身兑现**：中远距离拳腿创造机会，近距离用肘、膝、锁颈、身体碰撞兑现伤害。
5. **扫腿破根**：低扫削支撑、中扫打肋、高扫打头；扫腿后必须有对手重心变化或防御反应。
6. **锁颈缠抱控制**：贴身后控制头颈/肩背/上臂方向，拉低重心，为膝撞、转身甩摔或终结创造条件。
7. **物理冲击优先**：泰拳普通攻防阶段优先写肌肉发力、汗雾、尘土、衣物震动、骨架受力、地面震颤；特效只按角色主色服从。

### 1.2 统一禁区

- 禁止把泰拳写成纯拳击连拳，必须体现膝、肘、腿、锁颈或硬挡中的至少两类。
- 禁止把泰拳写成轻盈空翻游走或巴西战舞式倒立踢。
- 禁止只有“肘击很重”但没有压步、接触点、受击反馈和后续控制。
- 禁止过度现实危险教学：抠眼、掰指、后脑、喉咙、关节毁伤等内容在执行层必须净化为面门、下颌、胸口、肩背、肋侧、重心破坏等可视化打戏目标。
- 禁止四分支无因果乱炖。分支切换必须由距离、对手反应或阶段功能触发。
- 禁止长期同质化低扫/膝撞重复；同类攻击连续不超过2次，且路线、目标和功能必须变化。

## 2. 四分支风格速览

### 2.1 古泰拳 Muay Boran｜传统狠厉与全身武器化

- **核心标签**：古法、狠厉、全身武器化、飞膝、旋肘、扫踢、压迫式终结。
- **战斗作用**：适合终结技、破局重击、短时间爆发、传统武者气质角色。
- **视觉识别**：古法架势、肩背发力、肘膝腿连环、动作更原始粗粝，打击路线带大幅身体拧转。
- **净化原则**：保留“古法狠厉”和“全身武器化”的画面气质，删去真实致残细节，转译为二次元夸张冲击。
- **禁区**：不能写成现代擂台点数试探，也不能写成武侠轻功飞来飞去。

### 2.2 缅甸拳 Lethwei｜裸拳感与粗粝硬碰硬

- **核心标签**：裸拳感、头部顶撞意象、硬碰硬、粗粝近身、持续压迫。
- **战斗作用**：适合野性角色、Boss压迫、互殴力量交换、近身破防。
- **视觉识别**：拳面冲击更粗粝，前额/肩胸顶进形成空间压迫，双方距离极近，汗雾和身体碰撞感强。
- **净化原则**：头撞相关内容执行层优先改写为“额前压迫、肩胸顶进、头部贴近制造压迫”，避免现实头撞教学式描写。
- **禁区**：不能长期写成无技术乱斗；必须保留护架、压步、肘膝、硬挡等结构。

### 2.3 美式竞技泰拳｜现代擂台组合与拳腿节奏

- **核心标签**：组合拳腿、擂台节奏、低扫接拳、拳法铺垫扫踢、现代竞技读秒感。
- **战斗作用**：适合30秒完整对招、前中段压制、现代斗士角色、可读性强的拳腿组合。
- **视觉识别**：刺拳/摆拳创造角度，低扫削支撑，中扫打肋，高扫兑现，攻防节奏清晰。
- **禁区**：不能退化成普通拳击；拳法必须服务扫踢、膝肘或锁颈进入。

### 2.4 Muay Khao 坎波缠抱泰拳｜锁颈膝法与贴身消耗

- **核心标签**：锁颈、缠抱、连续膝撞、贴身消耗、压低重心、转身甩摔。
- **战斗作用**：适合终结前承接、近身压制、破重心、对付高机动角色或腿法角色。
- **视觉识别**：双手控制后颈/肩背/上臂，胸口贴近，膝盖连续顶入腹部/肋侧/胸口，脚步小幅转动让对手失衡。
- **禁区**：不能写成柔术地面缠斗；重点是站立缠抱和膝法处刑。

## 3. 四分支动态组合原则

泰拳专项采用“泰系共核 + 分支标签 + 阶段功能”的组合策略。

### 3.1 不需要固定四分支全上

生成泰拳打戏时，不强制把古泰拳、缅甸拳、美式竞技泰拳、Muay Khao 全部展示。系统应根据角色和时长选择1-2个分支作为主要画面气质，其余只在必要时作为动作补充。

### 3.2 动态组合必须有距离逻辑

```text
中距离拳腿试探/扫踢 → 硬格挡或压步推进 → 近身肘膝兑现 → 锁颈缠抱破重心 → 终结重击/甩摔/膝肘连段
```

分支切换示例：

```text
美式竞技泰拳拳腿组合 → 胫骨硬挡反低扫 → Muay Khao锁颈膝撞 → 古泰拳旋肘终结
```

或：

```text
缅甸拳粗粝肩胸顶进 → 泰拳高架硬挡 → 近身短肘切入 → Muay Khao转身甩摔
```

### 3.3 15秒动态组合规则

15秒推荐使用 **泰系共核 + 1-2个分支特征**，不要四分支全塞。

- 开局接触：压步前顶、硬挡反击、低扫截停。
- 近景拆招：胫骨硬挡、肘臂架挡、拳腿变线。
- 破重心：低扫削支撑、锁颈拉低、膝撞折身、小转步甩偏。
- 承接段：连续膝肘压制或拳腿组合逼入贴身，禁止纯蓄力。
- 终结：古泰拳飞膝/旋肘、美式拳腿重扫、Muay Khao锁颈膝撞甩摔、缅甸拳式肩胸顶进重击意象。

15秒必须避免：

- 连续低扫反复低扫，没有高度和功能变化。
- 两个镜头连续只写蓄力、摆架或眼神特写。
- 终结前只起跳或只锁颈不打击，造成无攻防空档。
- 真实危险部位教学化描写。

### 3.4 30秒动态组合规则

30秒允许使用 **2-3个分支特征**，按阶段铺开，不要乱炖。

推荐结构：

```text
0-5s：美式竞技泰拳拳腿试探，建立擂台节奏
5-12s：低扫/中扫削弱对手支撑，硬挡反击形成力量交换
12-20s：压步进入近身，肘膝重击或缅甸拳式粗粝顶进
20-26s：Muay Khao锁颈缠抱、连续膝撞、转身破重心
26-30s：古泰拳重膝/旋肘/甩摔终结，按角色主色加入特效或纯物理冲击
```

30秒分支转换理由示例：

- 对手后撤拉开距离 → 美式竞技泰拳拳腿组合追击。
- 对手起腿抢攻 → 胫骨硬挡后低扫支撑腿。
- 对手护头严密 → 肘击变线或膝撞打中线。
- 对手高机动闪避 → Muay Khao锁颈限制位移。
- 对手硬抗互殴 → 缅甸拳式肩胸顶进和近身短肘增强压迫感。

| 小转步膝撞换角 | 锁颈状态下小步转体，拉偏对手中线，从侧角提膝撞肋 | 变线/破重心 | 中近景·斜侧45°·横移跟拍·跟随脚步和膝线 | 0.8-1.1s | 禁止原地重复顶膝 |
| 锁颈甩摔落地 | 连续膝撞后小转步拉偏，松手瞬间把对手沿斜线甩倒 | 终结/摔倒 | 全景·斜俯角·后拉跟拍·跟随甩摔轨迹 | 1.0-1.4s | 禁止写成地面降服 |

## 5. 招式功能归类

### 5.1 适合开局接触

- 高架压步入距
- 胫骨硬挡反低扫
- 刺拳低扫组合
- 裸拳感重摆逼退
- 肩胸顶进破位

### 5.2 适合近景拆招

- 肘臂架挡接横肘
- 胫骨硬挡反低扫
- 粗粝短肘互换
- 古法斜肘破架
- 低扫假动作高扫

### 5.3 适合破重心

- 扫腿破根接高扫
- 锁颈小转步甩偏
- 古法扫腿压倒
- 双手锁颈拉低
- 小转步膝撞换角

### 5.4 适合压制承接

- 中扫打肋接摆拳
- 压步短肘连击
- 拳腿逼角接膝
- 锁颈连续膝撞
- 前额压迫假动作接膝

### 5.5 适合终结

- 飞膝冲胸
- 回身旋肘
- 扫腿破根接高扫
- 锁颈甩摔落地
- 古法扫腿压倒

## 6. 15秒调用规则

### 6.1 推荐结构

```text
0-1s：高架压步或硬挡反击，必须在攻击动作内部建立接触
1-3s：低扫/肘架/拳腿组合制造第一轮受击反馈
3-6s：短促高速对招，最多6个清晰攻击/格挡节点，以膝肘/拳腿变线打出节奏
6-9s：锁颈、扫腿或硬挡反击破重心，形成终结机会
9-12s：终结前承接必须继续命中或控制，不许纯蓄力
12-15s：飞膝、旋肘、锁颈甩摔或扫腿高扫终结，按角色主色处理特效
```

### 6.2 15秒分支选择

- **红茶类爆燃压迫**：美式竞技泰拳拳腿组合 + 古泰拳飞膝/旋肘终结。
- **将军类冷酷处刑**：泰系共核硬挡 + Muay Khao锁颈膝撞 + 八极或泰拳重击终结。
- **野性Boss类**：缅甸拳粗粝顶进 + 短肘互换 + 锁颈甩摔。
- **硬冰/封锁类角色**：胫骨硬挡、低扫破根、膝撞折身，可叠加角色主色冰晶封锁但不能遮挡接触点。

### 6.3 15秒禁区

- 禁止把0-3秒写成站桩对峙。
- 禁止6-12秒只写锁颈僵持、蓄力、眼神或起跳。
- 禁止连续两个镜头都是膝撞或低扫，除非第二次改变高度、角度或功能。
- 禁止真实危险细节教学化；执行层全部转成安全可视化目标。

## 7. 30秒调用规则

### 7.1 推荐结构

30秒泰拳适合完整呈现“试探→削弱→压迫→贴身→终结”的层级。

```text
0-5s：单人起手/脚步/前冲，展示高架护头、压步、拳腿试探
5-12s：拳腿组合与硬挡反击，建立双方力量交换
12-18s：低扫削支撑、中扫打肋、肘击破护架，逐步进入近身
18-24s：锁颈缠抱、连续膝撞、小转步破重心
24-30s：分支终结，古泰拳重膝/旋肘、美式高扫、Muay Khao甩摔或缅甸拳式粗粝重击意象
```

### 7.2 30秒镜头重点

- 前段可用脚步特写展示压步，但脚步特写不宜超过0.5秒。
- 对招中景侧正拍必须写清“攻击→硬挡/闪避→反击→变线”的因果。
- 近身段用近景/中近景拍锁颈、肘架、膝撞接触点。
- 终结段可用全景或低仰角展示身体被甩飞、震退或倒地轨迹。

## 8. 角色创建导览与绑定建议

### 8.1 给不懂武学用户的简介卡

如果用户不知道角色适合什么武学，可这样介绍泰拳：

```text
泰拳：硬派压迫型武学，核心是拳、肘、膝、扫腿、锁颈和硬格挡。它适合做“越打越近、越近越狠”的角色：先用拳腿逼近，再用肘膝破防，最后锁颈膝撞或飞膝终结。适合强攻、冷酷、野性、擂台斗士、Boss压迫型角色；不适合轻盈空翻、远程法术或纯柔术地面角色。
```

### 8.2 绑定层级建议

- **主战泰拳**：角色身份就是强攻压迫，动作签名必须包含膝肘、扫腿、锁颈或硬挡。
- **副战泰拳**：用于补近身破防和打击感，可与散打、八极、空手道、洪拳搭配。
- **终结层泰拳**：只在大招或终结段调用飞膝、旋肘、锁颈甩摔等重击。

### 8.3 与现有角色关系

- **红茶**：可优先调用美式竞技泰拳 + 古泰拳，表现橙红火焰式爆燃压迫。
- **将军**：可优先调用Muay Khao + 泰系共核硬挡，表现冷酷锁颈膝肘处刑，再接八极短爆发。
- **冰女**：可调用胫骨硬挡、低扫、膝撞折身作为硬冰封锁前的物理打击，但不能变成纯泰拳角色。
- **女帝/白鸽**：一般不作为主绑定。若临时对战需要，可只调用胫骨硬挡或低扫反制，不改变其腿法主轴。

## 9. 执行层净化规则

1. **危险目标降级**：真实武术中可能涉及喉、眼、后脑、关节毁伤的内容，执行层改为面门外侧、下颌线、肩颈线、胸口、腹部、肋侧、护架、重心线。
2. **头撞净化**：缅甸拳头撞不写成现实教学；改为“额前压迫、肩胸顶进、头部贴近制造压迫，实际用短肘/膝撞/肩胸撞开空间”。
3. **锁颈净化**：锁颈重点是控制肩背和重心，不写窒息、断颈、致残。
4. **特效服从角色主色**：泰拳本身不自带固定火焰或金光；红茶可橙红，冰女可硬冰，白鸽必须紫黑，雷电纯紫/银紫。
5. **动作可读性优先**：膝肘连击不能堆太密，1秒内最多展示2-3个清晰近身节点；高速段最多6个清晰攻击/格挡节点。
6. **镜头必须拍接触点**：泰拳打击感来自拳面撞护架、胫骨碰撞、肘臂接触、膝盖顶腹、锁颈拉偏，不能只拍脸和特效。

## 10. 与其他武学的差异

| 对照武学 | 差异点 |
|---|---|
| 散打 | 散打更重拳腿摔组合与进退节奏；泰拳更重膝肘、硬挡、扫腿和锁颈近身压迫。 |
| 八极拳 | 八极是贴身短爆发、震脚、顶心肘、靠打；泰拳是压步持续逼近、肘膝和扫腿逐步压垮。 |
| 洪拳 | 洪拳偏桥手硬架、马步、拳掌重击；泰拳偏高架护头、胫骨硬挡、膝肘扫踢。 |
| 咏春 | 咏春偏中线封桥、短打快拳；泰拳偏大力膝肘、扫腿、锁颈和身体碰撞。 |
| 太极拳 | 太极偏接触听劲、引化借力、柔摔；泰拳偏正面压迫、硬挡反击、膝肘重击。 |
| 巴西战舞 | 巴西战舞偏翻转游走和大幅腿法；泰拳偏站立硬碰硬和近身压迫。 |
