# 洪拳十二桥手专项｜铁线拳基础桥法

<!-- ID:MARTIAL-HONG-12BRIDGE-001 -->

> 定位：本专项用于 Seedance 2.0 二次元打戏系统中的“低马步 / 桥手锁控 / 中线压制 / 寸劲短打 / 沉桥终结”类近身硬控打法。它是普通洪拳的精细子专项，不替代通用洪拳，而是在需要“桥手体系、铁线拳基础桥法、贴身短打压制”时调用。

---

## 0. 武学导览卡

- **一句话理解**：低马步贴身硬架，用前臂桥手锁住对方手臂，再用寸劲短打和沉桥下压压垮对手。
- **战斗气质**：刚猛、贴身、沉重、低位、爆发、稳守快攻。
- **主战距离**：近距离、贴身、地面低位马步缠斗。
- **适合角色气质**：硬派、沉稳、正面压迫、厚重防守反击、近身控制型角色。
- **适合战斗定位**：近身封锁、前臂桥手控制、贴身短打、防守化解后反击、终结前压制。
- **画面识别点**：二字钳羊马沉低马步、双臂横架封中线、前臂硬碰硬、短距寸桥突刺、双掌下压锁桥、沉肩震脚发力。
- **适合15秒**：可用，但必须压缩成“架桥接触 → 桥手压制 → 寸劲短打 → 快速破重心 → 沉桥终结”，避免站桩摆架。
- **适合30秒**：非常适合，能完整展示“试探 → 防守 → 压制 → 破衡 → 反击 → 终结”的桥手攻防闭环。
- **不适合方向**：远距离拉扯、空中追击、腾空翻转、大范围绕侧、高位腿法主攻、玄幻光波特效。
- **推荐绑定方式**：可作为硬派近身角色的主武学；也可作为红茶/将军/冰女等近身硬压角色的副武学或局部招式池。具体角色绑定需另行评估，不在本专项直接写死。

## 1. 武学总定位

- **武学类型**：拳法 / 掌法 / 桥手体系 / 混合马步近身短打。
- **动作气质**：刚猛、贴身、沉重、低位、爆发。
- **主战距离**：近距离、贴身、地面低位马步缠斗。
- **核心优势**：控中线、手臂架挡卸力、寸劲贴身爆发、持续压制上中盘、锁控对手前臂。
- **核心弱点**：不适合远距离拉扯、不擅长空中攻防、下盘腿法稀少、大范围绕侧机动性弱。
- **视觉辨识点**：二字钳羊马沉低马步、双臂横架封中线、短距寸桥突刺、双掌下压锁桥、发力沉肩震脚。

---

## 2. 武学核心打法

### 2.1 起手逻辑

沉身扎二字钳羊马，双臂分左右横抬成桥手，缓慢前伸试探对手中线，步步踏马小幅向前贴身逼近，不跳不窜，稳扎中近距离封锁进攻路线。

### 2.2 压制逻辑

以前臂持续架挡对手手臂，高低桥手切换封死上、中盘中线，反复拍压、下揸锁住对手桥手，寸桥短促点刺打断对手发力节奏，贴身持续短打不让对手拉开距离。

### 2.3 破重心逻辑

主要控制手腕、前臂、肘关节、肩颈、胸口、肋部。通过下压对手前臂使其重心前倾，拍击肋部破坏躯干稳定，顶肘或掌根前顶迫使身体后倾失衡。

### 2.4 防守 / 反击逻辑

柔桥、分桥卸开对手直线冲击，刚桥硬格正面拳脚；架挡瞬间转寸桥、顶肘反击，借力下压对手手臂后贴身爆发，以桥手缠绕锁腕限制对手挥拳空间。

### 2.5 空间变化逻辑

仅依靠马步前后、左右小幅平移，极少腾空，以沉身低马缩小受击面积；后撤仍保持桥手架护中线，无大范围翻滚、腾空位移。

### 2.6 终结逻辑

寸桥连环点刺面门、顶肘重击胸口、双掌沉桥猛压胸腹，靠贴身连续爆发震退对手，或锁腕压制后持续短打直至对手失去反抗能力。无浮空斩杀类终结。

## 3. 攻防距离与节奏

- **最适合距离**：近距离、贴身、地面低位马步。
- **常见节奏**：轻轻重、试探蓄力后寸劲爆发、低中高低切换、格挡后瞬间反击。
- **单招平均长度**：0.3秒（寸桥短打）/ 0.5秒（基础架桥）/ 1秒（沉桥下压）。
- **是否适合高速连打**：适合，但最多3连桥手连招；每一连都必须有前臂、掌根、指尖或肘部明确接触点，不能写成模糊掌影。
- **是否适合终结技**：适合贴身寸劲连击、顶肘重击、沉桥压胸类重击终结。

## 6. 招式接续链

### 连招链1：低位锁臂破重心 → 高位寸劲重击

第7式 制桥下压 → 第3式 寸桥标指 → 第12式 马步双标掌沉桥

说明：制桥下压锁住对手前臂使其重心前倾、上盘暴露；锁臂状态下对手难以抬手格挡，寸桥直线点刺面门打断防御；对手头部后仰失衡瞬间，双掌前推下沉重击下腹完成终结。

### 连招链2：防守卸力化解 → 侧向反击压制

第2式 柔桥缓推 → 第10式 订桥戳肋 → 第8式 圈桥挑肘

说明：柔桥卸掉对手正面直拳冲击力，对手发力落空躯干侧敞；顺势侧向短戳肋部，破坏躯干稳定迫使对手侧身；沿对手手臂外侧绕弧挑肘顶击下颌，彻底打破平衡完成压制。

### 连招链3：中线起手控场 → 连续压制转入终结入口

第4式 直桥封中线 → 第6式 分桥左右劈砸 → 第11式 马步双推单指

说明：直桥直线前推锁死对手中线，逼迫对手抬臂持续防守；分桥左右劈砸分开对手格挡手臂，制造胸腹空当；双掌齐推叠加单点刺击胸腹，持续施压为沉桥终结铺垫。

## 7. 15秒高密度打戏调用建议

### 7.1 适配核心逻辑

15秒高密度打戏主打快节奏、短时长、高衔接、无冗余动作。洪拳十二桥手用于15秒时，必须保持贴身中线缠斗，不得站桩摆桥手。优先选用0.3-0.6秒快招；慢卸力、长时间锁臂动作只可压缩，不可完整拖长。

### 7.2 分位置适配招式

- **适合起手**：第4式直桥封中线、第9式马步左右挑掌。
- **适合破重心**：第5式迫桥前顶、第10式订桥戳肋、第7式制桥下压压缩版。
- **适合压制**：第6式分桥左右劈砸、第3式寸桥标指。
- **适合终结前承接**：第11式马步双推单指。
- **适合终结**：第12式马步双标掌沉桥。

### 7.3 15秒谨慎使用招式

- **第2式柔桥缓推**：0.8秒，偏慢卸力，适合30秒见招拆招；15秒只在用户明确要防反细节时短用。
- **第7式制桥下压**：原招0.7秒，15秒不能完整拖长；可压缩成0.5秒短促下揸破重心节点，用于保留桥手压制辨识度。

### 7.4 15秒最优连招流水线

起手试探 → 高频压制 → 瞬间破重心 → 承接铺垫 → 终结

推荐链：第9式马步左右挑掌 → 第6式分桥左右劈砸 → 第10式订桥戳肋 → 第11式马步双推单指 → 第12式马步双标掌沉桥。

### 7.5 15秒强制保留

- 低位马步姿态。
- 桥手压制接触点。
- 寸劲快打。
- 快速破重心。
- 重终结。

### 7.6 15秒禁止

- 禁止超过3秒只摆马步不接触。
- 禁止连续两个镜头都是架桥蓄力。
- 禁止写成远距离拳风。
- 禁止写成腾空大招。
- 禁止只有手臂挥舞、没有前臂/掌根/指尖/肘部接触点。

## 8. 30秒完整打戏调用建议

30秒打戏允许快慢结合、有来有回、攻防交替，可加入慢卸力、锁臂蓄力动作，完整呈现铁线拳“先稳后快、先守后攻、寸劲爆发”的完整武学逻辑。

### 分段动作安排

- **起手 0-5s**：第4式直桥封中线，稳扎贴身，锁定中线开启缠斗，建立低位马步姿态。
- **第一轮交锋 5-12s**：第1式刚桥横格 + 第9式马步左右挑掌，攻防试探交替，封锁对手进攻路线。
- **第二轮压制 12-20s**：第7式制桥下压 + 第5式迫桥前顶，锁臂破重心，持续贴身压制压缩对手空间。
- **中段见招拆招 20-26s**：第2式柔桥缓推卸力，衔接第10式订桥戳肋、第8式圈桥挑肘反击，完成攻防转换。
- **终结收尾 26-30s**：第11式马步双推单指承接施压，衔接第12式马步双标掌沉桥终结收尾。

### 30秒必拍清楚

- 前臂桥手与对方手臂的接触。
- 手腕、前臂、肘关节被架开、下压、锁住的过程。
- 马步沉胯发力。
- 寸劲短促爆发。
- 快慢节奏对比：柔桥卸力、寸劲快打、锁臂压制、肘击反击、沉桥终结。

## 9. 特效 / 无特效倾向规范

### 9.1 基础适配倾向

本武学默认适配纯无特效写实打戏，核心依靠马步、桥手、寸劲、肢体碰撞质感出效果，无需任何玄幻特效支撑。

### 9.2 可添加特效点位（仅写实轻特效）

- 寸劲类招式：指尖、掌缘、接触点出现轻微空气波纹震颤。
- 震脚发力招式：脚掌落地处浅淡地面微尘、细碎石屑弹起。
- 硬格发力招式：手臂碰撞点可有低亮度、瞬时消失的磕碰闪效。
- 沉身下压终结：胸腹受压处衣物褶皱和低空气流下压效果。

### 9.3 严格禁止特效

- 禁止大范围气浪、光波、能量冲击波。
- 禁止肢体发光、特效拖尾、瞬移残影。
- 禁止地面大范围裂纹、浮空震地、爆炸效果。
- 禁止玄幻功法特效、颜色光晕、技能锁定特效。
- 禁止招式释放前的蓄力光圈、能量汇聚动画。

## 10. 与相近武学差异点（防写混核心区分）

### 10.1 对比咏春拳

- **咏春**：小念头、摊膀伏、二字钳羊马更紧凑，发力完全寸劲、轻脆快，多侧身护中线，无沉肩震脚、无重劈硬格。
- **洪拳十二桥手**：桥手更粗重、前臂架挡面积大、有震脚沉胯刚劲，存在硬劈、重压、顶胸重招，气质更刚猛厚重。
- **防混核心**：禁止写成咏春“侧身小幅度摊打”，必须保留铁线拳“正面硬架、沉肩重劲”。

### 10.2 对比八极拳

- **八极**：顶心肘、贴山靠、闯步冲撞，主打长步进身、贴身硬撞、大开大合爆发。
- **洪拳十二桥手**：无闯步、无贴山靠、无大幅度跨步冲撞，全程马步稳扎，位移极小，发力以桥手寸压、点刺为主。
- **防混核心**：禁止写出八极“大步前冲、贴身硬撞、大开大合”动作。

### 10.3 对比太极拳

- **太极**：松柔圆转、借力打力、大范围划弧、虚实转换、无硬刚发力。
- **洪拳十二桥手**：仅柔桥一招卸力，其余以刚劲硬格、主动压制、主动爆发为主，无缓慢圆转游走、无虚实试探大弧线。
- **防混核心**：禁止全盘柔化、禁止超大圆弧卸力、禁止以静制动的太极节奏。

### 10.4 对比普通通用洪拳

- **普通洪拳**：可多高低起伏、跳跃腾空、鹤嘴、虎爪、大开大合劈扫、腿法丰富。
- **洪拳十二桥手**：无腾空、无跳跃、无花哨爪法、无大幅腿法，全程低位马步、专注手臂桥法攻防，极简、沉实、贴身。
- **防混核心**：禁止加入洪拳经典跳劈、飞脚、虎爪抓拿、高位腾空动作。

## 11. 打戏系统专属调用说明

### 11.1 核心动作识别点

- 全程固定低位二字钳羊马 / 四平大马。
- 无大范围位移、无腾空跳跃。
- 所有攻防以前臂桥手为核心，优先手臂架、压、劈、刺、锁，而非拳脚乱打。
- 发力特征：沉肩、锁腰、震脚、寸劲爆发，快慢分明，柔卸刚打。
- 战术特征：死锁中线、贴身缠斗、控臂破重心，不拉扯、不绕背游走。

### 11.2 必须保留的三种核心动作

1. 低位稳马步姿态：所有招式基础，丢失即脱离铁线拳内核。
2. 前臂桥手封挡 / 锁压动作：武学核心载体。
3. 静态马步下的寸劲短爆发：区别于外家长拳的关键。

### 11.3 最容易写错的误区

- 误写成高速游走、绕背、翻滚、腾空跳踢。
- 误写成大开大合长拳劈扫、八极冲撞、咏春侧身小打。
- 加入大量特效、蓄力、浮空击飞。
- 舍弃马步、直立出招、大范围移步。
- 慢动作过多、全程柔化。

### 11.4 15秒打戏强制保留内容

- 必须保留：低位马步姿态、寸劲快打、桥手压制、快速破重心、重终结五要素。
- 必须舍弃：慢节奏卸力、长时间锁臂蓄力、无命中纯摆架。

### 11.5 30秒打戏强制补充内容

- 必须补充：攻防转换细节、锁臂控重心细节、震脚发力质感。
- 必须体现：试探 → 防守 → 压制 → 破衡 → 反击 → 终结的闭环。
- 必须保留：快慢节奏对比，突出铁线拳“稳守快攻、重沉爆发”的特质。
