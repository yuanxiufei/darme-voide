# 镜头语法：情绪翻译表

景别、运镜、角度、构图、光线——五种镜头语言，每种对应一类情绪功能。选镜头=选情绪表达。本表是逐镜设计的依据库。

## 一、景别 = 情绪距离

| 景别 | 画面范围 | 情绪功能 | 使用时机 | 常见视觉停留参考 |
|------|---------|---------|---------|-----------|
| 大远景 | 环境为主，人物极小 | 孤独/渺小/史诗 | 开场建空间、收尾余韵 | 3-5s |
| 远景 | 人物全身+大量环境 | 疏离/客观交代 | 场景开场、人物进入空间 | 3-4s |
| 全景 | 人物全身 | 关系交代（站位即关系） | 双人/多人互动的基准镜 | 2-4s |
| 中景 | 膝盖以上 | 中性/日常 | 对话戏主力景别 | 2-3s |
| 近景 | 胸部以上 | 亲密/紧张升温 | 对话升级、情绪显形 | 2-3s |
| 特写 | 脸/手/物件 | 强调/顶点/秘密 | 情绪爆发点、关键道具、台词重锤 | 1-2s |
| 大特写 | 眼睛/局部细节 | 极端强调/窒息 | 全场戏最重的一锤 | 1s |

**景别收紧=情绪收紧。** 一场吵架从全景打到特写，就是情绪从克制到失控的可视化。反向也成立：爆发后突然回全景=抽离/残酷的旁观感。

## 二、运镜 = 情绪运动

| 运镜 | 物理动作 | 情绪功能 | 高频场景 |
|------|---------|---------|---------|
| 固定 | 机器不动 | 稳定/克制/观察 | 对话基准、平静段落 |
| 推 | 机器向主体靠近 | 压迫/聚焦/进入 | 发现、下决心、对峙升级 |
| 拉 | 机器远离主体 | 揭示/疏离/释放 | 收尾、真相揭露、孤独感 |
| 摇 | 机器原地转 | 揭示空间/跟随视线 | 看清环境、跟随目光 |
| 移 | 机器平移 | 陪伴/流动 | 跟随行走、展示空间 |
| 跟 | 机器追着主体走 | 紧张/追踪/代入 | 追逐戏、人物移动 |
| 手持 | 轻微晃动 | 不安/纪实/失控 | 争吵爆发、恐惧、混乱 |
| 升降 | 垂直运动 | 权力变化/全知视角 | 俯视揭示、上帝视角 |
| 急推 | 快速推近 | 突袭/震惊 | 转折点冲击 |
| 甩镜 | 极快横移 | 时间省略/段落连接 | 快节奏切换 |

**固定镜头是默认。** 有理由才动镜头——镜头动=情绪动。没有情绪理由的运镜是炫技，砍掉。

## 三、角度 = 权力关系

| 角度 | 情绪功能 |
|------|---------|
| 平视 | 平等/客观（对话戏默认） |
| 仰拍 | 崇高/压迫/强势方 |
| 俯拍 | 弱势/怜悯/审视 |
| 荷兰角（画面倾斜） | 不安/失衡/心理失常 |

谁占上风，谁被仰拍。吵架戏用角度「偏心」，观众不用台词就懂立场。

## 四、构图 = 心理暗示

| 构图 | 心理功能 |
|------|---------|
| 三分法 | 均衡（默认安全选择） |
| 对称 | 秩序/压迫/仪式感 |
| 框中框（门框窗框围住人物） | 困住/窥视/隔离 |
| 负空间（大面积留白） | 孤独/空虚 |
| 前景遮挡（前景有物半挡） | 窥视感/观众参与感 |
| 镜面反射（镜中/玻璃中人物） | 双重身份/自我审视 |

## 五、光线 = 情绪基调（物理写法）

| 光线 | 物理描述（写进分镜的写法） | 情绪 |
|------|--------------------------|------|
| 顺光 | 光从镜头方向打亮人物全身 | 平淡/纪实 |
| 侧光 | 光从侧面切出人物明暗分界 | 立体/冲突/人格分裂 |
| 逆光 | 光从人物背后，轮廓发亮，脸在暗部 | 神圣/悲伤/离别 |
| 顶光 | 光从头顶垂直压下，眼窝深陷 | 压迫/审讯 |
| 底光 | 光从下方打亮面部 | 恐怖/诡异 |
| 低照度 | 环境昏暗，光源少而集中 | 压抑/私密/电影感 |

光线永远写物理事实，不写形容词。「氛围压抑」是不可执行的，「光只有一盏台灯，人物半张脸在阴影里」是可执行的。

表中的秒数只帮助判断视觉节奏，不是视频时长硬限制。正式镜头必须由 CINEDANCE 根据对白、呼吸、停顿、反应、完整动作和目标模型重新核算；说不完就延长或按语义拆镜，内容撑不起时长就缩短，不机械套表。

## 六、切点规则（什么时候切）

四个合法切点：

1. **情绪转折处切**——态度变了，镜头跟着变
2. **动作顶点切**——动作到最高点那一帧切走，余韵留给下一镜
3. **台词重锤后切**——重点台词落地，切到听者反应
4. **呼吸点切**——静默/停顿本身就是切点

**禁止按时间均匀切。** 均匀=没有节奏=没有情绪。

## 七、听者优先原则

对话戏里，**听者的反应镜比重拍说话者更重要**。情绪不发生在说话的人脸上，发生在听的人脸上。吵架吵到关键句，切到挨骂那个人的脸——观众要看的是这个。
