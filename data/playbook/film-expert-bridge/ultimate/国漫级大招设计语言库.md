# 国漫级大招设计语言库

> 目的：为修仙、玄幻、魔法类大招提供“国漫级”设计语言，不让成品停留在单一模板或换色特效。
> 说明：本文件提炼的是设计方法、视觉语法与特效结构，不是对任何具体 IP 招式的照搬复刻。

---

## 一、总目标

国漫级大招，不是“元素更多、粒子更多”就够了，而是要同时建立：

- 角色辨识度
- 世界观气质
- 技能层级感
- 奇观感
- 压迫感
- 终结记忆点

如果一条大招只剩下“发光、爆炸、吞没”，通常还只是普通玄幻特效，不算国漫级。

---

## 二、热门国漫式设计方向

### 2.1 `凡人修仙传` 风格方向

适合提炼的设计语言：

- 法宝驱动
- 阵纹与符文层层展开
- 小起势带出大后果
- 精密控制感
- 冷静、克制、理性，但杀伤非常明确

适合转化为大招特征：

- 技能不是一下炸开，而是逐层布阵、逐层锁定、逐层兑现
- 异象更讲结构感，不只是混乱爆发
- 镜头强调“控制”与“精准命中”

### 2.2 `仙逆` 风格方向

适合提炼的设计语言：

- 苍凉古意
- 天威压顶
- 极强精神压迫
- 空间、意志、规则层面的镇杀感
- 一击下去像天地都在沉默

适合转化为大招特征：

- 前摇短，但威压极强
- 聚能时周围空间先失真、失声、失重
- 技能本体带“天罚”“古神”“镇压”“抹除”感
- 终结更偏“湮灭、抹去、震碎、强行镇压”

### 2.3 `完美世界` 风格方向

适合提炼的设计语言：

- 太古宝术
- 神禽凶兽法相
- 巨物奇观
- 天地共鸣
- 肉身与法术同时爆发

适合转化为大招特征：

- 技能主体形态更巨大、更原始、更兽性
- 不只是能量柱，而是“法相”“凶兽”“古纹”“宝术洪流”
- 环境反馈更强，山川、云层、地面都要跟着共振

## 三、国漫级大招六层结构

每条成品至少优先设计以下六层中的四层，最好六层都成立。

### 3.1 起势层

常见设计方向：

- 单手抬起，周围粒子倒流
- 双手结印，阵纹一层层亮起
- 身体悬空，衣袍与长发被气场托起
- 武器轻震，周围空间先出现细小裂纹
- 目光锁定目标，四周环境先一步失真

### 3.2 聚能层

常见设计方向：

- 云层塌缩
- 地面亮纹扩张
- 粒子倒灌
- 法阵旋转
- 神兽法相逐渐成形
- 多层异象由小到大叠加

### 3.3 主体形态层

技能主体不要总是“球”和“柱”，要有造型差异。

可选主体形态：

- 光柱 / 火柱 / 雷柱
- 巨型法相
- 神禽 / 凶兽 / 霜龙 / 雷兽
- 剑阵 / 剑河 / 万剑轮
- 火莲 / 冰镜 / 古印 / 大钟 / 天碑
- 扇面冲击波 / 环状震荡圈 / 漩涡吞噬核

### 3.4 清场层

清场段是“爽点”，但不能只是把敌人全炸没。

可选清场方式：

- 扫荡型：横推一整片敌群
- 点杀型：高密度不规则连锁击穿
- 压制型：先压跪再清空
- 吞没型：火海、寒潮、雷网、剑雨持续覆盖
- 追猎型：技能自动锁敌追击

### 3.5 首领终结层

Boss 终结必须比清场更高级，至少升级一项：

- 体量升级
- 速度升级
- 材质升级
- 法相升级
- 镜头升级
- 结果升级

常见终结方式：

- 正面贯穿
- 巨型法相压下
- 多重封锁后中心处刑
- 能量塌缩后瞬爆
- 抹除式湮灭
- 冻结后粉碎

### 3.6 余波层

真正的国漫级大招结束后，世界要留下痕迹。

可选余波：

- 地面巨坑
- 熔浆外翻
- 雷痕烧灼
- 剑痕撕开云层
- 冰层蔓延不止
- 空间裂纹迟滞崩开

## 四、国漫级镜头母题

### 4.1 前摇镜头

- 高空俯拍锁定角色
- 仰拍角色抬手引天威
- 手部极近景拍能量形成
- 小角度环绕强化压迫

### 4.2 聚能镜头

- 由远拉近看异象扩大
- 高空转俯拍看能量覆盖地面
- 近景拍能量核心震颤
- 镜头轻震体现能量压迫

### 4.3 清场镜头

- 大远景展示技能覆盖范围
- 跟拍技能前进轨迹
- 环绕跟拍敌群被击中
- 定格一个典型敌方消散瞬间

### 4.4 首领终结镜头

- 仰拍主技能锁定首领
- 特写终结前的极限压迫
- 命中一刻使用强冲击变焦或强透视
- 最后用远景或环绕展示彻底湮灭

## 五、材质与能量设计库

### 5.1 火系常用材质

- 赤金流火
- 暗红熔浆
- 金红火莲
- 黑焰边缘
- 焚毁后的焦灰余烬

### 5.2 雷系常用材质

- 紫电裂闪
- 蓝白高亮电核
- 黑紫雷云
- 电弧网状蔓延
- 雷击后的灼白炭痕

### 5.3 冰系常用材质

- 半透明冰晶
- 白蓝寒雾
- 镜面冰层
- 霜纹爬行
- 冰裂后的细碎晶屑

### 5.4 剑仙系常用材质

- 冷白剑光
- 青金剑辉
- 剑气流痕
- 阵纹剑环
- 斩开空间后的细长裂隙

## 六、反同质化组合公式

同一属性要避免只剩单一路数，可以按下面公式组合：

```text
主属性 + 设计母题 + 主体形态 + 清场方式 + 终结方式 + 环境遗留
```

例如火系：

- 火 + 神话法相 + 朱雀火翼 + 俯冲扫荡 + 中心镇压 + 满地焦痕
- 火 + 爆燃毁灭 + 炎爆核心 + 正面横推 + 巨型爆燃球终结 + 火山裂地
- 火 + 唯美高级 + 火莲开合 + 花瓣吞没 + 中心爆燃处刑 + 漂浮火屑与红雾

例如雷系：

- 雷 + 天罚审判 + 雷云光环 + 不规则轰落 + 雷兽光柱处刑 + 雷痕遍地
- 雷 + 极速贯杀 + 雷枪 / 雷刃 + 点杀型连锁 + 贯穿抹除 + 空间水纹震荡

---

## 七、绝对禁止项

1. 不要所有属性都写成“聚球 → 发射 → 爆炸”。
2. 不要所有终结都只是“敌人爆炸消失”。
3. 不要只换颜色，不换异象结构。
4. 不要只写抽象压迫，不写具体执行层。
5. 不要把热门国漫的大招视觉语言误写成具体 IP 招式复刻。

---

## 八、生成前速查

生成前快速问自己：

- 这条大招最强的视觉记忆点是什么？
- 它的技能主体是什么形态？
- 清场段和杀 boss 段是否明显升级？
- 环境有没有留下真实痕迹？
- 如果去掉颜色，这条大招是否仍有独特结构？

如果答不出来，说明这条还不够国漫级。
