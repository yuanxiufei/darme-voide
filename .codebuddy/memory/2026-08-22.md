## 排查 optimize-prompt「一直没反应」→ 根因是文本服务只有本地 Ollama
- 现象：`POST /api/v1/storyboards/1/optimize-prompt` 前端一直 pending。日志（`%TEMP%\drama-backend.log`）显示 `[AIConfig] active-config-selected serviceType=text configId=4 provider=openai model=qwen3:14b` → `[GpuManager] acquired`（acquire 正常，非死锁）→ 约 3 分钟后 `[TextGen] ERROR model-error error=The operation was aborted due to timeout` → `POST 400 186315ms`。
- 根因：数据库 `ai_service_configs` 里 **text 服务只有一条配置**（id=4「本地文本(本地)服务」，provider=openai，base_url=`http://localhost:11434`，model=`["qwen3:14b"]`，priority=85），**没有任何在线文本配置**。本地 qwen3:14b CPU 推理远超 60s 超时（fetchWithRetry 默认 3 次重试 → 186 秒才返回 400），前端看起来「没反应」。
- 影响范围：不止 optimize-prompt，所有走 `generateText` 的任务（动作建议、脚本续写、优化视频提示词等）都会挂 3 分钟超时。
- 解决：设置页添加在线文本模型配置（chatfire/火山/阿里百炼等）并设为激活或 priority 高于本地；文本任务走在线即可秒回。referrer policy `strict-origin-when-cross-origin` 为浏览器默认值、同源无影响，属干扰信息。
- **实测佐证**（用户追问「本地 qwen3:14b 可以用啊为啥调不通」）：直接 curl/Node fetch 调 `http://localhost:11434/v1/chat/completions` 让 qwen3:14b 生成「用一句话回复：你好」，**120 秒仍 AbortError 无任何返回**。Ollama 服务正常（`/api/tags` 返回 12 个模型，qwen3:14b 已下载）。结论：「可以用」是设置页「测试连接」只 ping 连通性（秒回），不等于推理够快；14B 在笔记本 CPU 上慢到无法实用，而 `generateText` 的 `fetchWithRetry` 超时仅 60s，必然超时。

## 全项目返回按钮导航逻辑排查 + 修复（本轮）
- 排查结论：共 5 个页面级返回按钮，均单次 `@click` 绑定、无重复绑定、无 form submit 重复触发；3 个用 `navigateTo('/xxx')` 明确目标、2 个用 `$router.back()` 依赖浏览历史。
- 核心问题：scene/character 详情页用 `$router.back()` 无兜底——用户直接刷新或新标签打开详情页时 history stack 无上一页，`back()` 失效/跳出应用（history 管理不当）。
- 修复（统一为「有历史则 back、无历史则兜底跳转」模式，5 文件）：
  - `pages/drama/[id]/scene/[sceneId].vue`、`character/[characterId].vue`：加 `const router = useRouter()` + `goBack()`（`window.history.state?.back` 有值→`router.back()`，否则 `router.push('/drama/${dramaId}')`）；模板 `$router.back()` → `@click="goBack"`。
  - `drama/[id]/index.vue`：`navigateTo('/')` → `goBack`（fallback `'/'`）。
  - `episode/[episodeNumber].vue`：`navigateTo('/drama/${dramaId}')` → `goBack`（fallback `/drama/${dramaId}`）。
  - `prompts.vue`：`back()` 内加同样 fallback（有历史 back、否则 navigateTo 项目页）。
- 判定依据：Vue Router 4 history.state 结构含 `back`（上一页路径，直接加载时为 null），`state.back` truthy 即可安全后退。
- lint：scene/character/drama/index/prompts 0 错误；episode 617 个报错均为既有 `ref(null)` 无类型标注历史债（`never` 类型 + any 隐式），与本次改动无关。未 git commit，等待审查 diff。
