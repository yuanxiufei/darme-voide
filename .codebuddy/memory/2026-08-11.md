## 发现并修复的 Bug

### 🔴 Bug 1: 视频重新生成时丢失 configId（严重）
**文件**: `backend/src/routes/videos.ts`
**问题**: `regenerate` 端点调用 `generateVideo()` 时未传递 `configId`，导致视频重新生成时无法使用正确的 AI 配置
**修复**: 添加 configId 获取逻辑，优先从请求体 → 从原记录关联的 episode 获取
**影响**: 视频重新生成功能可能使用错误的模型配置

### 🔴 Bug 2: Agent 模型回退逻辑失效（严重）
**文件**: `backend/src/agents/index.ts`
**问题**: 当 `dbConfig.model` 存在时，循环中每次都使用同一个 dbConfig.model，导致多模型 fallback 机制完全失效
**修复**: 将 dbConfig.model 作为首选模型插入 models 数组开头（去重），然后正常遍历
**影响**: Agent 文本生成无法享受多模型容错能力

## 性能优化

**文件**: `backend/src/shared/prompt-utils.ts`
