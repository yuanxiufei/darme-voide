## 修复多人对话拆分过度问题 (05:30)
- 问题：分镜台词中包含多角色对话（如"三娘：...姐姐：...小雪：..."），TTS生成时只取第一个角色
- 第一版修复用 split(/(?=(?:[^：:]*[：:]))/) 按冒号拆分，导致**每个标点/短句都被误拆成独立行**
- 最终方案：改用全局正则 `([^\n:：]{1,10}?)[:：]([^:：\n]{8,})` 匹配
  - 角色名限1~10字符
  - **冒号后必须 >= 8 字符且不含冒号**才算有效对话行
  - 拆分失败时 fallback 到旧的 parseDialogueForTTS 单人逻辑
- 后端 storyboards.ts + 前端 episode.vue 同步更新
- 多人模式 TTS：按角色分别调用不同音色 → ffmpeg concat 合并为一个 mp3

## 修复 Vue SFC 编译错误 - ref<T> 泛型与模板解析冲突 (当前)

### 根因
`<script setup>` 中的 `ref<string[]>([])` / `ref<any[]>([])` 等 TypeScript 泛型语法，其中 `<>` 被 Vue SFC 编译器误识别为 HTML 标签边界，导致 `<template>` 段解析混乱，报 `Unexpected token` 错误。

### 修复方案
双管齐下：1) 所有泛型 ref 改为类型断言语法；2) 显式加 `lang="ts"`

### 修复范围（5 文件，29 处）
| 文件 | 修复项 |
|------|--------|
| `characters.vue` | `ref<string[]>([])`×3, `ref<any[]>([])`×2, `ref<number[]>([])`×1, `ref<any>(null)`×1, `ref<number\|null>(null)`×1 + `<script setup lang="ts">` |
| `scenes.vue` | 同上模式 8 项 |
| `weapons.vue` | `ref<string[]>([])`×2, `ref<any[]>([])`×1, `ref<number[]>([])`×1, `ref<any>(null)`×1 + `lang="ts"` |
| `costumes.vue` | `ref<string[]>([])`×3, `ref<any[]>([])`×1, `ref<number[]>([])`×1, `ref<any>(null)`×1 + `lang="ts"` |
| `index.vue` | `ref<any[]>([])`×1 + `lang="ts"` |

### 转换规则
- `ref<string[]>([])` → `ref([] as string[])`
- `ref<any[]>([])` → `ref([] as any[])`
- `ref<number[]>([])` → `ref([] as number[])`
- `ref<any>(null)` → `ref(null as any)`
- `ref<number | null>(null)` → `ref(null as number | null)`
- `<script setup>` → `<script setup lang="ts">`

### 验证
- 全项目 `.vue` 文件中 `ref<` 模式清零（仅 `useAgent.ts` 保留1处，纯TS文件不走SFC编译器）
- 5 个 library 页面 HTTP 200 全部通过
