- ⚠️ 病灶：Viterbi 写成「对每个 `end`，把 `end-maxTokenLen…end` 的起点**重新扫一遍**前缀树」✗

### `Split`（**五种 behavior** ✓ 规则逐例实测 ✓）
对 `pattern` 匹配做原子化（匹配段 / 非匹配段 ✓）+ 五种贴法 ✓：
- `isolated`：`ab 12 cd` ⇒ `['ab ','12',' cd']` ✓（⚠️ **空白不特殊处理** ✗ —— 与 `Punctuation` 那套不同 ✓）；
- `contiguous`：相邻匹配合成一片（`ab12cd` ⇒ `['ab','12','cd']` ✓）；
- `removed`：只留非空段 ✓；
- `merged_with_previous`：`['ab1','2','cd']` ✓ —— ⚠️ 判据是「**前一片以匹配结尾**」✗ 不是「前一片存在」✓；
- `merged_with_next`：`['ab','1','2cd']` ✓ —— ⚠️ 匹配后面**紧跟匹配**（或到串尾）⇒ 它**自成一片** ✓；
- `invert` ✓ 匹配补集；`{"String": …}` ✓ 按字面切 ✓。

### `FixedLength` ✓
按**字符**数切（`'中文测试x'` ⇒ `['中文测','试x']` ✓ 不是按字节 ✗）；空串 ⇒ 无片 ✓；`length ≤ 0` ⇒ 拒绝 ✓。

### ⚠️ 两类**明确拒绝**（宁可回退参考实现 ✓ 也不静默按错的语义切 ✗）
