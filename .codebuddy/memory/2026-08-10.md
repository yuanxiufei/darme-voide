# 2026-08-10 工作日志

## 全部流程阶段实现多模型自动 fallback

### 背景
此前模型配置中的 `model` 字段存储为 JSON 数组，但实际只用 `models[0]`，后续模型被忽略。用户要求所有流程都要有模型切换能力。

### 修改的文件

#### 1. `services/ai.ts` + `adapters/types.ts` — 接口扩展
- `AIConfig` 接口新增 `models: string[]` 字段（存储全部可用模型，按优先级排序）
- `getActiveConfig()` / `getConfigById()` 返回完整 `models` 数组
- 保留 `model` 字段（指向首模型）维持向后兼容

#### 2. `services/image-generation.ts` — 图片生成 fallback
- `processImageGeneration` 改为 for 循环遍历 `config.models`
- 每次切换模型时：更新 DB model 字段 → 释放旧 GPU 租约 → 获取新 GPU 租约
- 预加载记录和参考图（所有模型尝试共享）
- `pollImageTask` 改为抛错误而非静默更新 DB（由外层 retry 循环捕获）
- `await pollImageTask` 替代原来的 fire-and-forget

#### 3. `services/video-generation.ts` — 视频生成 fallback
- 同图片生成的改造模式
- 预加载参考图 URL（所有模型尝试共享）
- Vidu 等无轮询端点：fetch 成功后返回（依赖 Webhook），失败则 fallback

#### 4. `services/tts-generation.ts` — TTS 语音合成 fallback
- for 循环遍历 `config.models`，失败后 `finally` 释放 GPU 租约，下一次迭代重新获取
- 所有模型均失败时才 throw

#### 5. `agents/index.ts` — 文本 Agent fallback
- 新增 `createAgentTools()` 导出，供 `createAgent` 和 `runAgentWithRetry` 共用
- 新增 `runAgentWithRetry()` — 遍历 `textConfig.models`，每次失败后重新创建 Agent + 新 model，全部失败才 throw
- 新增 `logTaskError` 导入

#### 6. `routes/agent.ts` — 所有 Agent 调用改用 runAgentWithRetry
- 移除 `normalizeToolName` / `normalizeToolResult`（已内聚到 runAgentWithRetry 内部）
- `createAgent + agent.generate` → `runAgentWithRetry`

#### 7. `routes/grid.ts` — 宫格图提示词 Agent 改用 runAgentWithRetry
- `tryAgentGridPrompt` 内部 `createAgent → agent.generate` → `runAgentWithRetry`
- 导入了 runAgentWithRetry 替代 createAgent

### fallback 行为
```
模型1 失败 → 释放 GPU(模型1) → 获取 GPU(模型2) → 模型2 成功 ✓
模型1 失败 → ... → 模型N 失败 → 全部失败，标记 failed
```

## Skill 设计模板归档

将用户提供的"仙宫导览风格视频" Skill 保存为 `skills/xian-gong-skill-template.md`，包含：
- 完整 Skill 定义（planner / storyboard_designer / media_generator / write_the_prompt / video_assembler）
- 模板结构分析（设计模式提炼）
- 复用指导（骨架保留、领域替换）

**可作为未来 Skill 设计的参考模板。**

核心设计模式提炼：
1. **阶段化流水线**：5阶段按序执行，阶段间有闸门，不一次贯通
2. **Variation Card**：6步递进式规则（家族→构图→奇观→科幻→雅事→去重）
3. **去重检查表**：跨镜头多样性约束（空间类型+前景框架+主奇观 二同重选）
4. **Style Lock**：逐字固定的风格描述块，保证视觉一致性
5. **三层空间公式**：前景25-40%/中景20-30%/远景35-50% 的结构化构图
6. **质量闸门**：16项首帧检 + 5图去重检，任一项失败即回溯
7. **负向提示词**：生图70+项 / 视频40+项 完整禁止清单
8. **配比约束**：对称≤2张/骑马≤1张/醒目圆环≤2张 等柔性排他规则
