## 项目约定：PowerShell 提交中文 commit message 需用 -F 文件方式
Windows PowerShell 下 `git commit -m "中文"` 会把中文按 GBK 编码传给 git，导致 commit message 乱码（已踩坑）。正确做法：用 `write_to_file` 写 UTF-8 的临时 message 文件，再 `git commit -F 文件`（或 `--amend -F`）。临时文件用完删除。此约定适用于本项目所有含中文的 commit message。
