## 修正 doctor 的 CUDA 检测（用户质疑「nvcc 未找到」）
- 用户质疑 doctor 报「CUDA nvcc 未找到」不对 → 实测澄清：本机**有 GPU + CUDA runtime，但确无 nvcc**（CUDA Toolkit）。
- 实测：RTX A5000（22GiB）、PyTorch 2.13.0+cu130 `cuda_available=True`；但 `CUDA_PATH` 空、Toolkit 标准目录空、PATH 无 nvcc。
- 根因概念：PyTorch 的 cu130 pip 包只带 CUDA runtime+cudnn，不带 nvcc 编译器；「torch.cuda 可用」≠「能源码编译 CUDA 版 sd.cpp」。
- 改进 `sd_h3_pipeline.py` doctor：新增 `detect_gpus()`（nvidia-smi）/`detect_cuda_toolkit()`（PATH+标准目录兜底）/`detect_torch_cuda()`，拆成「GPU / PyTorch CUDA / CUDA Toolkit(nvcc)」三段，提示语改为「缺 CUDA Toolkit 无法编译 CUDA 版 sd.cpp」。验证 `py_compile`+`doctor` 通过。
