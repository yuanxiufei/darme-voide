## 〇、三类视觉稿共用的底层规则（必须先记）

### 0.1 彩色箭头轨迹统一图例（红/蓝/绿/橙/紫）

凡「手绘风格分镜稿」（白模/草图）一律用下列五色箭头标注引导线，原文照录：

- **红色：机位运动箭头 / 构图箭头**——标注摄像机的运动轨迹、拍摄角度和构图变化。
- **蓝色：角色动作轨迹箭头**——指示角色 / 物体的移动路线、肢体运动方向和幅度。
- **绿色：互动关系箭头**——标注射击、投掷、攻击等物体的飞行轨迹，以及角色间的互动方向。
- **橙色：效果 / 冲击力箭头**——指示爆炸、碰撞、命中点的受力方向和影响范围。
- **紫色：音效 / 标注引导箭头**——指向需要添加音效、文字说明或特效备注的位置。
- **X：固定点 / 关键站位**。
- 框外写下镜头编号和简易焦段（如 50mm / 广角）。
- 用简单透视框（画个带消失点的方框）大致表明墙角、走廊还是室内一角，体现空间感。

### 0.2 标注元素隔离铁律（画线/走位类，防死循环，原文表述必须保留）

> 视频生成的时候请不要出现红色 / 蓝色 / 绿色的点，也不要出现箭头。
> 重点：生成的视频不能带任何标注，字母，文字，箭头等。线条只作为路径参考。
> 【重点、重点，必须执行的规则】生成的视频一定不能有红色引导图线、圆圈、标记、字母。

配套「戏内身份判定」表述：

> @图片1 = 拍摄场景，@图片2 = 拍摄指导图，拍摄指导图中的红色（或蓝色）带箭头线条代表摄像头的移动轨迹（请注意，视频生成的时候请不要出现红色线条，箭头、圆圈、以及字母）。

## 三、画线玩法（来源：《【图片】-image2-画线玩法全解析》）

> 总范式：**参考图 1 = 拍摄场景（成图/实拍），参考图 2 = 拍摄指导图（线稿）**，指导图上的红/蓝带箭头线条 = 摄像头移动轨迹。视频成片中**绝不出现**线条、箭头、圆圈、字母（见 0.2 标注隔离铁律）。FPV 第一人称、无断点一镜到底为主。

> 实操经验（原文）：
> - 第一视角那段：**参考图 >2 张时非常容易出错导致需要抽卡**，所以示例视频其实是 2 条视频拼接在一起的。
> - 单人物展示那段：**绕到背后的动作偶尔出错导致需要抽卡，建议避开高峰期使用**。
> - FPV 穿梭飞行：非常稳。
> - 场景中多人物展示：非常稳；image2 运镜及场景一致性中「群像展示」部分也是这么操作的（与《image2故事板与一致性库》八、群像同源）。

## 四、应用规则

1. **白模 vs 草图选择**：要「动作张力 + 快速定镜头节奏」且后续要转正式视频 → 白模黏土（AO、黑底白字、宫格不编号）；要「走位/路线/生产施工」且强调空间关系 → 铅笔草图（火柴人/抽象人形 + 五色箭头 + X + 焦段）。脸部要演出戏时用「脸部留白十字定位、不画五官」版本。
2. **画线玩法**：场景本身已经够清晰（颜色不复杂）就直接在成图上画红蓝线，不必转铅笔稿（与《image2故事板与一致性库》八、大场景操作步骤同源）；需要明确空间骨架时再先出线稿/工程图。
3. **标注隔离铁律**：所有画线/走位提示词必须重复写入「视频不出现线条/箭头/圆圈/字母/标记」，并按戏内身份写清「图片1=拍摄场景、图片2=拍摄指导图」，防止标注被渲染进成片、防止模型把引导线当画面内容反复生成（防死循环）。
4. **抽卡提示**：参考图超过 2 张、或要求「绕到人物背后」时易出错，需抽卡/避开高峰；可拆成多段视频再拼接。
5. **画质尾缀**：白模与上色统一拼 0.3 英文尾缀；视频段统一拼「3D CG国漫 + UE5 + PBR + 体积光 + 8K + 无穿模/崩坏/跳帧 + 时序匹配 + 动态模糊 + 光影统一 + 镜头连贯」参数串。
6. **组合**：白模分镜稿/草图分镜稿 → 用 1.1/1.2/2.x 的「@是故事版」视频提示词转视频；画线稿 → 用第三章范式转视频；与《image2故事板与一致性库》的角色版/道具版/电影制作板配套使用。
