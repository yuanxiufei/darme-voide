# 真人感去AI味提示词库（UGC/带货/手机实拍分支）

> 用途：08 CINEDANCE 生成 UGC 口播、真人带货、竖屏种草、剧情短片真人镜头时，专治「一眼AI」和「一眼广告」。
> 与《真实质感提示词库》分工：那份管**电影感**（电影光、骨相、焦段），本份管**手机实拍感**（混合光、生活杂物、毛孔、手持晃动）。真人短剧/带货/口播优先读本份；古装仙侠/电影镜头仍用《真实质感提示词库》。
> 吸收自 seedance-real-selling-video 实战方法论，已中文化。

## 一、核心矛盾

AI 真人视频两个死穴：
- **一眼AI**：塑料皮肤、崩手多指、眼神飘、口型对不上、画面冒乱码文字。
- **一眼广告**：影棚三点光、干净台面、完美居中构图、过度精致。

解法是**反向优化**：不追求精致，主动制造真实世界的不完美。欠指定的提示词，模型一定拿通用默认值填——那就是AI味来源。

## 二、四大真实感支柱（真人/UGC镜头必带）

### 支柱1 · 光线：混合光，别用影棚光
必须写清三件事：**色温 + 方向 + 质感**。
- 通用灯效（三点布光/柔光箱/均匀打亮）是最大AI味来源，**禁用**。
- 优先级：窗边自然光（纪实感最强）＞ 画面里能看见的实光源（台灯/手机屏/屏幕反光）＞ 蓝调时刻/阴天漫射 ＞ 三点布光（最后选，偏制作感）。
- 写法示例：「光从左侧窗户进来冷白日光，右侧一盏暖黄顶灯，色温自然冲突，脸上明暗不均，不打补光」。

### 支柱2 · 场景：主动塞「用过的痕迹」
「干净背景」是死刑。关键是用过的痕迹，不是摆好的道具：
- 假（摆拍感）：整齐叠放的毛巾、未拆封包装盒、空咖啡杯、摆正的手机、空白墙面。
- 真（生活感）：揉皱随手放的纸巾、拆一半胶带翘起的快递袋、喝一半杯壁有水痕的咖啡杯、屏幕朝下扣着还缠着充电线、贴了便利贴有电线的墙。
- 写法：逐件列出，例「半喝剩带杯渍的咖啡、拆开一半的快递袋、揉皱的纸巾、缠在一起的充电线」。

### 支柱3 · 皮肤：主动要毛孔和瑕疵
- 写法：「皮肤有自然纹理、可见毛孔、脸颊鼻翼轻微泛红、眼下淡青、几颗小痣，不要过度磨皮，不要塑料陶瓷感」。
- 同时给正向：「纪实写实风格，不要AI绘画质感，不要3D渲染感，不要插画感」。

### 支柱4 · 镜头：开头就写手机拍摄
四要素缺一不可，放在提示词开头：
- 「手机手持拍摄，带自然轻微晃动感，轻微动态模糊，构图略偏不居中，业余家庭录像质感，竖屏9:16」。
- 可叠加：轻微镜头脏污、自动曝光轻微调整、轻微果冻效应。
- 原理：完美无瑕本身就是AI特征，一点镜头脏、光晕、呼吸感显著提升真实度。

## 三、核心补丁语句库（默认全加，别等出问题才补）

| AI痕迹 | 中文补丁句（直接用） |
|---|---|
| 塑料/过度磨皮 | 皮肤有自然纹理、可见毛孔和细微瑕疵，不是光滑塑料感，不要过度磨皮 |
| AI绘画玻璃感 | 纪实写实风格贯穿全片，不要AI绘画质感，不要3D渲染感，不要插画感 |
| 崩手/多指/手粘连 | 手部解剖自然，五指完整、比例正确，手部动作简单（握、放、推近），不做翻转/精细操作 |
| 眼神飘/抖动 | 眼神稳定聚焦，无闪烁无抖动 |
| 中文口型漂移 | 口型严格对台词，不说话时嘴闭合静止，对准每个中文音节 |
| 背景段间漂移 | 与上一段是同一个房间同一处场景 |

## 四、负面轰炸（治乱码文字/logo/广告感）

建议把排除类描述集中列出多条（6条以上），并在镜头描述处和提示词结尾各写一次，效果更稳。

去广告感负向词：影棚布光、柔光箱、三点布光、过度磨皮、完美无瑕、对称居中构图、干净背景、极简布景、3D渲染、过度饱和、AI绘画感、塑料皮肤。

去文字/logo负向词：不要文字、不要汉字、不要英文字、不要数字、不要logo、不要UI元素、不要可识别符号。

**配套正向替代**：每条重要的「不要」都要配一句「要什么」，否则模型用变体填回来。例：不要浮字卡片 → 柔和发光的半透明矩形、紫粉蓝渐变、无可识别图案。

## 五、三段锁定（治跨镜头崩脸，多镜头真人片必用）

把角色/场景/声音提到镜头脚本**之前**成独立区块，模型把置顶区块当全局恒真事实：

```
【角色锁定】姓名：年龄/体型/发型/眼镜/服装/配饰，所有镜头同一套造型；皮肤有毛孔自然纹理，不要塑料感。
【场景锁定】环境+光源方向+色温+关键道具+空间布局，所有镜头同一场景。
【声音锁定】语言/口音/年龄段/音色；口型同步，不说话时嘴静止。
```
系列内容把这三块存成可复用头部，第二条视频直接复用同一锁定块，人设自动延续。

## 六、带货/口播脚本结构（15–25秒四段式）

| 段落 | 时长 | 写法 |
|---|---|---|
| 钩子 | 前2秒 | 具体数字/反常识/直接喊人群/从动作中段切入 |
| 痛点 | 3–8秒 | 说场景不说形容词：「每次挤地铁妆就花」胜过「持妆不好」 |
| 展示 | 8–18秒 | 手真实拿起产品，可见效果变化 |
| 行动 | 最后3秒 | 一句话说清怎么买 |

- 口播句子4–12字，长句必然拉低口型准确率；允许口语碎词（就是/其实/你懂吧）；不要排比押韵（那是广告腔）；语速偏慢。
- 运镜要给量：写时长（3秒慢推近）、幅度（轻微1.05倍变焦）、时机（第1秒开始推），别只写「推近」。

## 七、症状→修复对照表

| 症状 | 根因 | 修法 |
|---|---|---|
| 一眼广告片 | 棚光+干净台面+完美构图 | 换混合光/单一光源+塞生活杂物+构图偏心+声明手机拍摄 |
| 皮肤像塑料/玻璃 | 模型默认美颜审美 | 正向写毛孔瑕疵+拒绝AI绘画感，两句都要 |
| 脸上没阴影 | 均匀受光无来源 | 混合光色温冲突，或单一光源+不打补光 |
| 背景太空像影棚 | 欠指定 | 逐件列带使用痕迹的杂物+负向词加干净背景 |
| 镜头间人脸变了 | 锁定埋在镜头里 | 角色锁定提到置顶独立区块+结尾重申 |
| 手指数量不对 | 已知弱项 | 加手部解剖句+改用简单手势 |
| 口型对不上（中文） | 模型按英文音素 | 指定普通话+音节级同步+放慢语速+缩短句子 |
| 画面冒乱码文字/logo | 模型爱填细节 | 负面轰炸6条以上，镜头块与结尾各一遍 |
| 拼接处画面跳 | 段间背景漂移 | 加「同一段落同一房间」+转场从0.4秒加到0.6–0.8秒 |
| 真需要屏幕文字 | 模型写不对 | 外部做好截图当首帧图喂入，或后期叠加，别指望模型写 |

1. **什么时候用**：UGC口播、真人带货、竖屏种草、真人剧情短片、手机实拍质感镜头；古装/仙侠/电影感镜头仍用《真实质感提示词库》。
2. **08 CINEDANCE**：真人镜头提示词按「四段式支柱开头 → 三段锁定 → 镜头块 → 结尾质量指令+负面轰炸」顺序组装；遵守镜头术语编译规则，运镜仍写专业术语。
