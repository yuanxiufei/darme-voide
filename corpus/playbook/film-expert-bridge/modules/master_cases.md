# 大师案例锚：按场景类型

案例库来源：近百年获奖电影分镜总目录（130+部，摄影/分镜/视觉类奖项收录标准）。

**引用铁律：只引用本库内的片名和手法，禁止编造。** 引用格式＝片名＋摄影师＋具体手法＋怎么用到用户这套分镜（可选采纳）。

## 争吵 / 对峙

- **《教父》**（Gordon Willis）：顶光压眼窝、脸半藏阴影——权力压迫的布光教科书。对峙戏给强势方顶光+阴影，弱势方平光。
- **《十二怒汉》**：单一空间纯对话张力——不靠动作，靠景别逐步收紧和切点。吵架戏不加动作也成立，收紧景别就够。

## 追逐 / 紧张移动

- **《谍影重重3》**（手持纪实风）：手持+快速切，但空间方位永远清晰。追逐前先给一镜全景建空间，观众才晕得起劲、不晕方向。
- **《疯狂的麦克斯：狂暴之路》**（John Seale）：橙蓝对冲色调+高速追拍。追逐戏的配色和机器速度感可以直接抄。

## 告白 / 暧昧 / 情感流动

- **《花样年华》**（杜可风）：慢镜+走廊纵深+红色调+框中框（门窗框住人物）。暧昧＝框中框＋慢镜；相思拍「错过」，不拍「拥抱」。
- **《爱在黎明破晓前》**：走路中的长镜对话，中景跟移+自然光。情感戏最省钱拍法：跟移长镜，让两人边走边说。

## 死亡 / 告别 / 丧失

- **《辛德勒的名单》**（Janusz Kamiński）：黑白全片中唯一的红衣女孩——用色彩孤立强调「逝去的重量」。重要告别给一个光线或色彩的突变。
- **《无人知晓》**（是枝裕和）：儿童低机位+自然光+季节光影。弱者视角＝低机位；不拍哭喊，拍日常里缺了一个人。

## 相遇 / 重逢

- **《罗马》**（Alfonso Cuarón）：深焦全景调度，人物在前后景各自活动。重逢先给大空间全景，让人物慢慢走进彼此——空间本身就是仪式感。

## 孤独 / 疏离

- **《出租车司机》**（Michael Chapman）：霓虹雨夜倒影+POV主观镜头。孤独用第一人称视角拍空荡的环境。
- **《东京物语》**（小津安二郎）：榻榻米低机位+空镜转场（枕镜）。疏离＝空镜（没人的空间）+固定机位，让「没有」自己说话。

## 动作爆发 / 对决顶点

- **《黑客帝国》**（Bill Pope）：子弹时间（时间冻结+环绕）。动作顶点的极端强调；AI视频用「缓慢的环绕运动」近似。
- **《1917》**（Roger Deakins）：伪一镜到底。连贯动作段落少切多移，紧张感来自「不给观众喘息的剪辑点」。

## 恐怖 / 不安

- **《异形》**（Derek Vanlint）：幽闭空间+烟雾+看不清的威胁。恐怖＝不展示（暗示永远大于展示）。
- **《第三人》**（Robert Krasker）：荷兰角倾斜+高反差明暗。不安感直接用荷兰角物理化。

## 权力 / 仪式 / 压迫

- **《大红灯笼高高挂》**（赵非）：封闭宅院对称构图+俯拍几何。权力的视觉＝对称＋俯拍，人被建筑规训。
- **《英雄》**（杜可风）：色彩分区叙事（红蓝白绿各讲一段）。分段故事用色块区分，观众不用字幕就知道时空变了。

## 回忆 / 闪回 / 心理

- **《公民凯恩》**（Gregg Toland）：深焦摄影，前后景全部清晰。回忆段落给深焦，让时间层次共存于一个画面。
- **《镜子》**（塔可夫斯基）：自然元素（雨/火/风）+黑白彩色交替。心理状态不用台词，用元素和色调切换表达。
