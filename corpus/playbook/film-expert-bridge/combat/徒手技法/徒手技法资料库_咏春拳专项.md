## 0. 武学导览卡

- **一句话理解**：咏春拳不是“只会日字冲拳”，而是以中线、短桥、黏桥听劲、同步攻防、寸劲短打为核心的贴身快打体系；本系统默认以叶问系为主轴，其余派系只在不冲突时补短板。
- **主轴定位**：叶问系咏春为默认基础：标准二字拑羊马、中线固守、摊膀伏三手、黐手、寻桥小幅变线、标指插空、寸拳短打。
- **补强原则**：阮奇山岑能系补长桥拉扯、跪步靠身和六点半棍；姚才蛇形补腕部盘旋缠绕和狭小内门巧劲；古劳偏身补侧身蝴蝶掌和侧门绕袭；彭南永春补洪拳长桥、大开起伏和远近强攻。
- **战斗气质**：中正、干净、短促、贴身、攻守同期、快节奏、控制桥路、寸劲爆发；补派后可增加舒展长桥、蛇形缠绕、侧门绕袭或外放长桥强攻，但不能破坏叶问主轴。
- **主战距离**：贴身内门短桥为核心，中桥牵制为辅；需要补短板时可临时加入长桥拉扯、侧门绕袭或外放控距。
- **适合角色气质**：极速短打型、冷静精准型、小体型近身破招型、中线压制型、无多余动作的干净武者。
- **画面识别点**：二字拑羊马、手肘贴肋、摊膀伏、黐手、日字/中线寸冲、伏手压腕、低脚踩踏、标指插空、木人桩式短连击。
- **15秒适配**：适合高密度短桥连打，采用“探桥→寸冲→封桥→标指/低脚→连环寸拳终结”，尽量避免完整黐手和完整木人桩长流程。
- **30秒适配**：适合完整展示摊膀伏、寻桥、黐手、标指、低脚、木人桩连击，以及必要时加入1个补强派系解决距离或角度问题。
- **不适合方向**：大开翻腾腿法、泰拳式膝肘硬撞、太极长线柔化、洪拳大开桥手主导、巴西战舞空翻游走。

## 1. 统一总定位

本专项整合五类咏春/永春资料：

1. **叶问系咏春**：默认主轴，标准化最强，中线短桥、摊膀伏、黐手、寸劲、木人桩流程完整。
2. **阮奇山系岑能广州咏春**：长桥外放、跪步/箭步、整体沉劲、靠身撞击、六点半棍核心。
3. **姚才蛇形咏春**：腕部蛇形盘旋缠绕、轻浮窄马、狭小内门巧劲穿刺。
4. **古劳偏身咏春**：45度侧身偏马、蝴蝶掌开合、大步侧向绕袭、三点半短棍。
5. **彭南永春**：文字定名“永春”，洪拳长桥基底、高低起伏大马、大开外放长桥、远近强攻。

### 1.1 总调用铁律：叶问系为主，其余派系补短板

默认生成“咏春拳”时，不要五派平均乱炖。系统必须先使用叶问系建立身份，再根据角色或战斗问题选择一个补强方向。

```text
叶问系主轴：中线、短桥、摊膀伏、黐手、寸劲、标指、低脚、木人桩短连击
补强派系：只补叶问系短板，不反客为主
```

### 1.2 可补的短板

| 叶问系短板 | 可用补强 | 使用边界 |
|---|---|---|
| 正面站位多，侧身应变偏弱 | 古劳偏身咏春 | 只用于侧门绕袭和蝴蝶掌开合，不把角色全改成偏身派 |
| 中长桥拉扯不足 | 阮奇山岑能 / 彭南永春 | 阮奇山偏长桥+棍+靠身，彭南偏洪式长桥强攻；一次只选一个方向 |
| 对狭小空间细腻缠绕不足 | 姚才蛇形咏春 | 只补腕部盘旋缠绕，不替换叶问摊膀伏为全程蛇形 |
| 对远距离游走缺乏控场 | 阮奇山六点半棍 / 彭南长桥 | 有器械需求用阮奇山棍；徒手强攻用彭南长桥 |
| 终结画面容易单一寸拳 | 标指、低脚、木人桩短连击，或少量补派终结 | 终结仍要服务叶问主轴的短桥控制 |

### 1.3 禁止乱炖

- 禁止同一段同时出现叶问二字马、古劳永久侧身、阮奇山宽幅起伏、姚才轻浮窄马、彭南高低大马全部混用。
- 禁止一边写叶问“手肘贴肋中线固守”，一边写阮奇山“长桥外放大幅拉扯”却不给切换原因。
- 禁止把姚才蛇形缠绕写成太极云手或柔术关节锁教学。
- 禁止把古劳蝴蝶掌写成叶问摊膀伏或八卦绕圈。
- 禁止把彭南永春误写成“咏春”，正式称呼要保留“永春”字面差异；但系统归入咏春大类专项。
- 禁止真实危险教学：咽喉、眼、关节毁伤等目标在执行层净化为面门外侧、下颌线、胸口、肩颈线、肋侧、手腕控制、重心破坏。

## 2. 五派风格模块速览

### 2.1 叶问系咏春｜默认主轴

- **核心标签**：二字拑羊马、中线固守、摊膀伏、黐手、寸冲、标指、低脚、木人桩。
- **气质**：中正平稳、短促干净、攻守同期、内门短桥、节奏清晰。
- **距离**：贴身内门短桥为主，中桥辅助牵制。
- **用法**：默认咏春身份；15秒和30秒都必须优先保留。
- **不能丢的画面**：手肘贴肋、桥手接触、寸劲接触点、同步格挡反击、伏手锁桥。

### 2.2 阮奇山系岑能广州咏春｜长桥与棍法补强

- **核心标签**：宽幅起伏沉架、长摊长膀、跪步/箭步、靠身整体沉劲、六点半棍。
- **气质**：舒展、厚重、外放、拉扯、器械控场。
- **补强用途**：当叶问系需要中长桥、远距牵制、棍法控场或厚重靠身时调用。
- **禁区**：不能把叶问二字马永久改成宽架；不能无器械需求强塞六点半棍。

### 2.3 姚才蛇形咏春｜腕部缠绕巧劲补强

- **核心标签**：蛇形扭腕、盘旋摊膀伏、多层缠绕、轻浮窄马、狭小内门穿刺。
- **气质**：灵动、细腻、贴身缠绕、短促穿刺、巧劲卸力。
- **补强用途**：当叶问系需要更细的贴身腕部缠绕、狭小空间封桥、连续短穿刺时调用。
- **禁区**：不能把叶问平直摊膀伏完全替换成蛇形；不能写成长桥外放或侧身蝴蝶掌。

### 2.4 古劳偏身咏春｜侧身绕袭补强

- **核心标签**：45度侧身偏马、蝴蝶掌开合、大步侧跨、侧门绕袭、三点半短棍。
- **气质**：侧闪、绕袭、开合、侧门抢空、民间古传。
- **补强用途**：当叶问系正面中线被压制，需要侧身变角、侧门打击、短棍缠绕时调用。
- **禁区**：不能把全场都写成古劳偏身，除非用户明确点名古劳；不能出现叶问正身和古劳永久偏身无因果切换。

### 2.5 彭南永春｜洪式长桥强攻补强

- **核心标签**：永春、洪拳长桥、高低起伏大马、长扬外放、大步长勾、远近强攻。
- **气质**：大开大合、刚猛、迅猛、远近无缝、长桥外放。
- **补强用途**：当叶问系需要远距离长桥强攻、洪拳式外放压迫、大步突进时调用。
- **禁区**：不能写成叶问内敛寸劲；不能与阮奇山六点半棍混成一个器械主轴。

## 5. 统一动态组合原则

### 5.1 默认生成规则

如果用户只说“咏春拳”，默认组合为：

```text
叶问系 80%：二字马、中线、摊膀伏、寸冲、伏手、黐手、标指、低脚、木人桩短连击
补强派系 20%以内：只选一个派系补短板
```

### 5.2 按战斗问题选择补强派系

| 场景问题 | 推荐补强 | 示例组合 |
|---|---|---|
| 对手远距离游走，叶问短桥够不到 | 阮奇山或彭南 | 叶问起架→长摊/长扬拉桥→回到寸拳封桥 |
| 对手力量大，正面压进 | 古劳或阮奇山 | 膀手同步寸冲→侧跨绕袭或跪步靠身 |
| 对手桥手复杂，近身纠缠 | 姚才 | 黐手→蛇形缠绕伏手→寸拳/标指 |
| 需要器械咏春 | 阮奇山六点半棍或古劳三点半棍 | 六点半棍远控 / 三点半短棍贴身侧扫 |
| 需要狂暴远近强攻 | 彭南永春 | 长扬拉扯→大步长勾→回到短桥寸冲 |

### 5.3 派系切换必须有因果

合格切换示例：

```text
叶问系摊手寸冲被对手长臂压住 → 小幅寻桥仍够不到 → 借阮奇山长摊外放拉桥打开距离 → 箭步长勾逼近 → 重新回叶问伏手锁桥寸拳压制
```

```text
叶问正面中线被重拳压迫 → 膀手分流同步寸冲受阻 → 古劳式单次侧跨抢外侧 → 下合蝴蝶掌击侧肋 → 回到叶问黐手寸拳终结
```

```text
叶问黐手中对手试图抽桥 → 姚才蛇形盘旋吸附手腕 → 双层缠绕伏手锁桥 → 叶问中线寸冲与标指插空
```

不合格切换：

```text
二字马起手 → 立刻全程侧身蝴蝶掌 → 又突然六点半棍 → 再蛇形缠绕 → 最后洪拳长摆
```

原因：无距离逻辑，无对手反应触发，派系身份混乱。

## 6. 招式功能归类

### 6.1 适合起手

- 叶问：二字拑羊中正起架、摊手中线探桥
- 阮奇山：宽幅起伏沉架、长摊外放探桥（补中长桥）
- 姚才：轻浮窄马蛇形起架（点名姚才时）
- 古劳：45度侧身偏架（需要侧闪时）
- 彭南：高低起伏大开永春架（点名永春/长桥强攻时）

### 6.2 适合试探

- 摊手中线探桥
- 中线直线寸冲拳
- 短时黐手听劲
- 蛇形盘旋摊手
- 长摊/长扬外放探桥

### 6.3 适合破重心

- 伏手压腕封桥
- 低位内门踩踏
- 寻桥侧移勾冲
- 蛇形双层缠绕伏手
- 古劳侧跨下合掌
- 彭南大步低位踩踏

### 6.4 适合压制

- 中线寸冲短连击
- 膀手同步寸冲
- 短时黐手接寸拳
- 姚才连环短寸拳
- 古劳上下蝴蝶掌开合
- 阮奇山跪步靠身（仅补强）

### 6.5 适合空间变化

- 叶问寻桥小幅侧移
- 古劳大开幅侧跨绕袭
- 阮奇山箭步/跪步突进
- 彭南大步远近切换
- 姚才碎步微调（只在贴身区间）

### 6.6 适合终结前承接

- 伏手锁桥接标指
- 短时黐手听劲接寸冲
- 低脚踩踏限制下盘
- 姚才蛇形缠绕标指
- 古劳侧门肩窝勾掌
- 阮奇山短肘/靠身或彭南长勾（按补强方向）

### 6.7 适合终结

- 叶问木人桩式连环寸冲压缩版
- 叶问标指插空 + 连续寸冲KO
- 伏手锁桥 + 低脚破根 + 寸拳收尾
- 点名补派时可用：阮奇山棍扫失衡、古劳棍掌侧摔、彭南长桥重击；但默认仍以叶问短桥寸劲终结为优先。

## 7. 15秒调用规则

### 7.1 15秒核心原则

15秒咏春必须是短桥高密度，不是30秒门派展示压缩版。默认只保留叶问系主轴，补派最多加入一个明确功能点。

推荐节奏：

```text
0-1s：近景极推，二字马/摊手已经进入探桥动作，不能站桩摆架
1-3s：摊手开中线 + 寸冲命中 + 伏手封桥，形成第一次接触和受击反馈
3-6s：膀手同步寸冲 / 黐手短循环 / 低脚限制位移，完成高速短桥攻防
6-9s：按需要加入一个补强点：蛇形缠绕、侧跨绕袭、长桥拉桥或寻桥变线
9-12s：终结前承接必须继续命中或封桥，不能只蓄力/只摆架
12-15s：标指插空 + 连环寸冲 / 木人桩式短连击压缩终结
```

### 7.2 15秒推荐动作池

- 必选：摊手中线探桥、中线寸冲、伏手压腕、膀手同步寸冲。
- 强推荐：低位内门踩踏、近身标指、木人桩式短连击压缩版。
- 可选补强：姚才蛇形缠绕1次、古劳侧跨1次、阮奇山长摊或彭南长扬1次。

### 7.3 15秒禁用或压缩

- 禁止完整长周期黐手循环。
- 禁止完整木人桩116式流程，只能取“木人桩式短连击”。
- 禁止阮奇山完整长棍周转、古劳多段侧向闭环、彭南完整远距离长桥推摔。
- 禁止两个连续镜头都只是手部缠绕无命中反馈。
- 禁止终结前纯蓄力、纯摆架、纯眼神特写。

### 7.4 15秒最优流水线

```text
叶问二字马探桥 → 摊手开中线 → 膀手同步寸冲 → 伏手压腕封桥 → 低脚破根 → 标指插空 → 连环寸冲终结
```

若补姚才：

```text
摊手探桥 → 蛇形盘旋吸附 → 双层缠绕伏手 → 中线寸冲 → 标指插空终结
```

若补古劳：

```text
膀手分流 → 单次侧跨绕外侧 → 下合蝴蝶掌击侧肋 → 回叶问伏手寸拳终结
```

## 8. 30秒调用规则

### 8.1 30秒核心原则

30秒允许完整展示叶问系闭环，并加入1个补强派系解决战斗阶段问题。不要五派全塞。

推荐结构：

```text
0-5s：叶问二字马、摊手探桥、脚步小幅入距，建立中线短桥身份
5-12s：摊膀伏三手 + 膀手同步寸冲，展示攻守同期和中线压制
12-18s：寻桥小幅侧移、低脚限制、短时黐手听劲，制造对手失衡
18-24s：按战斗问题加入一个补强派系：姚才缠绕 / 古劳侧跨 / 阮奇山长桥 / 彭南长扬
24-30s：回到叶问伏手锁桥、标指插空、木人桩式连环寸冲终结
```

### 8.2 30秒补强示例

- **叶问 + 姚才**：适合极近身缠斗、对手擅长抽桥或反擒拿。
- **叶问 + 古劳**：适合对手正面重击强，叶问需要侧门绕袭破正面压力。
- **叶问 + 阮奇山**：适合对手拉远距离或需要六点半棍器械控场。
- **叶问 + 彭南**：适合需要更狂暴的远近强攻和洪式长桥压迫。

### 8.3 30秒必保留叶问识别点

无论补哪一派，30秒里必须至少出现：

1. 二字拑羊中正马或明显叶问中线起架；
2. 摊/膀/伏三手中的至少两类；
3. 中线寸冲；
4. 黐手或桥手接触听劲；
5. 标指/低脚/木人桩式短连击中的至少一类终结组件。

## 9. 特效/无特效规范

### 9.1 叶问系默认特效

- 以无特效或极内敛点状物理冲击为主。
- 寸冲/标指接触点可出现极小白色点状瞬时波纹。
- 伏手/膀手/黐手只写淡灰接触小点、衣袖震动、手臂微颤。
- 低脚踩踏只写小范围尘点和脚踝震动。

### 9.2 补派特效差异

| 派系 | 特效倾向 | 禁止项 |
|---|---|---|
| 阮奇山 | 大面积厚重灰白冲击、棍身长条震纹 | 禁止叶问点状寸劲感过强 |
| 姚才 | 纤细轻柔白色流转微光、腕部细小点纹 | 禁止大面积厚重撞击波 |
| 古劳 | 侧向小点波纹、短棍贴身细震纹 | 禁止六点半长棍远扫特效 |
| 彭南 | 外放长桥灰白冲击、长距离小幅扩散 | 禁止内敛纤细蛇形微光 |

### 9.3 统一禁区

- 特效必须服从角色主色，不允许咏春自带固定金光或玄幻光圈。
- 禁止全身发光、持续拖影、螺旋环绕、太极柔和长线气流、泰拳厚重膝肘爆炸尘土。
- 普通攻防优先拍接触点与物理反馈，不要让特效遮挡桥手动作。

## 11. 系统调用说明

当用户需求出现以下关键词时，优先读取本专项：

```text
咏春 / 永春 / 叶问 / 摊手 / 膀手 / 伏手 / 黐手 / 寸拳 / 日字冲拳 / 中线 / 标指 / 寻桥 / 小念头 / 木人桩 / 阮奇山 / 岑能 / 六点半棍 / 姚才 / 蛇形咏春 / 古劳 / 偏身咏春 / 蝴蝶掌 / 三点半棍 / 彭南永春 / 长桥永春
```

调用判断顺序：

1. 用户是否明确点名某一派？若点名，则以该派为主。
2. 若只说“咏春”，默认叶问系为主轴。
3. 若角色已有叶问系主轴但暴露短板，再选择一个补强派系。
4. 15秒最多“叶问主轴 + 1个补强点”；30秒最多“叶问主轴 + 1个补强派系”。
5. 所有危险目标执行层净化，不写现实致残教学。
6. 特效服从角色主色，普通攻防优先物理接触点。
