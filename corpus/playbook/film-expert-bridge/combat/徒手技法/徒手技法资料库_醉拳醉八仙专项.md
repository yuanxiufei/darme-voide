> 核心识别：不规则醉酒摇晃体态 + 举杯仿生虚招 + 松紧反差瞬时爆发 + 小幅低空跳跌

## 0. 一句话理解

醉拳·醉八仙不是普通短打加摇晃，也不是睡梦罗汉拳式地面躺卧缠斗，而是以醉酒踉跄身形作为伪装，借举杯、扶头、托坛、跌步、晃步等仿生动作扰乱对手预判；一旦对手进入0.5-1.4米中近距，就用跌步低扫、醉拳寸打、侧身醉肘、贴身顶膝、醉身抱摔和连环左右醉摆拳形成虚实交替的站立缠斗压制。

---

## 1. 武学总定位

### 1.1 武学类型

醉拳·醉八仙体系是象形仿生短打，以醉酒踉跄身形为伪装，手脚同步完成摔拿、短拳、低扫、顶膝和抱摔复合输出。

它分为两层逻辑：

```text
虚醉诱敌：举杯、晃步、跌身、扶头，故意暴露破绽，引诱对手误判。
实醉爆发：寸拳、摆拳、醉肘、顶膝、低扫、抱摔，借摇晃惯性瞬间爆发。
```

它区别于睡梦罗汉拳。睡梦罗汉拳以侧卧、仰卧、贴地滚翻和地面缠斗为核心；醉拳以站立踉跄、高低错落晃步为主，只允许少量低空跳跌，极少贴地平躺。

### 1.2 动作气质

- 东倒西歪；
- 脚步虚浮踉跄；
- 头、肩、腰持续左右摇晃；
- 重心忽高忽低；
- 看似随时摔倒，实际暗藏缠化、摔跌、击打；
- 虚招绵软无力，实招刚脆爆发；
- 醉态迷惑，突袭凌厉。

### 1.3 主战距离

```text
最优距离：0.5-1.4米贴身醉斗黄金区间
可用距离：0.3-1.7米贴身至中近距
弱势距离：1.7米以上远距离持续消耗 / 极致贴身锁臂缠斗
```

醉拳依赖中近距贴身缠斗。远距离只能靠举杯虚晃、晃步迂回、低空跳跌逼近，没有远程攻击手段。

### 1.4 核心优势

1. 醉态迷惑性极强，对手预判失效，容易主动近身落入圈套；
2. 身法无固定轨迹，左右摇晃、前后踉跄，常规直线拳脚容易落空；
3. 攻防一体，踉跄躲闪同步出拳、顶膝、低扫；
4. 摔拿、短拳、低扫、寸拳、醉肘、顶膝全套复合；
5. 重心高低自由切换，可下沉低位，也可小幅低空跳跌；
6. 单挑和多人合围都可通过晃步拆分进攻节奏。

### 1.5 核心弱点

1. 全程重心浮动大，面对高速直线突袭容易失衡；
2. 无远程招式，被远距离持续消耗时只能靠醉步迂回逼近；
3. 低空跳跌前摇略长，高速对手可贴身打断；
4. 姿态大开大合，极致近身锁臂后调整空间狭小；
5. 若失去醉态摇晃和虚实反差，会退化成普通短打。

## 2. 独家视觉识别铁律

醉拳·醉八仙必须保留以下识别点，否则会串味：

1. 全程醉酒摇晃体态：头、肩、腰持续左右晃动，脚步虚步踉跄；
2. 手部常模拟持酒坛、举杯、扶头、托坛、摇扇等仿生仪式动作；
3. 招式对应八仙形象气质：吕洞宾、汉钟离、韩湘子等醉态框架可以作为动作来源；
4. 位移以踉跄滑步、跌步、晃步为主，搭配小幅低空跳跌；
5. 极少贴地平躺，禁止写成睡梦罗汉拳式长时间地面缠斗；
6. 输出组合以醉拳寸打、醉肘顶撞、低位醉扫、醉身抱摔、贴身顶膝为主；
7. 腿法只做低位扫、截、绊、跳跌封路，不做高位腾空飞踢。

## 3. 核心打法逻辑

### 3.1 起手逻辑：醉酒举杯起势

一脚虚点、一脚承重，身形侧歪摇晃，一手虚托模拟酒坛，一手抬至唇边作饮酒姿态，重心忽沉忽浮；全程放松虚晃制造醉倒假象，引诱对手贸然突进。

核心口诀：

```text
晃即是躲，跌即是打。
```

对手拳脚近身瞬间，身体骤然收劲，借摇晃惯性反击。

### 3.1.1 观赏性通用规则：随机性耦合与假失衡借击回正

醉拳的观赏核心不是“看见攻击后闪避，再单点反击”，而是“身体本来就在随机晃动中，对手攻击正好打进晃动空位，角色借晃动惯性连续反攻，并用攻击把快要失衡的身体重新带回平衡”。

核心口诀：

```text
不是躲完再打，而是快倒时正好打出来，打出去以后正好站回来。
```

执行规则：

1. 醉拳角色的左晃、右歪、后仰、前扑、踉跄、快倒都不能只写成单纯闪避或摔倒，必须优先转化为攻击路径。
2. 对手攻击到来时，醉拳角色应表现为“正好”向某个方向醉晃，使拳、肘、膝、腿落入空位；晃动本身就是避锋和蓄力角度。
3. 每次成功避锋后，禁止只反击一下，必须顺着晃动惯性接2-3个站立醉拳连环动作，如左右醉摆拳、醉肘、顶膝、低位醉扫、后摆腿或醉身抱摔。
4. 攻击不只是杀伤，也负责恢复重心：后摆腿的腿弧、醉摆拳的甩臂、醉肘的肩胯反作用力、顶膝的前送回弹、低扫的脚下反作用力，都可以把“快倒”的身体重新带回中线或带入下一次醉步。
5. 移动方向与攻击方向必须经常错位：身体向左晃，攻击可从右侧摆入；身体向右倒，腿可从身后后摆；身体后仰，膝可从下方顶出；身体前扑，可顺势塌肩醉肘或醉身抱摔。
6. 打完不能摆正站定，必须继续保持醉态晃动，进入下一组随机耦合攻防，让对手无法判断下一招从哪边来。

正确执行示例：

```text
对手直拳冲胸时，醉拳角色身体正好向左醉晃，拳线擦肩落空；她不把身体摆正，而是借左晃惯性让右拳从身体外侧弧形甩出，右醉摆拳打向对手下颌线外侧。右拳被架住后，身体顺反作用力向右侧歪得像要倒下，对手横肘追头；她顺右侧倒势让肘尖掠空，同一拍左脚深踩地面，右腿从身后弧线后摆扫向对手肋侧外线。后摆腿的弧线把腰胯重新带回中线，落地回正瞬间左拳再从另一侧醉摆补打肩颈线。
```

禁止误写：

```text
对手攻击 → 醉拳后退闪开 → 停一拍 → 打一拳 → 站稳重新起手。
```

### 3.1.2 醉拳随机应变与无招胜有招铁律

醉拳的“无形胜有形、无招胜有招”不是没有动作，也不是随便乱打，而是对手每一次应对都会改变醉拳下一击的方向。醉拳角色不能按固定套路机械出招，必须在自己的攻击被挡、被压、被引、被闪或被贴身截断时，立刻把身体偏移、手臂反弹、肩胯歪斜、脚步踉跄转化成下一击的起点。

核心链路：

```text
主动攻击 / 虚醉诱敌
→ 对手格挡、托臂、压肘、抓腕、闪避或反击
→ 醉拳身体顺势偏、坠、歪、晃、仰、扑、旋
→ 偏移方向立刻生成新的攻击路线
→ 攻击命中、被挡或落空后继续转入下一次失衡
```

执行规则：

1. 醉拳每组攻防必须有“对手应对后的即时变化”，禁止一套预设拳法从头打到尾。
2. 醉拳攻击被挡时，不能停顿抽手重来；必须把被挡产生的反弹力写成转身、后仰、侧坠、前扑、换轴或下沉，再接背拳、反肘、横肘、低扫、顶膝、醉掌或抱摔入口。
3. 对手以鞭腿攻击腰部时，醉拳可以顺势转身避开腰线，让腿风擦过衣摆；转身惯性必须立刻接回身背拳、反肘扫肩窝、低扫支撑线或回身醉掌，禁止“躲完站稳再打”。
4. 醉拳打点必须无规则但有因果：可从正身打、侧身打、半背身打、后仰打、前扑打、单膝将落未落时打、单手撑地前一瞬打、身体旋回来的一瞬打；但每个姿态都必须说明由上一拍攻防怎样带出。
5. 打击点要随机轮换：面门外侧、下颌线、肩窝、肋侧、腹线外侧、前臂、手腕、腰侧、小腿外侧、支撑线、膝线外侧；禁止长期只打头、只打胸腹或只低扫。
6. 攻击路线要随机轮换：上砸、下撩、侧甩、反身抽回、转身回打、低位扫出、前扑横撞、后仰回肘；路线变化必须来自身体失衡和回正过程，不是无因果花活。

正确执行示例：

```text
梦梦右醉摆拳被对手左前臂架住，右臂被弹向外侧，肩线顺势向右歪倒；她不把右手抽回重打，而是让右肩继续下坠，左脚斜踩沙面撑住身体，左拳从低位斜撩对手腹线外侧。对手下压左拳时，梦梦腰胯被压得向前扑，右肘沿前扑惯性横扫对手肋侧，肘尖命中后身体借反作用力重新晃回中线。
```

禁止误写：

```text
醉拳随机出拳、随便换招、左右乱打。
醉拳被挡后停住，重新摆起手式再打下一拳。
```

### 3.1.3 醉拳失衡承重与反向回正发力铁律

醉拳的失衡方向不能机械等同于同侧主击。身体向左坠、向右摆、前扑、后仰时，必须先判断“承重侧”和“释放侧”：坠向侧通常负责吃重、撑住、压低、卡位、压腕、短撞、绊根或顺坠低位攻击；反向侧在身体回正时被全身力量甩出，往往形成更强的拳、肘、膝、腿主击。

醉拳的核心发力不是传统拳法的“站稳后腰胯带肩出拳”，也不是普通腿法的“腰胯带腿出腿”，而是“快要跌倒时，为了不倒而产生的全身回正力”。醉拳角色用全身力量防止自己真正倒下，拉回身位的瞬间把整股回正力释放成攻击。

承重侧 / 释放侧规则：

| 失衡状态 | 承重侧功能 | 释放侧主击 | 可视化重点 |
|---|---|---|---|
| 左坠 | 左脚、左胯、左肩吃重下沉，负责撑住不倒、压腕、卡肩、绊根 | 右拳、右肘、右膝、右腿借回正力甩出 | 左侧身体下坠，右侧像被弹簧甩回一样爆发 |
| 右摆 | 右脚、右胯、右肩吃重下沉，负责撑住不倒、压肘、卡位、短撞 | 左拳、左肘、左膝、左腿借回正力甩出 | 右侧承重，左侧横甩回打 |
| 前扑 | 前脚、前肩、前胯承接下坠重量，负责贴近、顶住、抱入、压低 | 后侧拳肘可横扫回打，膝、肩可顺前扑撞入 | 上半身向对手怀里前倾，攻击沿前扑惯性横撞或短顶 |
| 后仰 | 后脚跟、后胯、背线承接后倒重量，负责拉开攻击线 | 前侧腿、前侧掌、回身肘、反身背拳借回弹打出 | 胸腹线后拉，肩胯回弹时从下向上或反身抽回 |

生成醉拳动作时，必须按以下链路书写：

```text
失衡方向
→ 承重侧撑住不倒
→ 释放侧借回正力甩出
→ 攻击命中或被挡
→ 身体回正或继续转入下一次失衡
```

关键执行规则：

1. 左坠不等于左侧主击。左坠时左侧多负责吃重、压低、卡位、短撞或绊根，右侧反而更适合借回正力甩出重拳、右横肘、右膝或右腿。
2. 右摆不等于右侧主击。右摆时右侧多负责承重、压腕、压肘、卡肩，左侧反而更适合借回正力甩出左摆拳、左横肘、左膝或左腿。
3. 同侧也可以攻击，但通常是短控、短撞、压腕、卡位、绊根、低位顺坠攻击；真正有甩鞭感和爆发感的主击，优先来自反向回正侧。
4. 每次“回正攻击”必须写出脚、胯、肩、腰、肘或膝的发力链，禁止只写“借力反击”。
5. 醉拳终结前的连续连击，应该由多次“左坠右甩、右摆左甩、前扑横肘、后仰回掌”交替形成，不是普通左右拳连打。

正确执行示例：

```text
梦梦被太极捋带后身体向左侧坠落，左脚深踩沙面，左胯下沉吃住重量，左肩几乎贴近太极右臂；她没有用左拳硬打，而是借左侧承重产生的反向回正力，右肩从低处猛然甩回，右横肘沿弧线扫向太极肋侧。太极前臂架住肘线，梦梦右肩被弹回，身体又向右摆，右脚外侧压进沙面止住歪倒，左拳顺回正力从下往上醉撩太极下颌线外侧。
```

禁止误写：

```text
左坠就左横肘、左低扫、左肩撞，右摆就右摆拳、右侧踹、右反肘。
醉拳先站稳，再腰胯发力出拳。
```

### 3.1.4 醉拳起手识别姿势铁律

醉拳起手不是普通格斗架、马步、拳架或站稳蓄力，而是“预失衡状态”：观众第一眼要看到角色像要倒、像散、像醉、像没有重心，但肩胯、脚掌和手型又暗中保留攻击入口。

起手识别点：

1. 单脚承重，另一腿可提膝悬空、虚点地面或脚尖轻拖；承重脚必须有吃重压沙/压地反馈。
2. 身体侧坠或斜歪，肩线不水平，腰胯松垮但没有真正塌掉。
3. 双手高低错层：一手高架在头侧、眼前或额角附近，可作举杯、扶头、醉指、松腕；另一手低位外展、虚托酒坛或护住肋腹线。
4. 手腕必须松、垂、绕、虚托、醉指，不写拳击护架或标准马步抱拳。
5. 头部偏转，眼神斜看或半眯，视线不正面死盯，但要能让观众感觉她在“装醉诱敌”。
6. 整体持续微晃：膝盖微屈、肩胯轻摆、脚尖虚点、上身像要倒又被脚下暗劲拉住。
7. 30秒第一段若需要展示醉拳起手，必须用单人大腿以上中景或全身中景，让单腿、承重脚、侧坠肩线和高低手全部入镜；禁止只拍胸口以上，也禁止胸口单独特写。

标准起手画面示例：

```text
单人大腿以上中景·45°斜侧平视·缓慢推近·跟随梦梦承重脚、提膝腿和高低手。梦梦左脚深踩沙面承重，右膝松松提起悬在身前，身体向左侧坠得像要倒下；左手松腕高架在额角前方，指尖微垂如举杯醉指，右手低位外展虚托酒坛，肩线一高一低，头微偏，眼神斜看太极，整个人持续细微摇晃，脚下沙粒随承重脚压出半月脚印。
```

禁止误写：

```text
梦梦双脚稳站，双拳护脸，摆出标准格斗架。
镜头只拍梦梦胸口以上，完全看不到单腿、承重脚和侧坠重心。
```

### 3.2 分层压制逻辑

```text
第一层：虚醉迷惑层
踉跄摇晃、虚晃抬手，故意露出头、肋、下盘破绽，诱敌全力进攻。

第二层：晃步卸力层
顺着对手冲击方向跌步侧晃，卸掉冲力，同步低位扫腿锁断下盘。

第三层：实招爆发层
寸拳击胸线、顶膝撞腹、醉肘打肋、抱摔压身、擒拿锁肩，多重同步压制。
```

### 3.3 破重心逻辑

醉拳通过三段打击点位分层破重心：

| 层级 | 执行层目标 | 功能 |
|---|---|---|
| 上段 | 面门外侧、头侧护架、下颌线外侧 | 醉摆拳扰乱视线与头肩平衡 |
| 中段 | 胸口中线、肋侧、胸腹交界 | 顶膝、寸拳、醉肘打乱呼吸与躯干轴 |
| 下段 | 小腿外侧、膝线外侧、下盘支撑线 | 低位醉扫、跌步截腿，瓦解站姿 |

同时辅以醉身抱摔，通过自身跌步惯性牵引对手重心偏移，再集中爆发。

### 3.4 防守 / 反击逻辑

醉拳没有静态硬格挡。它的防守来自：

```text
晃步、跌身、侧歪、顺势卸力。
```

对手肢体触身瞬间，醉拳顺势随势摇晃借力，躲闪、扫腿、出拳三动作同帧完成。

禁止：

```text
原地架防 → 等一拍 → 再反击。
```

正确：

```text
对手冲拳 → 醉拳侧歪让线同时跌步低扫 → 上身晃开拳线同时寸拳回击。
```

### 3.5 空间变化逻辑

- 无直线稳定进退；
- 全程不规则左右摇晃、前后跌步；
- 小幅斜向穿插；
- 少量低空跳跌腾空；
- 打完立刻重回摇晃低位醉态；
- 始终维持贴身缠斗区间，不给对手稳定距离预判。

### 3.6 终结逻辑

醉拳有两套标准闭环终结：

#### A. 单人站立终结

```text
连环醉摆拳 → 侧身醉肘 → 贴身顶膝 → 跌步低扫
```

通过上层眩晃、中层肘膝、下层扫腿叠加，让对手站姿溃散、踉跄倒地。

#### B. 抱摔制服终结

```text
醉身顺势抱腰 / 锁肩 → 借自身跌步惯性向下掀摔 → 落地补低扫锁腿 → 迅速起身恢复醉步姿态
```

醉拳不做躺地长时间缠斗，摔跌后迅速起身，恢复站立醉步。

## 5. 13式执行级招式总表

### 第1式：举杯醉步起势

- **动作描述**：单脚虚点地面，身形持续左右歪斜摇晃，一手虚托酒坛，一手作举杯饮酒姿态，重心忽高忽低，周身松软无紧绷，仅腰暗蓄劲，不主动进攻。
- **打击 / 控制点**：无击打，伪装诱敌。
- **功能**：起手定型、醉态迷惑铺垫、八仙体系基底。
- **攻击轨迹**：平缓左右不规则摇晃，重心浮动不固定。
- **发力逻辑**：全身松弛蓄暗劲，呼吸模拟醉酒散漫。
- **适配镜头**：中景·正面平视或45°斜侧平视·缓慢推近·跟随举杯手、虚托酒坛手与东倒西歪肩线。
- **受击反馈 / 对手反应**：对手判断其重心不稳，贸然直线突进，门户敞开。
- **可接续招式**：跌步低位醉扫、醉式寸打直拳。
- **禁止误写**：四平稳定马步、挺胸直立、紧绷发力、无摇晃体态。
- **标准时长**：1.0s。

### 第2式：跌步低位醉扫

- **动作描述**：对手冲拳近身瞬间，顺势向外侧踉跄跌步，下沉重心，单腿贴地横向短促扫击对手下盘支撑线；身形同步歪斜躲闪，躲闪与扫腿同帧完成。
- **打击 / 控制点**：小腿外侧、膝线外侧、下盘支撑线。
- **功能**：卸开突进冲力、锁断下盘根基、制造基础失衡。
- **攻击轨迹**：低矮横向内敛扫踢，离地寸许不抬高。
- **发力逻辑**：跌步惯性带动腿部寸劲弹抖，上半身维持醉酒摇晃姿态。
- **适配镜头**：中景·低角度45°斜侧·线性横移跟拍·跟随跌步侧歪与低位扫腿弧线。
- **受击反馈**：对手小腿外侧被扫，脚掌打滑，重心前倾，胸腹与肩线暴露。
- **可接续招式**：醉身贴身顶膝、连环左右醉摆拳。
- **禁止误写**：高抬扫腿、原地站定扫踢、直立不跌步。
- **标准时长**：0.5s。

### 第3式：醉身贴身顶膝

- **动作描述**：跌步锁断对手下盘后，顺势向前踉跄靠身，提膝平直顶撞胸腹交界与肋侧，一手虚扶对方肩线维持醉酒摇晃，不全力抓握。
- **打击 / 控制点**：胸腹交界、肋侧、肩线虚扶点。
- **功能**：近身中层重创、打乱呼吸、大幅压制重心。
- **攻击轨迹**：纵向短促向前顶撞，身形歪斜不摆正。
- **发力逻辑**：腰胯随摇晃顺势前送，膝部短促爆发寸劲。
- **适配镜头**：中近景·胸腹侧45°平视·短促推镜·跟随歪身顶膝与虚扶肩线。
- **受击反馈**：胸腹受顶，呼吸被压断半拍，身体向后顿挫摇晃，上肢防御松散。
- **可接续招式**：锁肩醉身抱摔、醉式寸打直拳。
- **禁止误写**：高抬飞膝、直立硬顶、双手死抓锁肩。
- **标准时长**：0.6s。

### 第4式：锁肩醉身抱摔

- **动作描述**：顶膝迫使对手重心上浮，双手虚搭对方肩颈线，借自身向侧方跌步的惯性向下拉扯掀翻，身形同步顺势歪倒，不刻意硬摔。
- **打击 / 控制点**：肩颈线、腰腹支撑轴、重心线。
- **功能**：借力摔制、瓦解站立根基、单人制服前置。
- **攻击轨迹**：侧向下沉拉扯 + 跌步复合轨迹，随势顺势不蛮力硬拽。
- **发力逻辑**：全身跌步惯性传导，借力卸力摔发，不单独用上肢蛮力。
- **适配镜头**：中景·双人侧方45°平视·后拉跟镜·跟随醉步抱摔掀翻和落地轨迹。
- **受击反馈**：对手重心倾覆，向后摔倒，短时失去反抗节奏。
- **可接续招式**：跌步低位醉扫、八仙连环循环醉打。
- **禁止误写**：原地直立抱摔、腾空大力掀摔、锁喉掐颈。
- **标准时长**：0.6s。

### 第5式：醉式寸打直拳

- **动作描述**：身形左右摇晃间隙，拳头短促向前弹抖，直击胸口中线；打完手臂立刻松弛收回，身体继续歪斜醉酒，发力前后反差极强。
- **打击 / 控制点**：胸口中线、胸前护架、胸腹交界。
- **功能**：单点中层破防、累积躯干损伤、打断进攻节奏。
- **攻击轨迹**：短距平直内敛寸击，身形持续晃动不静止。
- **发力逻辑**：周身松弛瞬间骤然绷紧0.2秒，拳面弹抖寸劲爆发，随即复归松软。
- **适配镜头**：特写·正面微侧平视·急速推镜·推进至拳面命中胸口中线。
- **受击反馈**：胸口衣料短促内陷，呼吸紊乱，站姿松动，抬手格挡迟缓。
- **可接续招式**：连环左右醉摆拳、醉身贴身顶膝。
- **禁止误写**：长距离直拳、直立稳架发力、持续紧绷身形。
- **标准时长**：0.5s。

### 第6式：连环左右醉摆拳

- **动作描述**：左右交替晃身，双拳弧形横向短摆击向头侧护架与下颌线外侧，一拳出、一拳收，身形同步左右偏移，持续干扰对手视线。
- **打击 / 控制点**：头侧护架、下颌线外侧、肩颈平衡线。
- **功能**：上层连续压制、晃散头肩平衡、多层叠加眩晃。
- **攻击轨迹**：左右交替弧形短摆循环，无大幅度挥臂。
- **发力逻辑**：每拳短促弹抖，依靠身体摇晃惯性带动发力。
- **适配镜头**：中近景·45°斜侧平视·线性横移跟拍·跟随双拳交替摆击与肩线左右晃动。
- **受击反馈**：对手头肩持续受击，左右失衡，下盘暴露低扫空档。
- **可接续招式**：醉身贴身顶膝、锁肩醉身抱摔。
- **禁止误写**：原地站定直摆、大幅抡臂重拳、身形静止。
- **标准时长**：0.7s。

### 第7式：八仙连环循环醉打

- **动作描述**：融合吕洞宾提壶、汉钟离摇扇等基础动作，晃步交替寸拳、摆拳、低扫、顶膝，高低点位循环切换，全程无稳定站姿。
- **打击 / 控制点**：头侧、肋侧、小腿外侧、胸腹交界。
- **功能**：持续全域压制、拆分多人合围、多层累积损伤。
- **攻击轨迹**：不规则高低错落循环晃步，重心持续浮动。
- **发力逻辑**：每一招借摇晃惯性短促爆发，虚实交替无停顿。
- **适配镜头**：中景·45°斜侧平视或轻微斜俯·线性横移跟拍·跟随高低错落拳肘膝扫循环。
- **受击反馈**：对手被高低多层打击干扰，无法稳定预判路线，持续被动。
- **可接续招式**：低空跳跌醉袭、醉式寸打直拳。
- **禁止误写**：稳定直线进退、直立连贯连招、无重心起伏、360°完整环绕镜头。
- **标准时长**：0.9s。

### 第8式：低空跳跌醉袭

- **动作描述**：对手后撤拉开距离时，醉拳小幅腾空侧向跳跌，落地瞬间重心下沉，同步低扫封锁逃跑路线，落地仍维持摇晃体态。
- **打击 / 控制点**：膝线外侧、小腿外侧、下盘支撑线。
- **功能**：跳跃变线突袭、截断后撤路线、重新锁死贴身区间。
- **攻击轨迹**：小幅斜向低空跳跌 + 落地低位扫腿复合轨迹，腾空高度极低。
- **发力逻辑**：下落重力叠加扫腿寸劲，落地顺势持续晃身。
- **适配镜头**：中景·斜向45°动态跟拍·跟随低空跳跌、落地沉身和低扫封路。
- **受击反馈**：对手后撤路线被截断，双腿受击，进退双向受制，正面门户打开。
- **可接续招式**：连环左右醉摆拳、醉身贴身顶膝。
- **禁止误写**：高空腾空飞踢、原地跳跃、落地直立站稳。
- **标准时长**：0.6s。

### 第9式：晃步分层后撤回架

- **动作描述**：持续左右虚晃踉跄向后小幅退避，单手虚抬模拟扶酒坛护头，低位虚提小腿格挡扫腿，随时可侧向跌步反击，快速回归举杯起势。
- **打击 / 控制点**：前臂、膝线，偏防御缓冲。
- **功能**：重置贴身缠斗距离、缓冲攻势、循环诱敌铺垫。
- **攻击轨迹**：不规则歪斜后撤，重心持续浮动不直立。
- **发力逻辑**：全身维持醉酒松弛卸力姿态，无硬架格挡。
- **适配镜头**：中景·正面侧移平视·线性后拉跟拍·跟随摇晃后撤、扶坛手和低位虚提小腿。
- **受击反馈 / 对手反应**：对手直线拳脚随晃步落空，醉拳随时可跌步突进。
- **可接续招式**：举杯醉步起势、跌步低位醉扫。
- **禁止误写**：直线大步后撤、直立稳定后退、跳跃规避。
- **标准时长**：0.8s。

### 第10式：侧身醉肘横撞

- **动作描述**：晃身绕至对手侧门，手肘横向短促顶撞肋侧，一手虚晃遮挡视线，身形同步向反方向歪斜制造错觉。
- **打击 / 控制点**：肋侧、侧门空档、肩线视觉遮挡。
- **功能**：侧门偷袭破防、绕开正面防御、制造单侧躯干失衡。
- **攻击轨迹**：内向横向短促肘撞，身形反向晃身制造视觉迷惑。
- **发力逻辑**：腰胯摇晃扭转带动肘尖寸劲，虚实同步。
- **适配镜头**：中近景·侧肋局部45°平视·短促推镜·跟随虚晃遮眼与肘尖撞肋。
- **受击反馈**：肋侧衣料内陷，躯干被迫侧弯，单侧上肢失去格挡能力。
- **可接续招式**：醉式寸打直拳、低空跳跌醉袭。
- **禁止误写**：正面直进顶肘、直立稳身发力、大幅度甩肘。
- **标准时长**：0.6s。

### 第11式：醉拳跌步复合站立终结连击

- **动作描述**：连环醉摆拳、侧身醉肘撞肋、贴身顶膝、跌步低扫四层连贯输出，高低多层打击叠加，对手站姿彻底溃散，原地踉跄倒地。
- **打击 / 控制点**：头侧护架、肋侧、胸腹交界、小腿外侧。
- **功能**：醉拳标准站立闭环KO，多层失衡叠加终结。
- **攻击轨迹**：上层摆拳 + 中层肘膝 + 下层扫腿复合循环晃步轨迹。
- **发力逻辑**：分段借晃身惯性短促爆发，渐进式累积重创。
- **适配镜头**：中景·45°斜侧平视·后拉跟镜·跟随摆拳、肘膝、低扫四层连击到倒地结果。
- **受击反馈**：头肩眩晃、胸腹受压、下盘支撑断裂，多重失衡叠加，站立姿态崩溃。
- **可接续招式**：无，专属终结招式。
- **禁止误写**：中途直立稳定对峙、腾空飞踢收尾、拉开远距离输出。
- **标准时长**：1.1s。

### 第12式：虚酒诱敌绕后擒拿

- **动作描述**：举杯虚晃吸引正面注意力，顺势晃步绕至对手后背，单手虚扣后肩线牵制，低位寸步卡住支撑脚外侧，不大力锁拿，依靠晃身拉扯失衡。
- **打击 / 控制点**：后肩线、支撑脚外侧、背线。
- **功能**：绕后偷袭牵制、瓦解正面防御、摔法前置铺垫。
- **攻击轨迹**：侧身不规则晃步绕袭 + 内敛虚扣复合轨迹，全程松弛不硬锁。
- **发力逻辑**：手臂轻柔粘引借力，腰腿低位卡点同步协同。
- **适配镜头**：中近景·后背侧方45°斜俯·小幅跟拍·跟随举杯虚晃、绕后和后肩虚扣。
- **受击反馈**：对手后背被牵制，重心前倾，无法回身正面格挡。
- **可接续招式**：锁肩醉身抱摔、侧身醉肘横撞。
- **禁止误写**：正面直进、硬爪死锁、大幅翻身腾空。
- **标准时长**：0.6s。

### 第13式：八仙全域晃步闭环走位

- **动作描述**：持续不规则左右、前后踉跄跌步，交替举杯虚诱、寸拳、低扫、顶膝、跳跌，重心高低不停切换，始终维持0.5-1.4米贴身区间，封锁对手拉开距离路线。
- **打击 / 控制点**：头侧、肋侧、小腿外侧、胸腹交界全域控点。
- **功能**：贴身全域持续压制、打乱对手预判、醉拳完整循环走位体系。
- **攻击轨迹**：不规则歪斜高低复合循环晃步，无稳定直线位移。
- **发力逻辑**：每一步晃跌同步蓄力招式，循环不间断，醉态不消散。
- **适配镜头**：中景·45°斜侧平视或轻微斜俯·线性长移跟拍·跟随不规则晃步和高低攻防切换。
- **受击反馈**：对手无法捕捉稳定进攻空隙，持续被高低虚实招式消耗。
- **可接续招式**：举杯醉步起势、八仙连环循环醉打。
- **禁止误写**：原地静止对峙、直立稳定马步游走、长距离直线进退、360°完整环绕镜头。
- **标准时长**：0.9s。

## 7. 固定标准连招闭环链

### 连招链1：举杯诱敌 → 跌步扫腿 → 顶膝重创

```text
1 举杯醉步起势
→ 2 跌步低位醉扫
→ 3 醉身贴身顶膝
```

#### 连招逻辑

1. 举杯摇晃制造重心不稳假象，引诱对手直线突进；
2. 顺势侧向跌步躲闪，同步低扫锁断下盘；
3. 贴身晃身顶膝重创胸腹，打乱呼吸与站姿。

#### 调用价值

这是醉拳基础虚实牵制链，适合15秒主链和30秒第一段首轮反击。

---

### 连招链2：绕后虚拿 → 侧身醉肘 → 连环摆拳

```text
12 虚酒诱敌绕后擒拿
→ 10 侧身醉肘横撞
→ 6 连环左右醉摆拳
```

#### 连招逻辑

1. 正面虚晃迷惑视线，晃步绕至后背牵制肩线；
2. 隐蔽横肘重击肋侧，打散单侧躯干防御；
3. 左右交替摆拳持续击打头侧护架和下颌线外侧，叠加眩晃，铺垫终结。

#### 调用价值

适合做侧门偷袭均衡链，尤其适合第二轮攻击思路变化。

---

### 连招链3：八仙循环压制 → 低空跳跌 → 多层复合终极KO

```text
7 八仙连环循环醉打
→ 8 低空跳跌醉袭
→ 11 醉拳跌步复合站立终结连击
```

#### 连招逻辑

1. 高低交替虚实招式持续消耗，对手预判持续失误；
2. 小幅跳跌截断后撤路线，重新锁死贴身区间；
3. 摆拳、横肘、顶膝、低扫四层同步叠加损伤，完成标准站立KO。

#### 调用价值

适合30秒第二段终结链，不适合15秒完整展开。

## 8. 15秒高密度短打执行规范

### 8.1 适配核心逻辑

15秒短打主打：

```text
短晃虚招 + 单次跌步扫腿 + 单式寸拳 + 侧门醉肘
```

应剔除长周期八仙循环、全套多层终结慢连击、低空长跳跌。全程维持歪斜醉酒体态，杜绝稳定直立站姿和过长连环演示。

### 8.2 必保留招式

1. 第1式：举杯醉步起势；
2. 第2式：跌步低位醉扫；
3. 第5式：醉式寸打直拳；
4. 第10式：侧身醉肘横撞。

### 8.3 必须压缩或禁用

1. 第13式：全域长周期晃步走位，15秒不宜大篇幅展开；
2. 第11式：全套四层复合终结，15秒只能截取关键动作；
3. 第7式：长八仙连环循环，15秒不宜完整展开；
4. 第8式：低空跳跌，15秒只允许短促一次，不做高空表演。

### 8.4 15秒最优短打流水线

```text
举杯虚醉诱敌
→ 跌步低扫锁根
→ 寸打破防
→ 侧肘偷袭收尾
```

## 9. 30秒完整对战分段流程标准

### 9.1 30秒核心闭环

30秒适合完整呈现：

```text
举杯诱敌
→ 晃步卸力
→ 高低多层拳脚膝扫
→ 跳跌截断退路
→ 复合拳脚KO
```

### 9.2 第一段 0-15秒建议结构

```text
0-2s：举杯醉步起势，东倒西歪，重心忽高忽低；
2-5s：对手直线突进，醉拳晃步后撤诱敌，跌步低扫同步卸力；
5-8s：醉式寸打与贴身顶膝打乱胸腹中线；
8-12s：虚酒绕后擒拿，侧身醉肘撞肋，改变攻击角度；
12-15s：连环左右醉摆拳形成阶段压制，但对手仍未彻底倒地，留下第二段承接点。
```

### 9.3 第二段 0-15秒建议结构

```text
0-2s：承接第一段贴身醉斗，对手试图拉开距离；
2-5s：八仙连环循环醉打，高低点位寸拳、摆拳、低扫、顶膝交替压制；
5-7s：低空跳跌醉袭截断后撤路线，落地低扫封路；
7-11s：侧身醉肘、贴身顶膝、醉式寸打连续破胸肋中线；
11-15s：醉拳跌步复合站立终结连击，摆拳、横肘、顶膝、低扫四层叠加，胜负明确。
```

### 9.4 30秒必展现核心特质

1. 东倒西歪不规则醉酒晃步；
2. 虚实反差瞬时爆发；
3. 高低分层拳、肘、膝、低扫复合；
4. 小幅低空跳跌，不做高空飞踢；
5. 借力醉身抱摔，摔后迅速起身恢复醉步；
6. 飘忽难预判、醉形藏刚的象形短打气质。

### 9.5 防止“醉拳变普通短打”的观赏度规则

醉拳每一次摇晃都必须服务攻防结果：

```text
晃步让线 → 跌步低扫
举杯虚晃 → 寸拳突袭
扶头侧歪 → 醉肘撞肋
踉跄后撤 → 诱敌追击
低空跳跌 → 落地扫腿截路
```

禁止写成：

```text
角色一直摇摇晃晃，但没有具体扫、打、肘、膝、摔的攻防兑现。
```

## 12. 流派防混区分铁律

### 12.1 对比睡梦罗汉拳

睡梦罗汉拳大量侧卧、仰卧、贴地平躺和长时间地面缠斗，核心是躺卧锁拿。醉拳以站立摇晃为主，少量低空跳跌，极少躺地平卧，主打站立虚实拳脚摔打。

防混句：

```text
醉拳禁止长时间躺地、侧卧、贴地滚翻缠斗；必须保留站立醉酒晃步、小幅低空跳跌和拳肘膝扫复合输出。
```

### 12.2 对比进攻型太极拳

太极拳以腰为轴、螺旋缠丝、步伐规整进退为核心，摔法偏发放轻推。醉拳不规则摇晃跌步，无太极螺旋缠丝，摔法依靠自身跌步惯性掀翻。

防混句：

```text
醉拳删除螺旋缠丝、规整弓马步和太极发放语汇；全程维持东倒西歪醉酒浮动重心。
```

### 12.3 对比五行拳 / 硬派短打

硬派短打站姿稳定、发力全程紧绷、直线固定拳脚。醉拳重心持续浮动，发力松紧反差极大，以虚醉诱敌为核心战术。

防混句：

```text
禁止稳定直立马步、持续紧绷发力；醉拳必须保留摇晃虚醉伪装和松紧反差。
```

### 12.4 对比纯腿武学

纯腿武学以腿法为核心输出，手部多为平衡或格挡。醉拳拳、肘、膝、摔为主力，低扫腿只辅助断步，不作为核心杀伤。

防混句：

```text
禁止高抬飞踢、以腿为主要输出；醉拳腿法只做低位扫、截、跳跌封路。
```

## 17. 醉拳全分支观赏度素材池

> 资料ID：MARTIAL-DRUNKEN-EIGHT-IMMORTALS-002
> 模块定位：醉拳全分支统一素材池｜独立闭环调用

### 17.0 醉拳全分支收纳总原则

醉拳不是固定招式库，也不是某个角色专属武学。醉拳的核心价值是观赏度、随机应变、对招变化、变招意外性与终结组合差异化。所有醉拳分支资料录入后，不作为互斥固定模板，也不要求生成时精准调用某一分支，而是统一收纳为"醉拳观赏度素材池"。

生成醉拳打戏时，应优先从身体方向、攻防压力、失衡状态、对手应对方式、节奏密度、镜头美感和终结需求出发，自由抽取并融合不同分支的身法、手法、腿法、跌扑、封手、截腿、短打、飘步、仿生诱敌、摔发和终结素材。

醉拳专项必须独立闭环。凡是被收纳进醉拳体系的门派依附醉拳、象形融合醉拳、佛派醉罗汉、现代竞赛醉拳，都必须在醉拳专项内提炼成可直接调用的动作素材、变招素材、终结素材和防串味规则。生成醉拳打戏时，默认只读取醉拳专项，不再跳读其他传统武学专项。只有用户明确要求"醉拳 + 某武学双体系融合"时，才允许读取对应外部武学库。

### 17.1 醉拳观赏度综合指标

醉拳观赏度是综合指标，包含但不限于：

1. **大幅度动作**：侧坠、前扑、后仰、半背身、旋身、跌扑、低空翻转、弧形滑步、大跨度侧跳；
2. **高密度攻防**：每一次摇晃、被挡、被拍、被压、被抓、被踢，都必须同步生成下一击；
3. **强打击反馈**：拳肘膝腿摔命中时必须有皮肤压缩、衣料抽响、沙粒炸开、空气波纹或镜头微震；
4. **飘逸身法**：扬袖、仰头、弧形滑步、侧向跳步、轻跌卸打、中距变线；
5. **身体方向变化**：正身、侧身、半背身、后仰、前扑、低位、上浮、高低切换；
6. **同拍攻防**：避线、承重、拆手、反击必须尽量同拍发生，禁止对手连打多招后醉拳才反击；
7. **拳肘膝腿摔复合**：醉拳不能只写左右拳，必须混合拳、掌、肘、膝、低扫、肩撞、切腕、托腕、摔发入口；
8. **变招意外性**：上一击被挡、被拍、被抓、落空后，下一击必须顺身体偏移方向生成，不让对手预判到固定路线；
9. **终结组合差异化**：终结不能固定三拳收尾，应根据当前身体方向和对手防线状态设计连续压防、错位、控制点、重击或摔发。

### 17.2 身法观赏度素材池

#### A. 基础醉步身法

- **站立醉步**：身体持续左右不规则晃动，脚下始终有承重脚，外形松散但底盘暗稳。
- **左侧坠身**：左脚、左胯、左肩吃重，右侧拳、肘、膝、腿可顺回正方向甩出。
- **右侧摆身**：右脚、右胯、右肩吃重，左侧拳、肘、膝、腿可顺回正方向甩出。
- **前扑醉步**：前脚、前肩、前胯承接下坠重量，可接顶膝、肩撞、低位撑手旋回、背身肘。
- **后仰醉步**：后脚跟、后胯、背线承重，可接托腿、点踢、回弹拳、反身背拳。

#### B. 大幅度身法

- **大幅侧跌**：身体向侧方沉坠避开直线攻击，同时低扫、横肘或肩撞反打。（来源：武八仙沉身跌扑）
- **低空跌扑**：短距离斜向扑跌，落地瞬间接低扫、顶膝、肩撞或重拳。（来源：武八仙低空狂跌突袭）
- **半背身旋回**：拳被拍偏或肘被托起后，身体顺力半转背身，接后肘、反背拳或低扫。
- **震脚沉身**：大幅下沉重心后震脚压入，适合贴身靠撞或肩胯爆发的前置蓄势。（来源：武八仙震脚沉身）
- **低空翻转 / 跌翻**：只能服务避线、变线、截击或终结入口，禁止无接触空翻表演。（来源：现代竞赛醉拳）

#### C. 飘逸身法

- **大跨度弧形滑步**：保持高挑舒展体态，侧向弧形错开对手直线攻击。（来源：太白醉酒弧形飘逸滑步）
- **侧向跳步**：轻盈侧移改变攻击角度，接斜肘、点拳、轻扫或绕背。（来源：太白醉酒）
- **轻跌顺势卸打**：不沉重扑倒，身体轻侧跌避开重击，同拍点拳、斜肘或托腕反打。（来源：太白醉酒轻跌卸打）
- **中距虚晃卡位**：保持0.6-1.6m中距，利用弧线走位截断对手后撤路线。（来源：太白醉酒中距虚晃卡位）

### 17.3 对招变招素材池

这是醉拳执行层最核心的模块。醉拳不是站稳后打，而是对招中不断变。

#### A. 被拍腕后的变招

- 右腕被拍偏：右腕顺拍力外摆，左肩下沉避线，右肘从腰侧斜甩扫肋侧外线。
- 左腕被拍偏：身体顺拍力右摆，右脚吃重，左拳或左肘从低位反向甩出。
- 手腕被压住：不硬抽腕，肩线顺压方向送入，另一手从下方切腕或托腕，接膝顶、肩撞或背身肘。

#### B. 被挡后的变招

- 右肘被下压挡住：顺肘臂反震向右摆，左拳、左肘或左膝从反向甩出。
- 左拳被拍开：左拳继续带动身体前扑，右膝短顶支撑线，右肩擦入外门。
- 重拳被交叉防住：拳臂碰撞后不收，身体顺反震半转，接低扫、背身肘或肩撞。

#### C. 对手起腿后的变招

- 对手高位横踢：后仰避过腿风，左掌或右掌托住小腿外侧，回弹接点拳、钻拳、膝顶。
- 对手侧踢：身体前扑让侧踢从背后擦过，低位撑沙旋回，接贴地扫腿或反手拳。
- 对手低扫：脚尖轻抬或后仰避开，扫腿落空瞬间点踢对手支撑膝外侧。

#### D. 对手抓腕 / 短锁后的变招

- 抓右腕：右肩向对方手里送，左掌切抓腕手背，右腕旋出半寸，右肘撑开前臂防线。
- 夹臂压肘：顺压肘方向侧坠或前扑，另一手托肘，接膝顶、肩撞或低扫支撑线。
- 短暂锁线：不得拖入长时间地面锁技，必须在0.2-0.4秒内转为切腕、抽腕、膝顶、摔发或反肘。

#### E. 对手后撤后的变招

- 对手后撤拉距：醉步不直线追，弧形滑步卡回中距，接扬袖点拳、斜肘或低空跌扑截腿。
- 对手被打退半步：前脚斜踩入外门，身体半背身旋回，接后肘、低扫或肩撞。

#### F. 对手贴身压迫后的变招

- 对手封门压进：身体半转背身，拳从背身低位反甩腹线外侧，接膝顶支撑线。
- 对手双手拍挂控臂：被拍偏的手顺力下沉，另一手从下方穿出反抽肋线，脚步斜踩内门。

### 17.4 高密度短打素材池

醉拳高密度短打不等于快速乱挥，而是每0.3-0.5秒出现一次清楚的攻防节点。

#### 可抽取动作

- **短桥封手**：前臂贴身横拦，卡住对手手臂发力线，立即接短拳或短肘。（来源：混八仙短桥封手截臂）
- **低位截腿**：小腿贴地快速截击支撑线，动作短促，一击即收。（来源：混八仙低位截腿断根）
- **贴身短寸拳**：从腰侧或肘后短促弹出，打腹线外侧、肋侧外线、肩线外侧。（来源：混八仙贴身短寸重拳）
- **侧肋短肘**：贴身小幅顶撞，不大开肘，适合被压手后反打。（来源：混八仙侧肋短肘顶撞）
- **连环醉摆拳**：左右晃身中交替短摆，不是原地抡臂，必须带身体偏移。（来源：洪家醉八仙连环左右醉摆拳）
- **贴身卡位**：脚步斜踩内门或外门，封住对手后撤路线，接膝顶或快摔。（来源：混八仙乱醉贴身卡位）
- **顺势快摔**：借对手前倾或后退惯性，小幅侧身压跌，不写长时间缠斗。（来源：混八仙顺势贴身快摔）
- **醉态中线短打**：左右手交替黐贴，拍腕、托腕、压肘、切腕，短拳连打。（来源：咏春醉拳融合）
- **桥手斜挂拍打**：偏门拍打、挂打变线、大臂扫挂、醉步外门切入。（来源：蔡李佛醉拳融合）

### 17.5 强打击素材池

#### A. 武八仙强打击素材

- **沉身低位狂扫**：身体大幅侧跌下沉，单腿贴沙重扫支撑线，适合破下盘。
- **沉身贴身重膝**：扫腿或前扑后顺势贴近，膝部短促重顶腹线外侧或大腿支撑线。
- **侧身重肘横撞**：大幅晃身绕至侧门，肘尖横撞肩窝外侧或肋侧外线。
- **连环狂摆重拳**：左右大幅晃身中交替重摆，重点写肩胯带动、拳臂碰撞和头部外线受力。
- **低空狂跌突袭**：对手后撤时斜向低空跌扑截断路线，落地接低扫或重膝。
- **跌扑重压摔发**：借身体下坠惯性扑身压倒，不写锁喉、锁颈，改写肩背控制点和重心倾覆。

#### B. 门派依附强打击素材

- **八极醉拳素材**：醉步前扑接肩靠、沉肩顶肘、震脚压入、短爆发靠撞、被挡后侧坠接贴身肘。
- **形意醉拳素材**：醉步崩拳、前扑钻拳、侧坠横拳、后仰炮拳、脚步截根同步出拳。
- **醉虎 / 醉豹素材**：猛扑、肩背撞、低位压身、兽性扑袭、爆发推进。
- **鲁智深醉罗汉素材**：狂醉肩靠、地趟扑跌、破围重撞、震脚压迫。

强打击素材使用禁令：

```text
强打击素材必须服务攻防因果，禁止为了重击而突然原地蓄力。终结前必须有连续压防、防线错位或破重心控制点。
```

### 17.6 飘逸审美素材池

#### A. 太白醉酒素材

- **问天饮醉**：高挑舒展，仰头虚饮，用于0-1s起手识别或诱敌。
- **扬袖抛杯**：袖摆大幅扬起遮挡肩线，引诱对手抬架或误判上盘。
- **大跨度弧形滑步**：中距错开直线攻击，接斜肘、点拳、轻扫。
- **侧身斜肘**：弧步错位后，肘线斜切肩窝外侧或肋侧外线。
- **轻盈弧扫截腿**：不沉身重扫，只轻扫小腿支撑线，打乱节奏。
- **身法绕背袭打**：弧形滑步绕至侧后盲区，掌根压肩背或肘切肩线。
- **轻跌顺势卸打**：轻侧跌避开重击，同时扬袖点拳或斜肘反打。
- **中距虚晃卡位**：保持0.6-1.6m，不贴死、不远离，持续卡住对手进退。
- **抛袖凌空虚袭**：双手大弧度上抛外展制造凌空突袭假象，诱导对手抬架放空，随即瞬间下沉变线贴身实打。

太白醉酒防串味：

```text
禁止写成武八仙式沉身狂跌、混八仙式市井乱打、佛派醉罗汉式地趟滚扑。纯打击感版本不默认白金光效，应改写为衣袖气流、空气细纹、沙粒弧线和衣料抽响。
```

#### B. 现代竞赛醉拳素材

- **旋身跌翻**：被攻击逼退时，低空旋身跌翻改变朝向，落地必须接截腿、撑地反踢或背身肘。
- **乌龙绞柱式低位旋转**：只作为低位避线和转向反击素材，禁止无接触表演。
- **快速翻身变线**：倒地或低位后1秒内起身反打，禁止长时间躺地空耗。
- **高观赏度腾挪**：只能服务避线、变线、截击或终结入口。

现代竞赛素材使用禁令：

```text
只能服务避线、变线、截击、反打或终结入口。禁止无接触空翻、禁止纯表演翻滚、禁止脱离攻防因果。
```

### 17.7 柔巧控制素材池

#### A. 文八仙素材

- **飘步粘腕缠拿**：平缓侧向飘步卸力，单手轻柔搭住前臂顺势向内缠绕锁腕。
- **交替缠腕锁肘**：左右手臂交替轻柔搭粘对手双前臂，顺力向内循环缠绕锁肘。
- **扣肩牵制**：单手轻柔扣住肩井，顺着对手失衡力道小幅侧向拉扯。
- **拦腰轻发放**：揽住腰侧向内轻推，依靠飘步惯性将人向外轻发放跌。
- **醉脉轻点柔掌**：掌尖指尖轻柔向前点刺前臂脉门或肩线，点触即收。

文八仙使用限制：

```text
不作为强打击主轴，不用于高爆发终结。适合破招、卸力、短暂控制、节奏换拍。如果用于30秒主攻段，必须混入更强的拳肘膝扫或环境反馈，否则节奏偏慢。
```

#### B. 武当内家醉八仙素材

- **醉态缠丝**：醉步外形，腰胯螺旋化劲，手搭前臂顺势引偏。
- **引劲落空**：对手直线冲击时，身体醉晃后撤半寸，腰胯一转，手腕轻搭前臂，对手拳线滑空。
- **借力发放**：顺对手惯性向侧方推送，肩线一沉一送。

武当内家防串味：

```text
必须有太极螺旋缠丝元素，但外形必须保留醉态、摇晃身形。不能写成纯太极。也不能和文八仙混：文八仙是柔巧粘拿、轻发放；武当醉八仙是内家缠丝、引劲落空、借力发放。
```

#### C. 其他柔巧素材

- **燕青醉酒素材**：灵巧绕身、轻擒拿、游走偷袭、小幅醉步。
- **醉螳螂素材**：双勾锁腕、缠前臂、点肋侧外线、封手拆臂。

### 17.8 佛派醉罗汉与象形融合素材池

#### A. 佛派醉罗汉素材

- **鲁智深醉罗汉**：肩靠重撞、地趟扑跌、震脚狂晃、破围重撞。适合狂醉破围和多人乱战。

- **醉猴素材**：低矮缩身、窜跳、小幅翻滚、灵巧偷袭、突然高低变化。
- **醉螳螂素材**：双勾锁腕、缠前臂、点肋侧外线、封手拆臂。
- **醉虎 / 醉豹素材**：猛扑、肩背撞、低位压身、兽性扑袭、爆发推进。

### 17.10 终结素材池

终结前3秒必须执行"连击压防 → 防线错位 → 破防控制点成立 → 重击 / 摔发 / 断根终结"。不得三拳直接结束，也不得用纯表演动作替代攻防因果。

#### A. 洪家站立复合终结

适合标准醉拳终结。

```text
连环醉摆拳压防 → 侧身横肘切肩线 → 贴身顶膝破重心 → 跌步低扫断支撑 → 对手站姿崩坏
```

#### B. 武八仙狂暴终结

适合强打击爆点。

```text
狂摆重拳压前臂防线 → 侧身重肘撞肩窝外侧 → 沉身重膝顶腹线外侧/大腿支撑线 → 低位狂扫断根 → 重击或跌扑摔发收尾
```

#### C. 混八仙市井速战终结

适合高密度近身乱战。

```text
低位截腿 → 短桥封手 → 贴身短寸拳 → 侧肋短肘 → 贴身卡位快摔/短拳收束
```

#### D. 太白雅士飘逸终结

适合美感型错位收束。

```text
抛袖虚袭诱高防 → 弧形滑步错位 → 扬袖点面外侧 → 侧身斜肘切肩窝 → 轻盈弧扫截腿 → 绕背压肩线收束
```

#### E. 醉罗汉地趟破围终结

适合狂醉破围或倒地不断线。

```text
肩靠重撞 → 地趟扑跌避线 → 低位扫腿断根 → 翻身顶撞/撑地反踢 → 起身重击收束
```

#### F. 醉虎豹扑袭终结

适合兽性压迫。

```text
低身前扑 → 肩背撞开防线 → 爪形压臂/肘切肩线 → 膝顶支撑线 → 扑袭重压收束
```

#### G. 现代竞赛观赏度终结

适合高视觉冲击，但必须保留攻防因果。

```text
低空跌翻避线 → 旋身起身变线 → 背身肘/低扫截腿 → 腾挪重击收束
```

禁止纯翻滚、纯空转、无接触杂技。

#### H. 复合融合终结

可跨分支融合，例如：

```text
洪家连环醉摆拳压防 → 武八仙侧身重肘撞肩窝 → 混八仙低位截腿断根 → 太白弧形滑步错位 → 终结重击
```

这种融合不需要标注"来自哪个分支"，只要动作因果连续、观赏度高即可。

### 17.11 防串味与执行净化

#### A. 仿生动作使用规则

举杯、托坛、敬酒、抛杯、问天饮醉、扬袖抛杯、举坛邀月等仿生动作只作为识别动作池、诱敌或换节奏动作，不应长时间占用打斗时长。仿生动作必须快速转入攻击、避线、变线或破防。

#### B. 真实危险目标净化

执行层提示词必须使用替代表达：

| 原始目标 | 执行层替代表达 |
|---|---|
| 太阳穴 | 头侧护架 / 面门外侧 / 下颌线外侧 / 额侧外线 |
| 眉心 / 面门 | 面门外侧 / 额侧外线 |
| 下颌 | 下颌线外侧 |
| 心口 / 膻中穴 | 胸口中线 / 胸前护架 / 胸腹交界 |
| 胃脘 | 胸腹交界 / 腹线外侧 |
| 软肋 | 肋侧 / 侧腹护架 / 肋侧外线 |
| 胫骨 | 小腿外侧 / 下盘支撑线 |
| 脚踝 | 支撑脚外侧 / 下盘支撑线 |
| 膝盖 | 膝线外侧 / 下盘根基 |
| 肩颈 / 锁喉 | 肩线 / 肩窝外侧 / 肩背控制点 |
| 脉门 | 前臂腕线 / 腕线外侧 |

#### C. 特效使用规则

- 纯打击感版本不默认白金光效或其他异质光效，改写为衣袖气流、空气细纹、沙粒弧线和衣料抽响。
- 需要特效版本时，太白醉酒可使用清雅通透微光波纹；武八仙可使用厚重灰白冲击波纹；混八仙可使用朴素写实点状震纹。
- 所有版本禁止：长条上扬气流、立体螺旋环绕、大面积厚重风压、高空爆炸强光、火焰/雷电/石化等异质特效。

#### D. 现代竞赛动作使用规则

现代竞赛醉拳的跌翻、旋身、翻滚、腾挪只能服务避线、变线、截击、反打或终结入口。禁止无接触空翻、禁止纯表演翻滚、禁止脱离攻防因果。

#### E. 睡梦罗汉与站立醉拳边界

睡梦罗汉是醉态地面体系。普通站立醉拳只能短暂借用倒地不断线（1-2秒内低扫/探拿/顶撞并滚身起立），不能长时间地面缠斗。长时间地面锁拿属于睡梦罗汉，不属于普通醉八仙。

#### F. 提示词禁令

醉拳提示词禁止写解释句，必须落成身体动作。禁止出现以下类型句子：

```text
"左坠不是空坠"
"体现随机应变"
"借回正力反击"
"这展现了醉拳的无招胜有招"
```

应直接写成：

```text
梦梦右腕被拍偏的同一拍，左脚深踩沙面，左肩向下沉，头部斜偏让崩拳擦过发梢，右肘从腰侧斜甩而出，贴着芭乐前臂外侧扫向肋侧。
```

### 17.12 醉拳素材池调用流程

生成醉拳打戏时，按以下流程从素材池中抽取并组合：

1. **确定观赏度需求**：这场需要大幅度？高密度？强打击？飘逸？混合？
2. **设计对招链路**：从17.3对招变招素材池中选取适配的变招路径。
3. **填充高密度短打**：从17.4高密度短打素材池中选取拳、肘、膝、扫、封手、卡位、快摔等动作填充每0.3-0.5秒的攻防节点。
4. **插入强打击或飘逸素材**：根据节奏需要，从17.5强打击素材池或17.6飘逸审美素材池中选取动作做阶段爆点或节奏变化。
5. **设计终结组合**：从17.10终结素材池中选取或融合一条终结链，确保终结前3秒有足够压防铺垫。
6. **检查防串味**：对照17.11防串味规则，确认没有写成太极、睡梦罗汉、普通短打或纯表演杂技。
7. **净化执行层**：将所有真实危险目标替换为执行层替代表达，删除所有解释句。
