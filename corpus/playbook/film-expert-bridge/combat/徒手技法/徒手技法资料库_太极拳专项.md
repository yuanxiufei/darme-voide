## 0. 武学导览卡

- **一句话理解**：太极拳不是慢动作摆架，而是以接触、听劲、引化、借力、破重心、顺势反击为核心的防反体系；五派动作风格不同，但核心都服务“接触后控制力线，让对手自己失衡”。
- **战斗气质**：沉稳、防反、借力、圆转、黏连、控重心、柔中带刚、慢中藏快。
- **主战距离**：中距离、近距离、贴身；可通过孙式活步扩展到远近切换，通过陈式低位仆步进入地面低位。
- **适合角色气质**：冷静、沉稳、以弱胜强、后发制人、看似缓慢实则掌控全局、擅长拆招和反制。
- **适合战斗定位**：防守化解、借力反击、破重心、贴身控制、柔摔、终结前承接、爆发式发放。
- **画面识别点**：抱圆、黏手、引化、捋带、挤按、采手、侧身化解、活步绕侧、低位下采、弹抖发放。
- **适合15秒**：适合做“短接触→快速引化→破重心→反击发放”的高密度防反，不适合长时间摆架和完整慢缠。
- **适合30秒**：非常适合见招拆招、前后架势变化、五派动态组合、从平缓引化到爆发发放的层次推进。
- **不适合方向**：长期无接触摆架、纯远程气功、连续高速拳腿连打、腾空杂技式攻击、只用特效不拍接触点。
- **推荐绑定方式**：太极角色可绑定“统一太极拳专项”，不必固定单一流派；系统可在同一场战斗中根据阶段动态抽取五派招式，形成多样化但不串味的太极打法。

## 1. 太极拳统一总定位

太极拳专项统一包含五派资料：陈式、杨式、武式、吴式、孙式。五派不是五个独立文件，也不是五套互相排斥的角色，而是太极拳统一核心下的五种表现分支。

### 1.1 统一核心

所有太极动作必须围绕以下核心：

1. **接触先行**：先与对手手臂、肩、肘、腰胯等形成接触点，再进行引化、捋带、挤按、采手、发放。
2. **听劲判断**：通过黏手和身体接触判断对方力线，不凭空闪避或远程发力。
3. **引进落空**：诱导对手继续发力，让对手力线偏离中线或支撑点。
4. **借力破重心**：通过圆弧、开合、缠丝、侧身或内收，把对手重心带偏。
5. **顺势反击**：反击来自对方失衡瞬间，不是突然变成普通直拳硬打。
6. **慢中藏快**：前半段可以慢引化，但转折点必须有清晰反击、摔投、震退或发放。
7. **接触点可见**：镜头必须拍清手腕、前臂、肘、肩、胸腹、腰胯等受力点。

### 1.2 统一禁区

- 禁止写成远距离气功掌、隔空推人。
- 禁止只有抱圆摆架，没有接触和受力反馈。
- 禁止全程慢动作，无破重心和反击兑现。
- 禁止将太极写成普通拳击、咏春连拳、洪拳硬桥、八极肩靠主攻。
- 禁止只写“化劲”但不交代对方怎么失衡。
- 禁止特效遮挡接触点。

## 2. 五派风格速览

### 2.1 陈式太极｜立体缠丝与弹抖发放

- **核心标签**：立体8字螺旋、缠丝、仆步、高低起伏、震脚、弹抖、爆发发放。
- **战斗作用**：适合破重心、低位控制、终结爆发、把柔化后的张力瞬间释放。
- **视觉识别**：全身螺旋缠绕、腰胯折叠、仆步下采、震脚弹抖、对手被螺旋力震飞或侧摔。
- **禁区**：不能写成杨式平面大圆，不能删除螺旋和弹抖，不能全程柔和无爆发。

### 2.2 杨式太极｜中正大圆与平缓引化

- **核心标签**：中正、平面大圆、匀速、舒展、平缓引化、无震脚、无爆发。
- **战斗作用**：适合起手、导入、防守化解、30秒见招拆招、平缓牵引失重。
- **视觉识别**：立身中正，双手走平面大圆，黏手长捋，对手被平缓牵引失重。
- **禁区**：不能写成立体缠丝、低仆步、震脚弹抖、击飞爆发。

### 2.3 武式太极｜贴身小架与内敛暗寸

- **核心标签**：贴身小圈、内收圆弧、寸步、含胸敛胯、暗寸劲、贴身轻摔。
- **战斗作用**：适合贴身拆招、小空间压制、近距离精细破重心、短促暗劲反击。
- **视觉识别**：手脚不离胸腹中线，半步寸移，极小圆弧黏住手腕肘关节，贴身原地侧摔。
- **禁区**：不能写成杨式大圆外放、陈式仆步弹抖、吴式大幅侧身、孙式大范围活步。

### 2.4 吴式太极｜侧身斜圆与横向游走

- **核心标签**：45°侧身、斜向圆弧、横向侧碾步、单侧破重心、横向轻摔。
- **战斗作用**：适合规避正面直线强攻、侧向拆招、横向空间变化、单侧重心拉扯。
- **视觉识别**：固定侧身45°，双手斜圆，横向侧移，把对手纵向冲击带到侧方。
- **禁区**：不能转成正面中正大圆，不能写成内收小圈，不能加入陈式螺旋震脚。

### 2.5 孙式太极｜手脚同步开合与活步游走

- **核心标签**：手开步开、手合步合、开合、活步、绕侧、远近切换、轻快连贯。
- **战斗作用**：适合空间变化、远近切换、绕侧反击、30秒对招流动与前后架势变化。
- **视觉识别**：手脚同步开合，活步连续绕到侧后方，开合牵引让对手多向失衡。
- **禁区**：不能手脚动作分离，不能固定站桩，不能写成陈式重型仆步或洪拳硬桥。

## 3. 五派动态组合原则

用户明确提出：**太极的分支不同，但核心一样；不需要固定主分支，系统可以自行组合太极拳的多样性。即使30秒前后架势不同，也能看出区别。**

因此太极拳专项采用“统一核心 + 动态分支组合”策略。

### 3.1 不固定主分支

生成太极打戏时，不强制先确定“主分支”。系统可以根据镜头阶段、攻防功能、节奏变化，从五派中动态抽取招式。

### 3.2 动态组合必须有统一逻辑

可以跨五派，但必须统一在太极核心链路内：

```text
接触 → 引化 → 破重心 → 控制力线 → 顺势反击 / 发放 / 摔投
```

只要这个链路成立，前后架势可以变化，例如：

```text
杨式平面引化 → 吴式侧身斜圆卸力 → 武式贴身小圈控肘 → 陈式弹抖发放
```

或：

```text
孙式活步开合绕侧 → 杨式中正按掌稳定节奏 → 陈式仆步下缠破重心 → 武式贴身暗寸轻摔
```

### 3.3 15秒动态组合规则

15秒推荐使用 **2-3个分支特征**，不要五派全上。

- 起手/导入：杨式或孙式
- 空间变化：孙式或吴式
- 贴身控制：武式
- 破重心：陈式/武式/吴式
- 终结：陈式弹抖、武式暗寸轻摔、吴式侧向轻摔、杨式平面震退、孙式开合柔摔

15秒必须避免：

- 一个镜头塞多个流派概念导致看不清。
- 连续2秒以上只有抱圆、云手、慢捋，没有新接触或破重心。
- 为了展示五派而破坏动作因果。

### 3.4 30秒动态组合规则

30秒允许前后架势明显变化，可使用 **3-5个分支特征**，但必须按阶段分配功能。

推荐结构：

```text
0-5s：杨式/孙式建立太极框架与空间
5-12s：吴式/杨式化解第一轮直线进攻
12-20s：武式/陈式进入贴身或低位破重心
20-26s：孙式/吴式制造空间变化或侧向反击
26-30s：陈式/武式/杨式/孙式选择一种终结兑现
```

30秒允许“前后架势不同”，但每次转换必须有理由：

- 对手直线冲刺 → 吴式侧身斜圆化解
- 对手贴身抢攻 → 武式小圈控肘
- 对手重心前倾 → 陈式仆步下缠或弹抖发放
- 需要换位绕侧 → 孙式活步开合
- 需要稳住节奏 → 杨式中正平面大圆

## 4. 太极硬打进攻模块

### 4.0 太极硬打总纲

太极主动进攻不是单纯控制、牵引、抓腕或压肘，而是“化打一体，引即是攻”。掤、捋、采、挒、引、化只作为破门入口，真正观赏点必须落在青龙出水、搬拦捶、震掌、野马分鬃、右靠势、连珠炮、披身伏虎等整劲硬打。

执行原则：
1. **抓腕/采腕只是开门，不是主体**：抓腕、采腕、扣腕、压肘只允许作为0.2-0.4秒的连接点，必须立刻接打击、靠打、震掌、蹬脚、肘击、摔发或发放。
2. **引化后必须兑现攻击**：掤捋引化后不能停在“控制住”，必须快速打穿门户、撞身、破下盘或摔发。
3. **整劲必须可见**：太极硬打必须体现腰胯拧合、沉肩坠肘、脚下碾转、周身合力、螺旋缠劲或斜圆力线。
4. **分层打击**：上盘封路，中盘打胸线/肋侧/肩胸线，下盘截支撑线/髋线/腰胯连接点。
5. **不能拳击化**：太极硬打不是普通直拳乱打，必须有掤捋采挒、螺旋缠劲、斜圆力线、开合和整劲发放。
6. **目标净化**：危险部位写作时转为面门外侧、下颌线外侧、胸线、肋侧、肩胸线、髋线、支撑线、下盘根基等可视表达。

### 4.1 连招1：速攻三连｜掤捋引化 → 青龙出水 → 下沉捶 → 左蹬一根

功能：15秒/30秒都可用的太极短打爆发链，适合第二段主动进攻开局或中段突然提速。核心是上手破门、中层爆发、下层补击、低位截根。

动作逻辑：
1. **掤捋引化**：对手直拳冲胸时，右前臂逆缠掤住小臂，顺势下捋采牵引，让对手重心前冲、门户打开；左掌同步撩掌虚晃面门外侧，干扰视线。
2. **青龙出水**：腰胯猛然右转成右偏马步，左掌收贴小腹蓄劲，右拳顺缠螺旋向前崩弹，短促击入对手肋侧/胸侧，中层爆发；打完不回收，顺势粘住对方手臂。
3. **下沉捶**：身体左拧下沉，右拳逆缠向下沉砸，目标净化为髋线、腰胯连接点或下盘根基；左掌立掌护中封堵反击。
4. **左蹬一根**：重心移至后腿，双拳向外崩开对方双臂，脚跟低位横蹬对手膝外侧支撑线/腰胯线，高度不过腰，蹬完落步向前继续逼进。

节奏：约0.9秒，捋引0.3秒 → 青龙出水0.2秒 → 下沉捶0.2秒 → 左蹬一根0.2秒。

禁止误写：禁止打完一拳后撤；禁止抬腿过高写成跆拳道高踢；禁止手脚分家只动手不动腰胯；禁止把下沉捶写成危险部位直击，必须净化为髋线/下盘根基破坏。

### 4.2 连招2：近身五连强攻｜高探马 → 双风贯耳 → 右靠势 → 连珠炮 → 披身伏虎

功能：30秒单挑终结链，适合太极第二段9-15秒完成压缩空间和胜负收束。核心是拿脸、封路、贴身撞身、连拳压制、摔压终结。

动作逻辑：
1. **高探马**：左手采住对手腕线向下牵引，打乱重心；右掌直线扑击面门外侧/下颌线外侧，制造对手后仰和近身空隙。拿打同步，一拿一打。
2. **双风贯耳**：采腕不松，弓步前逼，双拳弧形夹击对手头部两侧外线，重点是封堵左右闪避路线，而非危险点直击。
3. **右靠势**：双拳回收贴肋，转髋沉胯，右肩整身撞入对手胸腔/肩胸连接线，靠劲传导全身重量，打断站姿和呼吸节奏。
4. **连珠炮**：靠完粘身不分离，左右拳顺缠交替短促连发，左拳击胸线，右拳打肋侧，一收一发对拉蓄劲，三连短拳无停顿。
5. **披身伏虎**：对手被连拳逼得重心上浮，双手顺势向外挒开双臂，侧身下沉锁住肩背，向下伏压摔入地面/沙地，形成制服终结。

战术逻辑：拿脸 → 封路 → 靠身 → 连拳 → 摔压。由远至近层层压缩空间，全程贴身不脱离。时长约1.1秒，可在30秒终结段放大到2-3秒拍摄。

禁止误写：禁止把双风贯耳写成残酷危险点攻击，应写成封两侧路线、夹击头侧外线；禁止右靠势写成普通肩撞，必须写转髋沉胯、整身靠劲和胸腔受力；禁止连珠炮写成拳击乱拳，必须有顺缠、一收一发、左右交替。

### 4.3 连招3：摔打复合进攻链｜野马分鬃 → 翻身蹬脚 → 海底翻花 → 顺步肘击

功能：对手后撤、闪避、护中或试图脱离时，太极主动追攻，不重新起手。核心是绕侧、断腿、下缠、肘击、发放一体化。

动作逻辑：
1. **野马分鬃**：对手双臂护住中线时，太极左右掌螺旋分开对方双臂，一手上掀、一手下捋，45度斜步绕侧翼，缝隙中掌根/前臂直击腋下肋侧。
2. **翻身蹬脚**：对手后撤闪避时，太极腰胯180度小幅翻身，后腿低位蹬击膝外侧支撑线/腰胯线，切断逃跑路线；蹬腿同时双拳分开防护上盘。
3. **海底翻花**：蹬腿落空或对手回收时，双手逆缠向下绞锁对手小臂，向下沉压，引其弯腰失衡。
4. **顺步肘击**：趁对手俯身，弓步贴身，右肘横击侧肋，沉肩坠肘，肘后掌根向前按推，完成发放跌出。

禁止误写：禁止对手后撤后太极停下重新摆架；禁止翻身蹬脚写成大幅花哨旋踢，应是小幅翻身、低位截支撑线；禁止海底翻花变成长时间抓腕，应立刻接肘击或发放。

### 4.4 连招4：玉女穿梭式空间进攻｜斜插穿掌 → 掤捋分化 → 震脚截线 → 当头炮

功能：主要用于群战，也可在单挑中借用四角穿插步法，作为太极空间进攻变化。

单挑改写逻辑：
1. **玉女穿梭斜插步**：太极左右斜插绕外门，单掌掤撑隔开对手来拳，另一掌穿掌击胸线。
2. **连环采捋**：双手交替捋采对手手臂，左右分力打乱重心，但每次采捋必须快速接掌击、震脚或炮拳，不能长时间拆手。
3. **震脚蹬踏下层**：脚下震脚截击对手小腿/支撑线，手打上层，脚控下层。
4. **当头炮**：寻空隙沉身蓄劲，蹬地转腰，双拳齐发向前崩击胸口外侧/肩胸线，整劲冲开对手防线。

适用边界：群战时可完整使用四角移动；单挑时只借“斜插步、穿掌、震脚、当头炮”作为空间变化，不写成莫名其妙四面打人。

## 5. 招式功能归类

### 5.0 适合主动硬打 / 30秒第二段进攻升级

- 速攻三连：掤捋引化 → 青龙出水 → 下沉捶 → 左蹬一根。
- 近身五连强攻：高探马 → 双风贯耳 → 右靠势 → 连珠炮 → 披身伏虎。
- 摔打复合进攻链：野马分鬃 → 翻身蹬脚 → 海底翻花 → 顺步肘击。
- 玉女穿梭式空间进攻：斜插穿掌 → 掤捋分化 → 震脚截线 → 当头炮。

### 5.1 适合起手

- 陈式：螺旋缠丝起手抱圆
- 杨式：平面大圆抱圆起手
- 武式：贴身内收小圆抱圆起手
- 吴式：侧身45°斜圆抱圆起手
- 孙式：手脚同步开合抱圆起手

### 5.2 适合防守化解 / 引化

- 杨式：上步平面外引手、顺臂平面捋带回拉
- 吴式：横步斜向外引手、斜向捋带回拉
- 孙式：开步外放引手开合、合步内收捋带回拉
- 陈式：弓步外缠牵臂
- 武式：寸步内收引手

### 5.3 适合破重心

- 陈式：仆步下缠采手、侧身折叠螺旋挤靠
- 武式：贴身内圈捋带回拉、贴身内敛短按掌
- 吴式：斜向捋带回拉、斜圆侧向挤按
- 孙式：合步内收捋带回拉、连环活步开合云手
- 杨式：顺臂平面捋带回拉

### 5.4 适合空间变化

- 孙式：开步外放引手开合、连环活步开合云手
- 吴式：横步斜向外引手
- 陈式：弓步外缠牵臂、仆步下缠采手
- 杨式：上步平面外引手
- 武式：寸步内收引手（仅小空间）

### 5.5 适合终结前承接

- 陈式：仆步下缠采手、侧身折叠螺旋挤靠
- 武式：贴身内圈捋带回拉
- 吴式：斜向捋带回拉
- 孙式：合步内收捋带回拉
- 杨式：顺臂平面捋带回拉

### 5.6 适合终结

- 陈式：缠丝弹抖劲发放下摔
- 武式：贴身小圈暗寸轻摔
- 吴式：斜圆横向轻摔
- 孙式：连环开合活步失重侧摔
- 杨式：顺势平面圆弧下摔 / 中正平面圆弧按掌震退

## 6. 推荐动态连招链

### 连招链1：平面引化 → 侧向卸力 → 贴身小圈 → 弹抖发放

```text
杨式上步平面外引手 → 吴式横步斜向外引手 → 武式贴身内圈捋带回拉 → 陈式缠丝弹抖劲发放下摔
```

说明：杨式先用平面大圆接住直线攻击，吴式转侧身把力线带偏，武式贴身小圈锁住手腕肘关节，最后陈式在对手完全失根时弹抖发放。

### 连招链2：开合绕侧 → 斜圆破单侧重心 → 中正按掌 → 柔摔收束

```text
孙式开步外放引手开合 → 吴式斜圆侧向挤按 → 杨式中正平面圆弧按掌 → 孙式连环开合活步失重侧摔
```

说明：孙式先用手脚同步开合绕侧，吴式斜圆打乱单侧支撑，杨式中正按掌稳定压制，最后孙式多向开合牵引完成柔摔。

### 连招链3：贴身内收 → 陈式低位下缠 → 武式暗寸 → 陈式弹抖终结

```text
武式寸步内收引手 → 陈式仆步下缠采手 → 武式贴身内敛短按掌 → 陈式缠丝弹抖劲发放下摔
```

说明：武式先把战斗压到贴身小空间，陈式突然下沉低位破根，武式暗寸短按压缩对手活动，陈式借失衡完成爆发终结。

### 连招链4：杨式缓引 → 陈式缠丝 → 孙式换位 → 吴式侧摔

```text
杨式顺臂平面捋带回拉 → 陈式弓步外缠牵臂 → 孙式连环活步开合云手 → 吴式斜圆横向轻摔
```

说明：前半用杨式平缓牵引让对手持续前倾，陈式加入立体缠丝改变力线，孙式活步绕到侧面，吴式横向轻摔兑现。

## 7. 15秒调用建议

### 7.1 15秒基本策略

15秒太极必须压缩成清晰动作链，不允许长时间慢摆架。推荐6-9镜头，8-12有效动作节点。

推荐结构：

```text
0-1s：近景极推，展示抱圆/开合/侧身/缠丝的攻击前摇
1-2s：首次接触，引化对方攻击
2-3s：对手被带偏或失根，给重量反馈
3-6s：动态组合1-2个分支完成破重心
6-10s：贴身控制或空间变化，不得纯蓄力
10-12.5s：终结前承接，必须有新接触或实质命中/摔带
12.5-15s：发放/柔摔/震退/定格收束
```

### 7.2 15秒推荐组合模板

#### 模板A：防反爆发型

```text
杨式平面引化 → 武式贴身小圈控肘 → 陈式仆步下缠 → 陈式弹抖发放
```

适合：太极以弱胜强、后发制人、最后震退/侧摔对手。

#### 模板B：游走反制型

```text
孙式开合绕侧 → 吴式斜圆卸力 → 杨式中正按掌 → 吴式横向轻摔
```

适合：对手直线冲刺，太极以侧向游走拆解。

#### 模板C：贴身暗劲型

```text
武式贴身内收 → 武式短按掌 → 杨式平面捋带 → 武式暗寸轻摔
```

适合：近距离小空间打戏，镜头多拍手腕、肘、胸腹接触点。

#### 模板D：低位破根型

```text
陈式缠丝起手 → 陈式仆步下缠 → 吴式斜圆挤按 → 陈式弹抖终结
```

适合：太极展示低位破重心和爆发终结。

### 7.3 15秒禁止项

- 禁止五派全部强行出现导致信息过载。
- 禁止连续两个镜头都是抱圆/云手/慢捋，没有新接触点。
- 禁止终结前纯蓄力、纯收势、纯旋身。
- 禁止只有“气流”没有手臂接触与身体受力。
- 禁止把杨式慢摔完整铺开导致节奏拖沓。

## 8. 30秒调用建议

### 8.1 30秒基本策略

30秒允许展示太极多样性。前后架势可以不同，但必须清楚体现“阶段变化”。

推荐结构：

```text
0-5s：导入架势，可用杨式中正大圆或孙式开合活步
5-12s：第一轮化解，可用吴式侧身斜圆或杨式平面引化
12-20s：第二轮破重心，可用武式贴身小圈或陈式低位缠丝
20-26s：空间/节奏变化，可用孙式活步绕侧或吴式横向侧移
26-30s：终结兑现，可用陈式弹抖、武式暗寸轻摔、吴式横向轻摔、孙式开合柔摔或杨式平面下摔
```

### 8.2 30秒多样性规则

- 可以在前段用杨式展示中正柔化，后段改陈式展示爆发发放。
- 可以在正面引化后用吴式侧身斜圆切到侧方。
- 可以在中段被逼近时切武式贴身小圈。
- 可以在需要空间变化时切孙式活步。
- 每次分支变化都必须由对手攻击变化触发，不能无理由换架势。

### 8.3 30秒示例组合

```text
杨式平面大圆抱圆起手 → 杨式上步平面外引手 → 吴式横步斜向外引手 → 武式贴身内收小圆控肘 → 陈式仆步下缠采手 → 孙式活步开合绕侧 → 陈式缠丝弹抖劲发放下摔
```

该组合逻辑：

```text
中正接招 → 侧向卸力 → 贴身控点 → 低位破根 → 活步换位 → 爆发发放
```

## 9. 特效 / 无特效倾向

### 9.1 默认倾向

太极拳默认适合无特效或弱物理特效。画面重点应是：

- 手臂黏连
- 掌腕接触
- 腰胯转动
- 脚步虚实
- 对手重心偏移
- 衣物褶皱
- 尘土轻扬
- 镜头轻微后座

### 9.2 可添加轻特效

- 陈式：手臂接触点淡灰白螺旋细线，震脚处少量尘土，弹抖瞬间短促空气波纹。
- 杨式：平面圆弧方向的极淡白色气流细线，不能螺旋。
- 武式：接触点极淡向内收拢气流，范围贴近手腕和胸腹。
- 吴式：横向流动气流细线，跟随斜圆弧侧向流动。
- 孙式：双向开合气流细线，跟随手脚同步开合。

### 9.3 严禁特效

- 禁止大范围光波、法阵、彩色能量环。
- 禁止全屏震爆、地面大面积龟裂。
- 禁止隔空击飞。
- 禁止特效遮挡手腕、前臂、胸腹、腰胯接触点。

## 10. 与相近武学差异点

### 10.1 与八卦掌

- 八卦掌核心是绕圈走转、换掌、侧后绕位。
- 太极核心是接触引化、圆弧借力、破重心。
- 禁止把太极写成持续绕圈游走不接触。

### 10.2 与形意拳

- 形意拳核心是直进直出、五行劲、爆发穿透。
- 太极核心是引化后反击，不是主动直线硬冲。
- 禁止把太极写成形意崩拳式直线突刺。

### 10.3 与咏春拳

- 咏春偏中线快打、短桥连拳、密集拳掌。
- 太极偏黏连引化、圆转借力、重心控制。
- 禁止把太极写成日字冲拳连打。

### 10.4 与洪拳十二桥手

- 洪拳十二桥手偏低马步、硬桥、锁桥、寸劲硬控。
- 太极偏引化、圆弧、借力、柔化反制。
- 禁止把太极写成硬桥硬架、固定马步平面格挡。

### 10.5 与八极拳

- 八极偏贴身硬撞、震脚、顶肘、贴山靠。
- 太极可有发放，但必须来自引化和失衡，不是主动硬撞。
- 禁止把陈式弹抖写成八极贴山靠。

---

## 11. 给后续打戏系统的调用说明

### 11.1 系统优先判定特征

1. 必须有接触点：手腕、前臂、肘、肩、胸腹、腰胯。
2. 必须有力线变化：直线力被圆弧、斜圆、开合、小圈或缠丝改变。
3. 必须有对手失衡反馈：踉跄、侧滑、前倾、后仰、重心塌陷、侧摔。
4. 必须体现“后发制人”：太极通常不是先硬打，而是先化、再制、再发。
5. 可以动态组合五派，但必须统一在太极核心链路下。

### 11.2 最应该保留的动作

1. 抱圆 / 开合 / 圆弧引化的基础框架。
2. 黏手不脱离的接触过程。
3. 通过捋、挤、按、采改变对手重心。
4. 终结前必须有明确失根动作。
5. 终结必须是发放、柔摔、震退或顺势倒地，而不是凭空击飞。

### 11.3 最容易误写成什么

- 慢动作健身操。
- 远程气功掌。
- 咏春连拳。
- 洪拳硬桥。
- 八极硬撞。
- 八卦纯绕圈。
- 陈式被写成八极爆发，杨式被写成慢摆拍，武式被写成咏春短打，吴式被写成普通侧移，孙式被写成无规则跑位。

### 11.4 用于角色创建时

当用户不懂太极分支，只说“太极角色”时，系统应默认提供：

- 杨式：基础引化与中正框架。
- 武式：贴身小圈与近身控制。
- 孙式：活步空间变化。
- 吴式：侧向化解。
- 陈式：破重心与爆发终结。

但不要一次性强塞全部；根据用户角色气质和战斗需求动态抽取。

### 11.5 用于太极角色现有绑定

当前太极角色可优先理解为：

```text
远化劲 → 中八卦绕位 → 近咏春中线 → 贴身八极爆发
```

若调用太极拳专项，则太极拳部分可升级为：

```text
杨式/吴式引化接触 → 武式贴身小圈控点 → 陈式弹抖发放 / 孙式活步换位
```

注意：这不自动覆盖现有角色绑定，只提供更精细的太极拳动作库。
