## 0. 专项定位

八卦掌不是“绕圈闪避”，也不是原地拍掌。八卦掌在打戏系统中的核心定位是：

```text
空间调度 + 扣摆步换门 + 绕侧绕背 + 螺旋卸力 + 掌臂黏引 + 掌根短打 + 擒拿锁控 + 肩胯靠摔 + 旋身带摔 + 地面衔接 + 跨卦终结
```

### 0.1 打戏气质

- **主战气质**：游身、绕门、换掌、贴身穿插、避正打斜。
- **核心观赏度**：人物始终在走圆、换轴、错身，攻防线不断从正面切到侧门、背门、下门、斜门。
- **战斗距离**：中距切入、近身短掌、贴身控制、绕背摔投、低位地面衔接。
- **胜负逻辑**：不靠单次爆炸硬轰，而是通过连续换门让对方护架失效、支撑线错位、重心被牵出圆外，最后用掌根、肩靠、旋摔或跨卦终结兑现。

### 0.2 与旧版八卦掌的关系

旧版 `MARTIAL-BAGUA-001` 只保留“游身八卦连环掌12式”的基础入口，适合快速调用。

1. 收纳后天六十四掌完整结构。

## 1. 八卦掌核心观赏度

八卦掌观赏度来自“持续变换身体朝向与攻防入口”，不是单纯动作花。

| 观赏度来源 | 画面表现 | 执行要求 |
|---|---|---|
| 走圆 | 双脚沿弧线绕对手移动 | 必须写清顺时针/逆时针、从正门切到侧门或背门 |
| 扣步 | 前脚内扣锁住转向 | 用于急停换向、避开来拳、打开侧门 |
| 摆步 | 外摆脚开门换身 | 用于进入对手外侧、让掌从侧肋/肩窝/腕线打入 |
| 趟泥步 | 脚掌贴地滑行，不抬高 | 适合中景/斜俯拍，沙地/水面/尘土可留下圆弧脚痕 |
| 换掌 | 掌型与身体轴线同步切换 | 不能只写换手，要写肩胯、腕线、肘线、掌根落点 |
| 绕侧绕背 | 从正面压力转成侧背攻击 | 每次绕身后必须接穿掌、劈掌、压肘、锁肩或摔投 |
| 掌臂黏引 | 前臂/掌缘贴住对方手臂引开 | 必须在0.2-0.4秒内兑现为掌击、靠打、摔投或换门 |
| 旋身带摔 | 身体水平转轴带动对方重心 | 摔投必须写抓腕/压肘/肩线被带偏和落地反馈 |

## 2. 基础身法与步法

### 2.1 趟泥步

**执行动作**：脚掌贴地推进，脚跟轻擦地面，膝胯微沉，身体不高低跳动，像趟过湿泥一样沿圆弧滑行。

**打戏用途**：
- 建立八卦掌身份识别。
- 让角色不用直线前冲也能快速逼近。
- 在沙地、尘土、积水、雪地等环境中留下圆形脚痕，强化空间轨迹。

**镜头建议**：
```text
中景·45°斜俯平视·横向缓慢平移跟拍·跟随脚掌趟泥步圆弧，脚掌贴沙滑出半圆弧脚痕，膝胯微沉，身体始终面向对手。
```

### 2.2 扣步

**执行动作**：前脚脚尖向内扣，膝盖对准圆心，腰胯随脚尖内扣拧转，身体从正门快速转向侧门。

**打戏用途**：
- 打断对方直线追击。
- 把攻击线从正面移到侧肋、肩窝或肘线外侧。
- 作为“闪避同时反击”的脚步开关。

### 2.3 摆步

**执行动作**：外脚向圆外摆开，胯部打开，肩线随之外展，掌从腰侧或肋下穿出。

**打戏用途**：
- 进入对手外侧门。
- 配合穿掌、劈掌、推掌、压肘。
- 承接扣步形成“扣摆换门”。

### 2.4 扣摆换门

**标准链**：
```text
扣步让开来拳 → 摆步开外门 → 肩胯随脚步水平拧转 → 前掌黏住来臂外摆 → 后掌从肋下穿入 → 对手肩线被带偏 → 下一击掌根/肘线/肩靠兑现
```

### 2.5 走圆与换轴

**执行动作**：脚下走圆，身体始终面向对手，肩胯围绕对方中心线转动；换轴时用扣步或摆步把自身旋转轴从正面切到侧方。

**禁写**：
- 禁止写成“绕着对手转圈但不攻击”。
- 禁止无接触空转。
- 禁止360°环绕运镜代替八卦掌走圆。镜头只能半环绕、斜俯、横移跟拍或中景跟拍。

## 3. 攻防执行铁律

1. **掌中带步，步中带掌**：任何掌法必须伴随脚步换门；任何走圆必须带出攻击或控制。
2. **避正打斜**：第一道直线攻击可通过扣步/摆步让线，但第二拍必须从侧肋、肩窝、肘线、腕线或背门反击。
3. **绕身不空转**：每次绕侧/绕背后，必须接穿掌、劈掌、托肘、压腕、锁肩、靠摔或回身重击。
4. **掌臂黏引快速兑现**：抓腕、压肘、采腕、托肘只能作为短连接，0.2-0.4秒内必须兑现为打击、摔投或空间变化。
5. **手脚同帧**：中景对招要同时写手部桥接与脚步扣摆，不能只写上半身拍掌。
6. **对手必须反咬**：八卦掌主攻时，对手要持续用拳、腿、肘、膝、抓腕或截腿反压，八卦掌再用换门拆掉，禁止单方教学演示。
7. **防守递进**：远距第一道攻击可让线；贴近二段追击必须用前臂黏引、托臂、压肘、扣腕、切腕、按膝等接触式防守。
8. **大幅观赏动作必须有因果**：转身、绕背、旋摔、地面衔接都必须来自落空惯性、扣摆换门、抓腕牵引或被压迫后的顺势变线。

## 15. 15秒/30秒调用规则

### 15.1 15秒调用规则

15秒使用八卦掌时，不能慢慢绕圈铺垫，必须把八卦掌压缩成“走圆即攻击”的爆点结构。

推荐结构：
```text
0-1.5s：扣摆换门直接进入接触，第一掌或第一托臂必须打到/接到。
1.5-5s：中近景手部对招，前臂黏引、托肘、压腕、穿掌连续出现。
5-8s：空间变化，绕侧/绕背/低位切入制造视觉钩子。
8-12s：情绪拐点，回身劈掌、旋身带摔或掌根短震破防。
12-15s：终结三段式，破局→绽放→余震，最后一帧停在命中/摔落/气爆高点。
```

### 15.2 30秒调用规则

30秒使用八卦掌时，八卦掌要体现“完整武打调度”：

第一段：
```text
0-1s：单人起手识别，趟泥步、扣摆步、掌型、肩胯和眼神明确；对手不入镜。
1-2s：脚步启动，脚掌贴地滑出圆弧。
2-6s：第一轮近身初探，穿掌/托臂/压肘/扣腕与对手反咬同拍。
6-7.5s：受力退开，脚步定住或沿圆弧卸力。
7.5-12s：第二轮改变攻击语言，从手部穿掌改成低位破根、旋身带摔或绕背劈掌。
12-15s：阶段破招与空间对位，禁止终局，留下第二段可承接的方位和控制点。
```

第二段：
```text
0-2s：承接第一段结尾，双方起手式变化；八卦掌方可从试探掌架改为压低重心、扣摆换门、肩胯蓄力的凌厉掌架。
2-5s：高密度拆招，平均每秒约2组有效攻防；手部轨迹要有左托右穿、右压左抽、左扣右掌根、右切腕左回中。
5-6.5s：重击反馈和稳身恢复。
6.5-9s：攻击思路变化，例如低位破根、绕背、抓腕旋身带摔、地面衔接。
9-12s：控制点成立，压肘/扣腕/肩线带偏后立刻接摔投或重掌。
12-15s：终结前3秒压防链，连击压防→防线错位→破防控制点成立→重击终结。
```

| 容易串味对象 | 八卦掌正确写法 | 禁止写法 |

## 18. 八卦掌在15/30秒短视频打戏中的调用规则

> 本节为短视频执行优先级规则。生成15秒/30秒打戏时，八卦掌的表现重点不是完整展示传统走圆，而是把扣摆、趟泥、换门、转身、穿掌、劈掌、托掌、压肘、侧推等元素压缩进高密度攻防中，形成“打着变、变中破、破后连”的观赏结构。

### 18.1 总定位：短视频八卦掌不是“走圆展示”，而是“高速变线破防”

15秒/30秒短视频中的八卦掌，不能把观赏性理解成慢慢绕敌、展示步法、等待机会。完整走圆、长期游身、铺垫式身法更适合长电影或教学展示，不适合短视频爆点结构。

短视频八卦掌的核心表达是：

```text
高速变线 + 多方向掌法 + 声东击西 + 防守反打 + 破防后高密度连招
```

执行时必须让观众在极短时间内看见：

- 八卦掌“变”的能力：掌法方向、身体角度、攻击高度、力线持续变化。
- 八卦掌“快”的能力：前几招能被对手勉强防住，后续打击点越来越快、越来越刁钻，对手防线跟不上。
- 八卦掌“破”的能力：用上打下、左引右穿、外劈内刺、虚掌真穿等声东击西方式撕开防守。
- 八卦掌“连”的能力：破防后直接接8连、9连、12连等高密度终结连招。

一句话执行原则：

```text
不绕给观众看，而是边打边换门；不慢慢找机会，而是用连续变线把机会打出来。
```

### 18.2 步法使用规则：步法必须嵌入攻防

八卦掌可以有扣步、摆步、趟泥步、换门、绕侧、转身，但这些步法在15秒/30秒短视频里只能作为“攻击发力和空间变化机制”，不能独立占用镜头时长。

正确写法必须满足：

```text
步法出现 = 同时产生攻击 / 拆招 / 破防 / 反击 / 命中 / 控制线变化
```

推荐执行方式：

- 扣步半拍换门，同时右横掌切向面门外侧，左穿掌从下线攻向腰腹侧线。
- 摆步抢侧门，同时上掌托开对手前臂，下掌穿入肋下侧线。
- 趟泥步贴沙滑半步，同时侧部推掌顶开胸前护架，让对手肩线偏转。
- 身体短转，同时左掌压肘、右掌回身劈向侧颌线外侧。
- 侧身绕出半肩位，同时掌根短震打胸前护架中心，沙粒被脚掌拧起。

时间控制：

```text
0.2-0.4秒：扣摆换门、压肘、托臂、穿掌等小幅变线。
0.4-0.8秒：侧部推掌、小幅周边移动、回身劈掌、转身穿掌。
超过1秒仍无新攻防事件，即判定为节奏错误。
```

禁止把以下内容当成短视频八卦掌主体：

- 绕敌半圈寻找机会。
- 走圆两秒展示步法。
- 中远景空镜交代八卦步。
- 后拉镜头专门看脚下走圆。
- 只写“游身绕步”但没有接触点、攻击点和对手反应。

### 18.3 速度与力量规则：八卦掌不是轻飘，是高速多点爆发

八卦掌的灵活不是“轻轻绕开”，而是短时间内用身体角度、掌法方向和打击点变化制造连续压迫。输出时必须体现速度感、力量感和声音质感。

动作质感关键词：

```text
唰、嚓、啪、砰、短震、贴身炸开、掌风抽响、衣袖爆响、沙粒跳起、透明气爆贴衣扩散
```

推荐动作表达：

- 右横掌“嚓”地切向头部外线，左肩顺势下沉，左穿掌“唰”地钻向腰腹侧线。
- 对手抬臂防头的瞬间，凛羽身体下压发力，右穿掌从肘下穿出，掌尖点刺胸前护架中心。
- 左掌压肘、右掌劈肩、身体短转，掌根短震“砰”地把对手护架打散。
- 连续掌影不是空泛残影，必须拆成可见动作：横掌、穿掌、托掌、劈掌、点刺、掌根短震、回身推掌。

力量反馈必须明确：

- 对手手臂被托开、压低、外摆、打散。
- 肩线被侧部推掌顶偏。
- 胸前护架被掌根短震打塌。
- 腰腹侧线被穿掌逼退半步。
- 沙面出现脚掌拧痕、碎沙被掌风和脚步震起。

### 18.4 变线破防规则：声东击西，多方向打击点

八卦掌短视频的核心观赏点是“变”。对手可以防住前几招，但必须在后续更快、更刁钻、更多方向的打击点中逐渐跟不上。

推荐破防结构：

```text
上线诱防 → 下线穿入 → 侧线压肘 → 中线短震 → 回身补击 → 高密度连招
```

可用打击点组合：

- 头部外线 + 腰腹侧线。
- 面门外侧 + 肋下侧线。
- 胸前护架中心 + 肩线外侧。
- 侧颌线外侧 + 小腿外侧支撑线。
- 上掌托肘 + 下掌穿腹。
- 左劈掌压头线 + 右穿掌破腰线。

典型声东击西写法：

```text
凛羽左劈掌先压向梦梦头部外线，逼梦梦抬臂格挡；同一拍身体下沉，右穿掌从梦梦肘下钻入腰腹侧线，掌风“唰”地贴衣炸开；梦梦刚要收肘，凛羽扣步换门，左掌压肘外摆，右掌回身劈向侧颌线外侧，连续三处打击点让梦梦防线慢半拍。
```

注意：变线必须写清身体部位和力线，不能只写“连续变招”“掌影缭乱”。

### 18.5 连招调用规则：8-12连作为终结招式池

用户提供的八卦掌8连、9连、12连连招，不是静态资料，也不是只能原样照搬的套路，而是短视频终结段的高密度招式池。生成提示词时必须根据节奏和时长灵活调用。

调用建议：

```text
8连：适合2-3秒短爆发，用于15秒中段破防或30秒第二段前半段反打。
9连：适合3-4秒连续压制，用于阶段性优势建立。
12连：适合4-6秒终结段，用于凛羽胜、破防后连续点打、多打击点覆盖。
```

使用原则：

- 可以拆分、重组、压缩，但必须保留“多方向、多高度、多打击点、快速变线”的骨架。
- 连招必须由破防动作自然接入，不能凭空开始。
- 每2-3招至少改变一次高度、方向或打击点。
- 点穴类连招必须净化为二次元可视接触线，禁止写真实穴位和真实伤害机制。
- 终结连招必须有明确节奏递进：前几招破护架，中段打乱重心，最后双掌重击或掌根短震完成胜负点。

可用终结连招骨架：

```text
压肘开门 → 横掌切头线 → 穿掌攻腰线 → 托掌掀臂 → 劈掌压肩 → 点刺胸前护架 → 回身掌根短震 → 双掌重击定格
```

点打终结骨架：

```text
上点面门外侧 → 中点胸前护架中心 → 侧点肋下侧线 → 下点小腿外侧支撑线 → 回身劈掌 → 双掌短震破防
```

### 18.6 输出禁区：防止再次写偏

生成八卦掌短视频打戏时，以下写法视为错误：

- 禁止用2秒或更长时间单独展示绕圈、走圆、游身。
- 禁止把空间变化写成空镜移动，空间变化必须由攻击、拆招、破防或反击带出。
- 禁止连续超过1秒没有新攻防事件。
- 禁止把“中近景为主”理解成全程固定中近景；仍需按打戏铁律切换中景、近景、特写、侧拍、正拍、过肩等镜头。
- 禁止只写“掌影连绵”“八卦掌连打”而不拆出横掌、穿掌、劈掌、托掌、压肘、点刺、掌根短震等具体动作。
- 禁止把八卦掌写成轻飘、慢、柔、绕、等机会。
- 禁止把点穴写成真实医学穴位、真实伤害原理或武侠隔空封穴。
- 禁止把防守反打写成先完整防守、停顿、再进攻；必须同拍完成托、压、穿、劈、点。

正确倾向：

```text
打着换位，换位同时打；防守同时反打，破防立刻连；声东击西，多点压迫。
```
