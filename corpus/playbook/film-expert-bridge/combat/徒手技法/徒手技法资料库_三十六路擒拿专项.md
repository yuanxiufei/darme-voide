## 1. 武学总定位

- 武学类型：传统少林全域擒拿体系，纯手脚协同锁控技法；双手为核心控制手段，腿只负责卡位、截步、锁根辅助，不作为主力输出。
- 差异定位：区别于鹰爪功硬抓硬锁，三十六路擒拿主打顺势借力、缠丝卸力、杠杆分筋，覆盖腕、肘、肩、颈、指、膝等全身关节线。
- 动作气质：绵密缠粘、顺势巧拧、贴身贴靠、小幅辗转；不蛮力硬顶，粘手不脱，锁必到位。
- 核心优势：全关节覆盖，可单拿、连环锁、反制拳腿突进；借力卸力机制完整，以小制大；上肢锁控与低位锁根同步制造双重失衡。
- 核心弱点：极度依赖贴身距离，离开贴身区间失效；无远程击打、无高位腾空重击；遇同等贴身擒拿容易僵持，缺少单一爆发硬杀伤。

### 1.1 独家视觉识别铁律

1. 双手以缠、绕、拧、托、压为主，极少鹰爪式硬扣死抓；重点是顺势粘腕走劲。
2. 身形小幅侧身绕靠，不正面沉桩硬刚，持续跟随对手力道辗转。
3. 腿法只有低位截步、卡位踏膝、锁踝寸步，无扫腿、飞踢、顶膝重击。
4. 连招连贯缠绕，一拿接一锁，无缝衔接，无一招一停的硬断节奏。

### 核心闭环

```text
搭手粘引 → 顺力缠腕 → 托肘压肩 → 低位锁根 → 多层关节锁控 → 制服闭环
```

## 2. 武学核心打法逻辑

### 2.1 起手逻辑

侧身虚步贴身起架，一手虚搭对手前臂粘手引力，另一手藏于腰侧预备托肘拧折；低位寸步小幅前移卡住对手后撤下盘线路。顺着对手出拳或出腿力道缠绕，不主动硬冲，以“引带拿”为前置。

### 2.2 压制逻辑

三层连环递进压制：

```text
虚搭粘手引开对手发力重心 → 缠腕拧折限制单侧上肢 → 托肘压肩/侧压肩颈线叠加低位锁根
```

全程顺着对手力道转向，每一层锁拿同步低位腿切断支撑，让对手发力即被卸、后撤即被卡。

### 2.3 破重心逻辑

上段控制肩颈线，中段控制腕、肘、肩线，下段控制支撑脚外侧与下盘支撑线。依靠杠杆拧转制造躯干扭转、上身侧倾、下肢单膝跪落的三重失衡。最终提示词不写现实关节伤害教学，转译为腕线被锁、肘线被托、肩线被压、下盘支撑线被切断。

### 2.4 防守/反击逻辑

无独立格挡，以搭手粘臂代防。对手拳脚攻来，手掌轻搭对方肢体顺着力道绕转，同步侧身变线、低位截步卡位，粘拿、卸力、锁关节三动作同帧完成。防御即擒拿反击，不后撤硬抗。

### 2.5 空间变化逻辑

仅小幅侧身绕靠、前后寸步卡位、90度以内小幅变线。禁止180度大翻身、腾空跨越、长距离外放走位。主动缩小间距，永久维持贴身缠拿区间。

### 2.6 终结逻辑

两套标准闭环终结：

1. 连环缠腕拧肘 + 压肩锁颈线，上身关节线被强制扭转，形成僵直制服。
2. 低位踏膝锁踝断根基，同步托肘压肩，对手单膝跪地全身受制。

全部贴身站立或半跪完成，不进入地面躺卧缠斗。

## 6. 固定连招闭环链

### 连招链1：粘手引力 → 单腕缠拧 → 托肘压肩 → 踏膝锁根

基础柔拿牵制链。轻柔搭手顺着对手出拳力道引动，顺力缠绕腕线制造单侧失控，托肘压肩形成肩肘双层锁控，寸步锁根切断后撤。

```text
1 → 2 → 3 → 4
```

### 连招链2：同步缠拿反打 → 连环双腕交替 → 翻身变线绕袭

均衡变线压制链。对手突进瞬间搭手卸力同步缠腕锁根，随后双手交替缠绕双腕，小幅翻身绕至侧后反拿上臂。

```text
6 → 5 → 12
```

### 连招链3：多层肩肘锁控 → 锁颈侧压 → 全身多重关节制服

终极制服链。肩肘双层杠杆持续挤压，肩颈线侧压造成上盘无法回正，四层连续缠锁叠加低位锁根，对手单膝跪地完全受控。

```text
7 → 9 → 11
```

## 7. 15秒高密度短打执行规范

### 7.1 适配核心逻辑

15秒短打选用0.4-0.7s短周期缠拿招式，剔除0.9-1.1s长全域走位和全套慢终结。全程坚守侧身柔劲架构，禁止大幅翻身、长循环复合锁，以搭手、单缠腕、托肘、同步反击、低位踏膝卡位为主。

### 7.2 必保留招式

```text
1 侧身搭手粘腕起势
2 顺力缠腕单拧
3 托肘压肩锁肢
4 低位踏膝锁根卡位
6 侧身同步缠拿反击
```

### 7.3 15秒慎用/禁用招式

- 禁用或极少用：13 全域寸步长循环走位、11 全套四层多重终结慢连击、7 长周期肩肘复合锁。
- 可压缩使用：7 可拆成“托肘+压肩”单节点，11 可简化为“三点锁控制服定格”，不得完整慢展开。

### 7.4 15秒推荐结构

| 时间 | 功能 | 推荐招式 | 画面重点 |
|---|---|---|---|
| 0-1.5s | 开局接触 | 1 侧身搭手粘腕起势 → 2 顺力缠腕单拧 | 前1.5秒必须完成搭手接触与缠腕 |
| 1.5-3s | 破架锁控 | 3 托肘压肩锁肢 | 近景拍肘线被托、肩线被压 |
| 3-5s | 破重心 | 4 低位踏膝锁根卡位 | 低位镜头拍支撑线被卡住 |
| 5-8s | 防守反击 | 6 侧身同步缠拿反击 | 对手反扑，搭手卸力、缠腕、锁根同帧完成 |
| 8-11s | 连续压制 | 5 连环双腕交替缠拿 | 双手交替缠腕，不能写成鹰爪死抓 |

### 7.6 15秒自检清单

1. 前1.5秒是否发生搭手/缠腕接触？没有则不合格。
2. 是否全程维持0.4-1.2m贴身缠拿区间？拉到远距对峙则不合格。
3. 是否以手部缠绕锁控为主，腿只负责低位卡位？腿法抢戏则不合格。
4. 是否出现鹰爪硬扣、龙爪虚晃、五行拳冲击、纯腿输出？出现则串味。
5. 6-12秒是否仍有缠腕、托肘、压肩、锁根等新攻防接触？纯蓄力/纯特写不合格。

## 8. 30秒完整对战分段流程

### 0-5s 起手定型

第1式侧身搭手粘腕建立柔和缠拿基础架构，低位寸步小幅卡位，试探对手发力习惯，确立顺势柔拿节奏。

### 5-12s 首轮攻防互换

第8式后撤分层粘手缓冲 + 第6式同步缠拿反击。对手突进时，搭手卸力、侧身变线、缠腕锁根同帧完成，初次建立上下肢双重锁控主动权。

### 12-20s 全域多层缠拿压制

第2式缠腕拧折 + 第5式连环双腕交替 + 第10式低位截步反缠，持续扭转对手躯干，全方位封锁上下肢挣脱路线。

### 20-26s 肩颈深度锁控铺垫

第12式翻身变线绕袭衔接第7式肩肘双层杠杆锁、第9式肩颈线侧压，多重关节线受控叠加头部侧转，单膝失衡彻底铺垫终结条件。

### 26-30s 全身多重擒拿闭环制服

接入第11式四层连续关节锁控连击，多点同步压制，对手单膝跪地无法挣脱，完成三十六路擒拿标准制服收尾。

### 30秒必展示核心特质

```text
侧身柔劲粘手 / 顺力缠绕不蛮力 / 肩肘颈膝全域关节锁控 / 寸步低位卡位锁根 / 无腾空无硬抓 / 巧劲克制刚猛拳脚
```

## 10. 流派防混区分铁律

### 10.1 对比鹰爪功

- 鹰爪功：硬爪紧实扣锁、正面沉桩、硬力分筋、抓住不放。
- 三十六路擒拿：柔劲搭手缠绕、侧身小幅辗转、借力卸力、不硬抓死扣。
- 防混核心：删除紧实鹰钩硬爪动作，保留轻柔顺力缠拿体系。

### 10.2 对比龙爪手

- 龙爪手：龙形侧身游走、虚实探爪、扣肩锁颈线、灵动切门。
- 三十六路擒拿：小幅侧身、无虚爪晃招、侧压肩颈线不掐喉、无腾空动作。
- 防混核心：禁止大范围龙形游走、腾空垫步、虚爪诱敌。

### 10.3 对比形意五行拳

- 五行拳：握拳直线冲击、裹身中正、拳为主杀、腿辅断根。
- 三十六路擒拿：无握拳击打，纯缠绕锁控，腿仅卡位不输出。
- 防混核心：全程无崩拳、劈拳、钻拳、炮拳、横拳等击打招式。

### 10.4 对比纯腿武学

- 纯腿武学：腿法为主要杀伤，手只格挡平衡。
- 三十六路擒拿：双手缠绕锁控为主，腿仅卡位辅助无杀伤。
- 防混核心：禁止腿法作为输出，删除各类腾空、扫踢重击腿招。

### 10.5 对比柔术/地面缠斗

- 柔术/地面缠斗：可进入倒地、抱摔、地面降服。
- 三十六路擒拿：站立/半跪贴身制服，不躺卧地面缠斗。
- 防混核心：终结是单膝跪落或站立僵直受控，不写地面滚缠。

## 11. 执行层净化规则

真实危险细节必须转译为可视化影视动作语言，不输出教学式伤害目标。

| 原始危险表达 | 执行层净化表达 |
|---|---|
| 腕关节剧痛、折腕 | 腕线被缠住、手臂被带偏、手掌无法回收 |
| 肘关节拧折 | 肘线被托起、前臂被固定在胸前 |
| 肩关节压锁、锁骨剧痛 | 肩线被压低、上身被迫侧倾 |
| 锁颈、颈侧压迫 | 肩颈线被侧压、头肩方向被带偏 |
| 膝盖外侧、脚踝韧带 | 支撑脚外侧被卡住、下盘支撑线被切断 |
| 多关节制服/重伤打法 | 多点被同时锁控、单膝跪落、无法拉开距离 |

## 12. 系统识别与写作禁令

### 12.1 触发关键词

```text
三十六路擒拿 / 36路擒拿 / 擒拿十三式 / 少林擒拿 / 搭手粘腕 / 顺力缠腕 / 缠腕拧折 / 托肘压肩 / 低位踏膝 / 锁根卡位 / 肩肘复合锁 / 锁颈侧压 / 全身多重关节锁控 / 柔劲擒拿 / 贴身制服 / 借力卸力 / 杠杆关节锁控
```

### 12.2 绝对不可删减三大标志性动作

1. 侧身搭手粘腕柔劲起势。
2. 顺力缠绕单腕杠杆锁。
3. 托肘压肩双层关节复合锁。

### 12.3 高频写作误写禁令

1. 禁止误写鹰爪硬扣、紧实钩爪、硬力硬掰关节。
2. 禁止误写大幅龙形游走、腾空垫步、虚爪晃招。
3. 禁止加入握拳击打、劈崩钻炮等重拳杀伤。
4. 禁止增加腾空飞腿、大范围扫腿作为输出。
5. 禁止正面四平沉桩硬刚、逆力对抗、不懂顺势卸力。
6. 禁止进入地面躺卧缠斗，三十六路擒拿默认站立/半跪制服。

### 12.4 15秒硬性保留规则

保留侧身柔劲架构、搭手缠腕、托肘卡位短连招；舍弃长周期全域走位、四层完整关节终结慢连击。

### 12.5 30秒硬性补充规则

完整覆盖：

```text
粘手诱敌 → 缠腕锁肢 → 变线绕袭 → 肩颈多层锁控 → 低位腿锁根基 → 全身多重关节制服
```

突出顺势借力、全域关节锁、巧劲制服、无硬力硬刚的专属擒拿特质，与爪功、拳法、纯腿武学彻底区分。

## 14. 终极定调

三十六路擒拿不是鹰爪功的软版，也不是龙爪手的地面版。它的核心画面是：

```text
轻柔搭手 → 顺力缠腕 → 托肘压肩 → 低位锁根 → 肩颈线侧压 → 单膝制服
```

它不是靠打击赢，而是让对手每一次发力都变成新的锁控入口；不是硬抓死扣，而是粘住、顺走、绕开、托起、压下、卡根，最后让对手在贴身区间失去所有发力空间。
