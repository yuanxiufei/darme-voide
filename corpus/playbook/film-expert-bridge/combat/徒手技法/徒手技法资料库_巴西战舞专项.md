## 1. 统一总定位

巴西战舞 / 卡波耶拉在本系统中不是单一动作风格，而是由三条主轴组成的统一技法库：

1. **雷吉奥纳尔**：现代竞技高空主轴，强调直立Ginga、高速突进、腾空飞踢、360度直立高旋踢，是白鸽最优主轴。
2. **安哥拉**：传统低位古传主轴，强调永久低伏、地面滚转、低旋踢、贴地扫腿和近身压迫，只作低位辅助或特殊低位角色主轴。
3. **当代综合**：融合通用主轴，兼容高空与低位，但必须按镜头阶段选择主路线，不等于三派全塞。

### 1.1 总体防混铁律

- 卡波耶拉规避以动态位移为核心：Ginga摆动、下潜、滚转、跳闪、变线，禁止写成原地硬挡硬抗。
- 禁止混入东亚武术框架：无二字马、中线寸拳、摊膀伏、太极云手、固定扎马定型。
- 禁止混入泰拳固定站姿膝肘硬顶；卡波耶拉即使近身也应保留摆动、低位绕袭或高空变线气质。
- 旋踢必须锁定为水平旋身、直立高旋或贴地水平低旋，禁止写成竖向后空翻、无方向空中乱转。

## 2. 三派主轴速览

### 2.1 雷吉奥纳尔：高空竞技主轴

**定位**：现代竞技卡波耶拉，高空踢技压制、远距离突进和标准化序列最强。  
**核心识别**：直立舒展Ginga、大步箭步、本桑推踢、马尔泰罗腾空飞踢、阿尔马达360度直立高旋踢、连环高旋踢。  
**使用原则**：适合短视频爆点、白鸽主攻、舞台高光、高空腿法压制。

**必保留动作**：
- 直立舒展Ginga高架
- 本桑直线推踢
- 大步箭步直线突进
- 马尔泰罗腾空飞踢
- 阿尔马达360度直立高旋踢
- Rasteira近距离短扫腿

**禁区**：
- 禁止深度低伏Negativa、长时间Role地面滚转、近身头撞肘击。
- 禁止写成普通跆拳道原地高踢；必须保留Ginga摆动和巴西战舞式节奏。
- 禁止把阿尔马达写成竖向翻腾或后空翻。

### 2.2 安哥拉：低位古传主轴

**定位**：传统地面低位卡波耶拉，重心贴地、缓慢潜行、低位绕袭和近身压迫。  
**核心识别**：低位Ginga、Negativa深度下潜、Role地面横向滚转、Meia Lua低位水平旋踢、Rasteira贴地扫腿。  
**使用原则**：适合低位突围、狭小空间、地面反杀、诡诈近身角色；对白鸽只能作低位辅助，不能改为主轴。

**必保留动作**：
- 低位潜行Ginga
- Negativa深度低躲
- Role地面横向滚转
- Meia Lua低位水平旋踢
- Rasteira贴地扫腿
- 贴身短击 / 肩胸顶进式压迫（执行层净化后使用）

**执行层净化**：
- 资料层可理解“头撞、肘击、眉心、下颌、太阳穴、韧带”等原始动作逻辑。
- 最终Seedance提示词必须转译为：肩胸短促顶进、额前贴近压迫、面门外侧受压、护架震开、胸口/肋侧受击、支撑脚外侧被扫、重心坍塌。
- 禁止输出现实伤害教学式表达，如“撞鼻梁、撞眉心、断脚踝韧带、血肉杀伤”。

### 2.3 当代综合：高低自由融合主轴

**定位**：影视通用融合卡波耶拉，兼容雷吉奥纳尔高空与安哥拉低位。  
**核心识别**：双模式Ginga、低伏与直立互切、地面滚转接高空踢、双模式扫腿、混合同步反击。  
**使用原则**：适合芭乐、通用角色、混搭对战；但必须有主路线，不能杂技大杂烩。

**三种安全路线**：
1. 高空主线 + 低位一次变线。
2. 低位主线 + 高空一次爆发。
3. 高低交替主线，仅建议30秒使用；15秒禁止频繁来回切换。

## 4. 三派连招链

### 4.1 雷吉奥纳尔高空链

`本桑推踢 → 大步箭步突进 → 马尔泰罗腾空飞踢 → 阿尔马达直立高旋踢`

逻辑：推踢迫使后撤并抬臂，箭步压缩距离，腾空飞踢打出躯干失衡，落地立刻直立高旋踢扫头侧完成高空压制。

### 4.2 安哥拉低位链

`Negativa下潜 → Role地面滚转 → Meia Lua低旋踢 → 贴地Rasteira扫腿`

逻辑：下潜避开上盘攻击，滚转抢侧门，低旋踢震荡上盘，贴地扫腿切断支撑。执行层必须净化为低位绕袭和重心破坏，不写现实脆弱部位伤害。

### 4.3 当代综合桥接链

`双模式Ginga → 高空突进或低位下潜 → 双模式扫腿 → 单一路线终结`

逻辑：先选择高空或低位主路线，中途只允许一次姿态切换服务破重心，终结仍回到当前主路线完成。

## 5. 15秒调用规则

### 5.1 总规则

- 15秒必须选择一个主轴：高空雷吉奥纳尔 / 低位安哥拉 / 当代综合单路线。
- 15秒禁止三派频繁来回切换；最多“主轴 + 1个辅助变线点”。
- 每个镜头必须有攻防、位移、受击或破重心功能，禁止纯Ginga长展示、纯滚转、纯蓄力。
- 高空旋踢必须写明水平旋身/直立高旋/高位横扫，避免竖向翻腾。

### 5.2 雷吉奥纳尔15秒推荐

`直立Ginga试探 → 本桑推踢 → 大步箭步突进 → 马尔泰罗腾空飞踢 → 阿尔马达直立高旋踢收尾`

适合：白鸽主轴、高空爆点、踢技压制。

### 5.3 安哥拉15秒推荐

`低位Ginga诱敌 → Negativa下潜 → Role滚转变线 → Meia Lua低旋踢 → 贴地扫腿破重心`

适合：低位反杀、狭小空间、地面变线。执行层净化近身顶撞与目标部位。

### 5.4 当代综合15秒推荐

- 高空主线：`直立Ginga → 腾空突进 → 飞踢 → 直立高旋踢`
- 低位主线：`低伏Ginga → 下潜 → 滚转 → 低旋踢/扫腿`
- 只允许一次桥接，例如“飞踢落地后短暂低扫断支撑”，不要反复高低切。

## 6. 30秒调用规则

30秒可以完整展示三派差异，但仍需分段而非乱炖：

1. 起手：根据角色主轴建立Ginga姿态。
2. 第一轮：主轴招式建立压制，例如高空推踢/飞踢，或低位下潜/滚转。
3. 第二轮：用辅助分支补短板，例如高空角色加入一次低位短扫，低位角色加入一次起身反踢。
4. 中段：可短时使用当代综合桥接，但必须解释为对手距离变化或攻防压力触发。
5. 终结：回到主轴完成，不用三派混合终结。

## 7. 角色适配规则

### 7.1 白鸽

**默认主轴：雷吉奥纳尔高空竞技 + 少量当代综合桥接。**

可用：直立Ginga、马尔泰罗腾空飞踢、阿尔马达直立高旋踢、本桑推踢、大步箭步突进、短Rasteira、阿乌类翻转。  
慎用：Negativa低伏、Role地面滚转，只作低位突围或起身反踢铺垫。  
禁用：安哥拉永久低伏主轴、长时间地面黏缠、头撞肘击主攻。

白鸽终结仍优先540度水平旋风腿：必须写“身体水平旋身如陀螺横转”，禁止竖向翻腾/后空翻。

### 7.2 芭乐

**适配：当代综合的高低切换辅助，不作为纯卡波耶拉角色。**

可用：翻转空间变化、低位绕袭、柔术进入前的变线、起身反击。  
避免：写成白鸽式雷吉奥纳尔高空踢法主攻。

### 7.3 女帝

**适配：单个卡波耶拉低位反击动作，不绑定主轴。**

可用：倒立托马斯回旋踢、安哥拉侧旋踢、马尔特洛翻转踢作低位反击和空间变化。  
禁用：白鸽式弹跳空翻游走、安哥拉长期低伏缠斗。

### 7.4 临时新角色

- 高空舞台/踢技主攻：优先雷吉奥纳尔。
- 低位诡诈/地下缠斗：优先安哥拉，但执行层净化危险目标。
- 通用灵巧/混搭：选择当代综合，但必须指定高空或低位主路线。

## 8. 特效与无特效规范

### 8.1 雷吉奥纳尔

- 高空飞踢/直立高旋踢：长条、上扬、厚重的接触波纹；特效颜色服从角色主色。
- 落地：可有环形尘土和衣物风压，但不要全屏爆炸。

### 8.2 安哥拉

- 贴地滚转/低扫：细小、贴地、水平的尘纹和摩擦光点。
- 低位命中：小范围接触波纹，不上扬、不爆炸。
- 禁止高空长条气流、玄幻光圈、全屏震屏。

### 8.3 当代综合

- 高空阶段用雷吉奥纳尔特效。
- 低位阶段用安哥拉特效。
- 同一镜头内不要混用两套特效逻辑。

## 9. 防混规则

1. 雷吉奥纳尔不是跆拳道：必须保留Ginga摆动、大步箭步、巴西战舞节奏。
2. 安哥拉不是地堂腿：它是低伏、滚转、低旋、贴地扫的卡波耶拉地面体系，不写少林仆步、罗汉定式。
3. 当代综合不是大杂烩：必须有主路线，15秒尤其禁止高低频繁乱切。
4. 卡波耶拉不是泰拳：禁止固定站姿硬顶、膝肘压迫主导。
5. 卡波耶拉不是咏春：禁止二字马、中线寸拳、摊膀伏。
6. 卡波耶拉不是太极：禁止云手、引化、失重柔摔、柔和长线气流。

## 10. 执行层净化规则

资料层中的真实武术术语用于理解动作，不直接全部输出给Seedance。最终提示词需要正向可视化、二次元化、非教学化：

| 资料层表达 | 执行层建议写法 |
|---|---|
| 头撞眉心/鼻梁/下颌 | 额前贴近压迫、肩胸短促顶进、面门外侧受压后仰 |
| 肘击膈肌/肋骨 | 肋侧短促撞击、护架被顶开、躯干侧向蜷缩 |
| 扫断脚踝/韧带 | 贴地扫击支撑脚外侧，重心坍塌、单膝下沉 |
| 太阳穴重击 | 头侧/肩颈线受高位横扫冲击，身体横向踉跄 |
| 血肉杀伤/古传杀术 | 低位贴身压迫、重心拆解、连续受击反馈 |

## 11. 系统调用说明

1. 生成白鸽相关打戏时，若涉及巴西战舞，优先调用本专项的雷吉奥纳尔高空主轴，并结合白鸽角色卡中的36路腿法、谭腿、跆拳道和540度水平旋风踢铁律。
2. 用户只说“巴西战舞/卡波耶拉”但没有角色定位时，先判断是高空竞技、低位古传还是高低混合；如需直接生成，默认当代综合通用框架，但输出时仍选择单一主路线。
3. 15秒最多主轴+1个辅助点；30秒可主轴+1个补强分支；不得三派无因果乱炖。
4. 所有危险目标与真实伤害表达必须执行层净化。
5. 所有旋踢、飞踢、翻转必须写清运动方向，尤其白鸽540度和阿尔马达类动作必须锁定水平旋身，禁止竖向翻腾。
