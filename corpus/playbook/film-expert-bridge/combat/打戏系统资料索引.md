# 打戏系统资料索引

> 目的：让 seedance-combat-prompt 在资料越来越大时，优先通过“唯一ID锚点 + 标题关键字 + END结束锚点 + 行号辅助”定位资料，避免每次全文读取。
> 维护原则：唯一ID一旦建立，除非废弃模块，否则不要修改；模块内容可持续做加法；行号仅作辅助，不作为唯一依据。
> 最后整理时间：2026-06-29

---

## 0. 定位协议

### 0.1 推荐读取优先级

```text
第一优先级：唯一ID锚点，例如 <!-- ID:CHAR-TAIJI-001 -->
第二优先级：标题关键字，例如 ## 太极角色卡
第三优先级：END结束锚点，例如 <!-- END:CHAR-TAIJI-001 -->
第四优先级：读取范围，例如 向下读取28行
第五优先级：参考行号，例如 SKILL.md L206-L216
```

### 0.2 标准模块格式

```md
<!-- ID:模块唯一ID -->
## 或 ### 模块标题关键字

模块正文……

<!-- END:模块唯一ID -->
```

### 0.3 读取规则

```text
1. 先读取本索引文件。
2. 根据用户需求找到角色、技法、规则、兵器专项或精品案例的唯一ID。
3. 到对应文件中搜索唯一ID锚点。
4. 优先从 ID 读取到 END。
5. 如果 END 缺失，则按“建议读取范围”向下读取。
6. 如果 ID 暂未写入正文，则用“标题关键字”检索后局部读取。
7. 如果仍无法定位，再使用参考行号或全文读取兜底。
```

## 8. 维护规范

1. 新增角色时，必须新增 `CHAR-角色-编号`，并在角色库索引登记主战技法、特效主色、关联技法ID。
2. 新增技法时，必须新增 `MARTIAL-技法-编号`，并在徒手技法库索引登记适用角色、核心用途和读取规则。
3. 新增兵器专项时，必须新增 `WEAPON-专项-编号`，并登记触发关键词、禁止项和文件路径。
4. 新增规则时，必须新增 `RULE-规则-编号`，并登记触发条件。
5. 如果正文模块已加入 ID/END 锚点，读取时优先使用锚点；如果暂未加入锚点，使用标题关键字和建议读取范围兜底。
6. 大规模编辑后，可批量刷新参考行号，但行号永远不是唯一定位方式。
