# 打戏生成自检清单（强制逐项过，缺一项不出稿）

> 每次出打戏提示词/分镜前，必须逐条核对。任何一条没做到，先补再出，不许跳过。

## 一、空间与连续性
- [ ] **空间锚定**：第一镜已建立两人左右方位（A左B右）、距离、环境锚点
- [ ] **正反打不越轴**：后续每镜标注谁在画面左/右，无理由不左右翻转
- [ ] **草图=母版**：走位稿定下后，首帧/视频都照草图对应格派生
- [ ] **尾帧接首帧**：相邻镜头动作连续，前一镜尾帧=后一镜起始状态

## 二、分镜质量
- [ ] **每格动作不同**：禁止重复构图/同一姿势
- [ ] **两套箭头**：角色移动箭头 + 机位相机运动箭头都画了
- [ ] **因果链完整**：蓄力→出招→受击→反馈→结果，每格交代清"因为所以"
- [ ] **对比放大信息**：每格都在放大某个信息（力量/压迫/速度），不是摆pose

## 三、受力反馈
- [ ] **攻方出招**：写清了攻方用什么打（拳/脚/剑/法术）
- [ ] **受方物理反应**：受方怎么吃这一下（躯干弯/头偏/腿软/后退/格挡）
- [ ] **镜头微震/命中停顿**：打击瞬间有镜头反应，不是"打铁板"
- [ ] **受力时机正确**：飞溅/碎石/气浪在击打发生时，不是开头就有

## 四、角色一致性
- [ ] **人物卡锁脸**：用image_edit挂参考图，禁止纯文生开盲盒
- [ ] **角色招式绑定**：按角色武学体系出招式，不串角色
- [ ] **同对战不重复**：A vs B 这组，之前用过的招式不再重复

## 五、环境与质感
- [ ] **环境反馈**：打斗影响环境（碎石/气流/水波/树叶），不是虚空打
- [ ] **战场锚点**：用了战场场景库的空间锚点（可交互物/材质/光色）
- [ ] **负面排除清单**：畸形四肢/多手多脚/穿模/僵硬漂浮都挂了
- [ ] **质感一致**：皮肤/布料/金属质感符合题材，不塑料

## 六、台词与时长
- [ ] **台词时长**：有台词的镜头，时长≥字数÷语速（4~5字/秒）
- [ ] **首帧时间线正确**：首帧=该段戏时间线第一画面，不拿高潮帧当头帧
- [ ] **时长分配合理**：不机械平均，爆发段短切、蓄力段留白

## 七、大招/终结技（如有）
- [ ] **前摇→聚能→释放→受击→终结**链条完整
- [ ] **大招有记忆点**：最后一帧留印象，不是打完就切
