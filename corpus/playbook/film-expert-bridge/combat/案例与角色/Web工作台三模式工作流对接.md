# Web工作台三模式工作流对接

> 目的：把 feichi_skills_fight_v3 配套 Web 工作台（打戏提示词生成器）的三模式输入维度固化进对话生成流程，让对话直接生成时覆盖 Web 工具全部能力。
> 适用范围：附加C 打斗分镜提示词（对打/清兵两模式）；大招模式对应附加D（`../../seedance-fantasy-ultimate-prompt/SKILL.md`）。
> 对接关系：Web 工作台把选项拼成"请求文本"再交给 AI；本文件让 AI 在对话中直接按同一套维度收集输入并产出最终成品，省去中转。

## 一、模式判定（先定模式再收输入）

- 双方明确攻防（1v1/2v2/2v3）→ **对打模式**
- 主角/小队清兵、杀怪、冲阵，敌方只配兵群信息 → **清兵模式**
- 仙侠玄幻魔法核心技能释放 → **大招模式**（转附加D）

## 二、对打模式输入维度

> ★ = 缺省必问，不得默认；未指定时长必须先问（15/30/自定义）

- ★时长：15秒（高密度爆点）/ 30秒（双15秒完整叙事）/ 自定义
- ★阵型A/B成员：姓名 + 临时武学绑定（已选武学3-6个 / 主战 / 破招 / 终结 / 劲气：颜色+形状+性格）+ 角色定位
- 打法模板：双线并进 / 主线决斗+侧翼牵制 / 围点打援 / 先分后合 / 全场追猎 / 自定义
- 对位模式：一一对位 / 主副对位 / 围攻单点 / 前分后合 / 自由混战
- 镜头分配：平均分镜 / 主线聚焦 / 双线交替 / 群战全景优先；中段是否允许换对手
- 三阶段对位（开局/中段/收束）：每阶段"谁对谁（焦点：正面对位/支线牵制/夹击过渡/终结主线）"
- 成员职责：主攻/牵制/补位/游走/截断退路/终结收口
- ★场景（20选，见 SKILL.md 附录E 场景设计选择功能）★视觉风格（5选，见附录D 风格选择功能）★战斗节奏（高速压制/拉锯/逆转）★结局（按角色对生成：碾压性胜利/险胜/势均力敌/惨胜）特殊要求（见第五节）

## 三、清兵模式输入维度

- ★时长 ★阵型A成员（绑定同上，敌方不绑武学）
- 清兵结构：冲阵清兵 / 围攻拆阵 / 守点清怪 / 突围逃杀 / 头目压场
- 敌群：类型（黑衣小兵/刀盾兵/兽群怪物/尸潮怪物/机关傀儡/异形魔物等）+ 数量
- 头目：无头目（兵群连续清场）/ 有头目压场（头目类型 + 态势：坐镇压场/中途入场追杀/先清兵再追头目）
- 清兵起手：主角主动进攻 / 兵群成群冲来 / 双方迎面撞上 / 主角先被包夹后反杀
- 清兵方式：单点突穿 / 移动追杀 / 协同推进 / 被包围后反向清场 / 旋转横扫
- ★场景 ★视觉风格 ★战斗节奏 清兵结果（持续推进/最终大招清完/突围成功/压住战场/清后追杀头目）特殊要求
- 清兵模式禁止回显模板字段，必须直接输出时间轴分镜（RULE-TEMPLATE-EXEC）

## 四、大招模式输入维度（转附加D）

- ★时长 ★主角 ★反派 ★场景（10选）★视觉风格（5选）
- ★技能属性（9选：火/雷/冰/剑仙飞剑/风/土岩/水/暗魔/光神圣）+ ★属性细分（如朱雀神火）+ 中段招式（多选）+ 后段大招（多选）
- ★战斗节奏（被击反应8选：压制崩溃/快速闪避/游刃有余抵挡/勉强招架/硬抗后破防/先闪后失误/被气场镇压/被锁定无法脱身）
- ★结局（9选：正面轰杀/击退坠落/冰封粉碎/贯穿重创/镇压封印/剑阵诛灭/爆炸吞没/重伤未死/被迫撤退）
- 特殊要求；输出铁律：双成品（标准版+强化版），每条固定六段（人物/场景/风格/分镜/细节强化/负面提示词约束）

## 五、特殊要求分类速查（跨模式通用）

- **速度**：快速打斗/零前摇瞬间出招/高频连续对招/招式切换不断档/越打越快/追击速度
- **走位**：不断走位/不能停留原地/极速滑步跟进/不同方位追逐/空中位移换位/切角绕后侧闪/跨落点跨区域追逐
- **受力反馈**：拳拳到肉/击退数米/高速倒飞后撤/失衡踉跄/衣衫破裂/重击打停感/清晰碰撞反馈/地面开裂碎石
- **环境与能量反馈**：能量迸发/轨迹缠绕延展/环形能量波纹/放射碎片/能量场压迫/能量划痕轨迹/先压缩再爆开/旋涡卷流/层层脉冲/束状刃状能量/对冲交织/冲击波气浪/火花乱流/残影拖尾/场景物件破坏
- **打斗要求（基础铁律）**：开局0.5秒正面硬撞/中段上半身近景对招/禁纯特效对轰/攻防链条清楚/禁停顿发呆/结尾必有终结技

## 六、对话生成规则

1. 按用户需求判定模式后，按对应维度收集输入；★必问字段缺失时先问，不默认。
2. 用户只给部分维度时，用技能库默认推荐补全非★字段（场景/风格/节奏按附录D/E引导选择）。
3. 维度决定"编排"（谁打谁、怎么布局、什么节奏），打戏铁律与镜头规格强制（铁律30）决定"写法"——两者都必须执行。
4. 生成结果必须直接输出最终提示词成品（时间轴分镜），禁止回显输入字段。
