# 精品案例提炼_清兵多风格专项

> 用途：把高质量用户案例里真正稳定、可迁移、可执行的部分抽成内部规则，供 `seedance-combat-prompt` 在“清兵 / 怪群 / 剑阵围攻 / 巨兽 / 电影级 CG 打戏 / 多风格群战”场景中按需调用。
> 适用原则：提炼“效果机制”，不照抄用户原句；生成时仍必须服从 `SKILL.md` 的通用铁律、15秒/30秒铁律、镜头规格强制系统、旋转运镜禁令与可读性要求。

## 一、清兵多风格精品感提炼

### 1. 清兵不是单一种类，必须先判断敌群类型
- 清兵场景至少分为四类：
  1. **杂兵群**：街斗人群、现代持械敌群、赛博义体兵。
  2. **武侠阵群**：剑阵、刀阵、道士阵、门派围攻、军阵。
  3. **怪群 / 魔物群**：尸潮、兽群、异形、傀儡。
  4. **巨体目标**：独眼巨兽、Boss、重甲怪将。
- 生成前必须先判断当前属于哪类，再决定动作驱动力、镜头节奏和结果表达。

### 2. 角色描述必须先立“辨识锚点”
- 角色不能只写“美女剑修/少女战士/大侠”，必须先立 3 层锚点：
  1. **轮廓锚点**：发型、围巾、披风、肩甲、长靴、长兵器、异色手臂、双刀、长袍、门派服饰。
  2. **材质锚点**：金属、皮革、晶体、鳞片、生物甲、符文、旧化、裂纹、PBR 高光、布袍、竹叶水雾。
  3. **气质锚点**：冷静、肃杀、压迫、极快、零前摇、利落、无多余动作、宗师感、豪侠感。
- 生成角色描述时，要让观众在一眼内认出“她/他是谁”，而不是只看到泛化美术词。

### 3. 场景必须用“三层结构”写实
- 高完成度场景不要只写地点名，要拆成三层：
  1. **主体空间层**：废墟街区、道观广场、竹海战场、荒凉关隘、宗门山门、赛博广场。
  2. **空气层**：灰尘、体积雾、烟尘、逆光颗粒、水汽、竹叶碎屑、灵能光尘、余烬。
  3. **地面层**：裂痕、碎石、青苔水膜、泥土、落叶、积水反光、石板沟壑、尘环。
- 生成时至少给出“空间层 + 空气层 + 地面层”，避免只剩一个空洞背景词。

### 4. 武器不能只写名字，必须写“结构与材质”
- 重武器、魔剑、长刀、巨剑不能只写“巨型魔剑/黑刀”，必须补足：
  - **刀身 / 剑脊 / 刃口 / 护手 / 握柄 / 尾饰** 中至少 3 个部位；
  - **材质与能量核心**：黑钢、龙骨、晶核、裂纹、符文、冷光/红光内透；
  - **整体气质**：古老、诅咒、厚重、优雅、危险、非制式兵器。
- 武侠兵器则要写清：
  - 剑尖、剑脊、剑花、剑诀、剑阵、剑气、断刃、脱手、空手入白刃；
  - 不能把武侠长剑写成玄幻大剑，也不能把写实刀客写成浮夸塑料光效。

### 5. 命中反馈必须使用“电影级反馈包”
- 高质量命中不要只写“打中爆炸”，优先调用以下反馈包：
  - **视觉瞬时反馈**：白闪 1-2 帧 / 高对比黑白闪回 / 单色红染或金橙染。
  - **镜头反馈**：短促震镜 / 急推到命中点 / 径向速度模糊 / snap 回正常速度。
  - **接触点反馈**：火花、能量碎屑、甲片崩裂、切口内发光、压痕、形变、布料裂开、断发掠镜。
  - **环境反馈**：地裂、尘环、碎块飞散、玻璃震碎、水花炸起、落叶卷飞、石板崩开。
- 推荐写法：`命中瞬间反馈 + 0.2-0.4s 微升格 + snap 回速 + 环境兑现`。

### 6. 慢拍不是停画，必须“画面持续在动”
- 蓄力慢拍、收势慢拍、英雄定场都不能写成静止摆拍。
- 即使进入慢拍，也必须保留至少两类二级运动：
  - 发丝 / 围巾 / 披风 / 衣摆 / 光尘 / 烟尘 / 水汽 / 余波 / 碎石悬浮；
  - 气场内收 / 能量爬升 / 残影追上本体 / 剑身余光滑落 / 尘埃沉降。
- 内部定义：
  - **A 类慢拍**：重击后余震慢拍，突出受力与碎屑流动。
  - **B 类慢拍**：蓄力或收势慢拍，人物已稳住，但布料、粒子、气场仍在持续运动。

### 7. 清兵 / 怪群不能写成“站桩挨打”
- 敌群与怪群必须具备主动性，至少满足以下一项：
  - 成群冲阵、围扑、夹击、扑落、前后包夹；
  - 有一波接一波的压近趋势；
  - 有头目 / 焦点怪 / 核心目标驱动节奏升级。
- 主角清兵要优先写成：
  - **切入**：突穿、俯冲、贴地滑切、瞬闪入群、轻功切边、踏墙变向。
  - **清场**：横扫、贯穿、追杀、回身反斩、扇面打击、锥形轰落、掌风震退。
  - **兑现**：杀穿、压场、继续追头目、大招清完、稳住战场。

### 8. 武侠清兵必须有“阵法感”或“门派协同感”
- 武侠群战不能只写很多人乱冲，优先补足以下任一结构：
  - 剑阵、北斗阵、品字阵、三角突刺、小阵前压；
  - 同步出剑、方位封路、变阵收拢、背靠背绕圈、前后夹击；
  - 门派差异：道士、少林、丐帮、剑派、军阵，各自动作和兵器不一样。
- 武侠清兵的快感，不只是主角强，而是**群体阵法被主角不断拆解**。

### 9. 武侠围攻的镜头价值在“前景掠镜”
- 武侠剑阵 / 围攻类案例里，前景非常重要，优先使用：
  - 靴底从镜头前景放大掠过；
  - 剑尖 / 剑刃 / 衣袖 / 手臂从镜头边缘快速划过；
  - 倒地肢体、压镜身体、飞出武器、断刃、布片、发丝掠过镜头。
- 这类“前景掠镜”能把围攻感和临场压迫拉满，尤其适合武侠真人电影感和硬派群战。

### 10. 武侠真人感优先“物理声画证据”
- 当用户偏向硬核武侠、真人电影、35mm 胶片、无音乐环境音时，优先强调：
  - 手持摄影、快推快拉、急停回弹、轻失焦、镜头呼吸；
  - 金属擦鸣、靴底擦地、水花、碎石、衣料抽响、断刃坠地、沉闷钝响；
  - 不依赖大面积玄幻特效，也能让打击成立。
- 这类风格里，气劲可以有，但要更偏空气扭曲、掌风、尘浪、水幕，不要全程发光塑料特效。

### 11. 巨体战与清兵战的动作驱动力不同
- **巨体战**：强调体量反差、弱点攻击、胸口核心、纵向位移、俯冲贯穿、建筑级反馈。
- **清兵战**：强调横向穿杀、连续换位、连杀节奏、弧线扫荡、镜头跟随移动路径。
- **武侠阵战**：强调拆阵、破位、卸械、借力反摔、空手入白刃、以小破大范围围攻。
- 禁止把不同类型混成同一套打法。

### 12. 多风格适配规则
- 该专项默认支持以下五类大风格：
  1. **现代格斗**：拳脚、摔投、近距离撞击、地面和墙体反馈。
  2. **武侠**：阵法、兵器、轻功、掌风、卸械、门派感。
  3. **仙侠**：剑气、法器、御气、宗门场景、灵力波纹。
  4. **未来赛博朋克**：义体冲刺、霓虹反光、粒子故障感、机械碎裂。
  5. **二次元动漫格斗**：残影、夸张动态模糊、命中定格、爆发帧强化。
- 适配时只改“表现材质与特效语言”，不要破坏动作因果和清兵逻辑。

### 13. 风格切换时的特效控制
- **现代格斗**：保留气爆和冲击，但减少玄幻光效。
- **武侠**：保留掌风、剑气、尘浪、水幕、落叶、空气扭曲，控制特效透明度。
- **仙侠**：允许灵力、龙形、符纹、剑气具象化，但动作仍要有发力链。
- **赛博**：允许霓虹粒子、电弧、扫描残影、机械火花。
- **二次元**：允许更强的残影、单色爆闪、速度线、集中线，但仍需看清主动作。

### 14. 终结后必须保留“余震价值”
- 高完成度终结不能命中即结束，至少补一个后效：
  - 敌体崩解 / 核心熄灭 / 残骸倒塌 / 能量柱冲天 / 尘埃沉降；
  - 主角拖剑站定 / 收刀礼 / 余光未灭 / 继续锁定暗处新威胁；
  - 武侠群战中还可写：满地断剑、空手失措、广场归静、落叶缓落、尘浪渐息。
- 终结后的 0.5-2 秒是“情绪兑现段”，不能浪费成空镜。

### 15. 电影感来自“效果链完整”，不是堆词
- 遇到用户给出超长精品案例时，优先提炼为以下链条：
  - **角色辨识** → **敌群类型** → **空间层次** → **动作因果** → **命中反馈包** → **余震与尾势**
- 不要机械复制“masterpiece / best quality / 8K / HDR10+”等堆料词；只有当用户明确偏好超写实 CG / 暗黑电影感 / IMAX / 35mm 胶片时，再把画质和渲染词少量前置。

### 16. 与现有铁律的兼容关系
- 本专项允许增强：
  - 清兵群战的结构化类型
  - 阵法 / 门派 / 怪群 / 巨体的差异化表达
  - 命中反馈包
  - 慢拍中持续运动
  - 武器结构化描写
  - 终结余震和场景兑现
- 本专项**不推翻**以下既有铁律：
  - 15秒/30秒动作密度要求
  - 镜头规格完整写法
  - 动作先于镜头
  - 屏幕方位衔接
  - 360°满环绕禁令

### 17. 关于 360° 环绕的特别说明
- 用户案例里出现的“360°高速环绕”有参考价值，但只能提炼为：
  - **名场面余震镜头**：只在爆炸后、终结后、能量柱前的 0.3-0.5 秒短时放大中谨慎使用；
  - **二次元 / 游戏化极端风格镜头**：可以在明确指定时单次使用，但不能承担核心对招主镜头。
- 核心对打、清兵主流程、武侠拆阵、巨兽压制段，仍优先使用线性运镜、急推、低仰、俯冲跟拍、环绕半圈以内。

## 二、清兵多风格场景的优先调用清单

当用户出现以下任一需求时，优先读取本专项后再生成：
- 清兵、杀怪、冲阵、守点清怪、突围清兵
- 群殴、围攻、剑阵、道士阵、门派群战、军阵
- 巨兽、怪物、魔物、独眼巨兽、异形、Boss 战
- 暗黑写实 CG、电影级 3DCG、超写实 3D 国漫、硬核武侠真人、IMAX 武侠大片、赛博群战、动漫名场面
- 希望“达到案例这种程度”“画面要像名场面”“命中反馈更炸”

生成时优先检查以下 10 项：
1. 角色辨识锚点是否成立？
2. 敌群类型是否判断清楚？
3. 场景三层是否成立？
4. 武器结构是否能支撑后续镜头？
5. 武侠围攻是否具备阵法感 / 前景掠镜？
6. 是否安排了命中反馈包？
7. 慢拍是否保持持续运动？
8. 终结后是否有余震兑现？
9. 风格材质是否与现代 / 武侠 / 仙侠 / 赛博 / 动漫匹配？
10. 是否仍遵守 15秒/30秒主铁律与镜头禁令？

## 三、提炼后的内部写作公式

### 公式A：巨体目标镜头强化公式
`角色辨识锚点 + 巨体量差 + 弱点/核心锚点 + 纵向位移攻击 + 命中反馈包 + 建筑级环境兑现 + 终结余震`

### 公式B：清兵战镜头强化公式
`阵型A切入方式 + 敌群主动压近 + 连续位移清杀 + 横扫/贯穿/扇面清场 + 追击不断线 + 收束结果`

### 公式C：武侠拆阵强化公式
`阵法建立 + 方位封路 + 前景掠镜 + 主角闪挡拆招 + 卸械/反摔/断阵 + 全阵失衡`

### 公式D：电影级重击强化公式
`命中点特写 + 白闪/单色闪回 + 震镜/径向模糊 + 微升格 + snap回速 + 碎屑/火花/冲击波兑现`

### 公式E：B类收势慢拍公式
`人物收势已完成 + 发丝/布料/围巾/光尘仍在动 + 剑身余光/粒子残留 + 环境烟尘持续沉降 + 新威胁或余威仍在场`
