# 七角色武学绑定V2

> 目的：按角色战斗功能重新绑定武学，让每个角色的技法服务核心定位，支撑15秒高密度打戏与30秒双15秒完整战斗叙事。
> 核心原则：角色定位优先，武学服务定位；每个角色只能有一个主轴，辅助技法必须服务主轴，不能写成“什么都会”。
> 最后整理时间：2026-06-29

---

## 0. 通用绑定原则

```text
角色定位 > 主战技法 > 辅助技法 > 破招逻辑 > 终结链方向 > 禁止偏移
```

1. 主战技法决定角色观感，比例通常为40%-70%。
2. 辅助技法只服务主轴，不允许抢戏。
3. 30秒打戏必须体现“第一轮试探—第二轮变招—破招机会—终结兑现”。
4. 每个角色后续都应继续拆成：12式主战招、6式破招反制、3式终结链、3种情绪起手式/杀招前摇。
5. 如果角色使用临时技法，必须在提示词中明确“临时使用”，不能覆盖角色默认绑定。

## 1. 白鸽：踢技主攻 / 踢技截击 / 手部短截辅助

### 核心定位

```text
高机动踢技主攻型。攻击以踢技为主，防守也尽量用踢技截击；手部动作只用于短截、开路、制造节奏变化，不能变成拳法主攻。
```

### 技法比例

```text
主战70%：巴西战舞 + 36路腿法 + 跆拳道
截击20%：截拳道腿法截击 + 谭腿
手部观赏10%：截拳道手部短截 + 少量咏春短桥
```

### 技法职责

- 巴西战舞：翻转游走、倒立闪避、侧身回旋，用身体旋转制造踢击角度。
- 36路腿法：高扫、侧踹、后摆、连环踢、高低腿变化，提供腿法内容库。
- 跆拳道：高位腿、下劈、旋踢、后旋踢、腾空踢，强化观赏性。
- 截拳道腿法：下踩、截踢、低位侧踢、迎击腿，负责“用腿防守”。
- 谭腿：直线弹腿、蹬腿、扫腿，补充规整基础腿法。
- 截拳道/咏春短桥：拍手、挂手、截拳、摊手、膀手，只用于手部对招观赏和制造空档。

### 战斗路线

```text
翻转游走 → 踢技截击 → 高低腿连续压制 → 手部短截制造空档 → 高位腿/旋转腿终结
```

### 典型截击逻辑

- 对方正蹬腿刚抬到腰线，白鸽前脚下踩压住对方小腿，顺势后旋踢反打肩颈。
- 对方低扫踢来，白鸽提膝截住来腿，同时反踢对方肋部。
- 对方冲拳前压，白鸽侧身低位截踢膝外侧，打断前进路线，再接高扫。

### 禁止偏移

- 禁止写成拳法主攻。
- 禁止地堂腿占比过高；地堂腿只作低位突围辅助。
- 禁止终结技长期只用540°水平旋风踢，必须发展多种腿法终结链。

## 2. 太极：太极防反 / 八极兑现 / 基础腿法控距

### 核心定位

```text
太极拳防守反击型。主用太极拳接、化、引、缠，借力打力；八极拳用于反击兑现；基础腿法用于控距、破重心、增加连招层次。
```

### 技法比例

```text
主战65%：太极拳
爆发20%：八极拳
腿法10%：北派基础腿法/谭腿基础段
短打5%：咏春封桥辅助
```

### 技法职责

- 太极拳：听劲、化劲、缠丝、引进落空、四两拨千斤、掤捋挤按、采挒肘靠。
- 八极拳：顶心肘、贴山靠、崩拳、震脚、短距离爆发，负责破防后的伤害兑现。
- 基础腿法/谭腿：正蹬、低扫、截腿、勾踢、蹬膝、弹腿、扫踝，负责控距离和破重心。
- 咏春封桥：摊手、膀手、拍手、黏手、日字冲拳，只作近身封线辅助。

### 战斗路线

```text
接触听劲 → 化劲卸力 → 借力破重心 → 基础腿法控距 → 八极贴身爆发
```

### 典型反击逻辑

- 对方直拳进攻，太极云手外旋化开拳路，顺势勾踢脚踝破重心，再贴身八极顶肘。
- 对方高位腿进攻，太极后撤半步引空，搂膝拗步压腿，接正蹬腹部拉开距离。
- 对方连续拳压迫，太极如封似闭压肘，咏春拍手封桥，八极贴山靠震退。

### 禁止偏移

- 禁止写成单纯咏春角色。
- 禁止一直柔化不反击；太极必须有反击兑现。
- 禁止腿法过花，太极腿法只用于控距、扫踝、破重心、补连招。

## 3. 红茶：攻击代防 / 膝肘压迫 / 贴身爆发

### 核心定位

```text
攻击代替防守的压迫型角色。她不靠闪避和化解，而是用更重的肘、膝、拳、肩撞顶回去；防守动作本身也必须带攻击性。
```

### 技法比例

```text
主战60%：泰拳
连击20%：散打
爆发15%：八极拳
直线突进5%：空手道
```

### 技法职责

- 泰拳：横肘、砸肘、顶膝、箍颈膝撞、低扫、肘膝组合，以肘架拳、以膝截腹。
- 散打：直摆勾、鞭腿、接腿摔、拳腿组合，补中距离压迫。
- 八极拳：顶心肘、贴山靠、震脚冲肘、撞肩破防，作为贴身核爆。
- 空手道：正拳突进、手刀、前蹴、冲步压迫，只作直线突进补充。

### 战斗路线

```text
硬顶来招 → 肘膝反击 → 散打拳腿压制 → 八极贴身爆发 → 膝肘同顶终结
```

### 典型攻击代防逻辑

- 对方直拳打来，红茶横肘横封拳路，同时另一手短拳砸向太阳穴。
- 对方侧踢踢腹，红茶提膝硬顶小腿，前压砸肘打下巴。
- 对方试图近身抱摔，红茶箍颈顶膝打腹，接八极顶心肘破防。

### 禁止偏移

- 禁止写成灵巧闪避型。
- 禁止过多复杂防守，红茶的防守必须带反击。
- 禁止削弱膝肘压迫感。

## 4. 芭乐：柔韧锁摔 / 打击铺垫 / 地面降服

### 核心定位

```text
柔韧锁摔型。所有打击、翻转和身法都必须为了抓、缠、锁、摔做铺垫；不是单纯打击型，也不是第二个白鸽。
```

### 技法比例

```text
主战45%：柔术/巴西柔术
摔投25%：柔道
铺垫20%：蔡拳 + 跆拳道轻腿
柔韧爆点10%：巴西战舞柔韧翻转
```

### 技法职责

- 柔术/巴西柔术：腕锁、肘锁、肩锁、绞控、腰背控制、地面翻滚、倒地反制。
- 柔道：过肩摔、内股、大外刈、袖钓込腰、扫腰、抱腰摔，提供摔投爆点。
- 蔡拳：密集手部扰乱、逼防、打乱重心、制造抓腕机会。
- 跆拳道轻腿：点踢、轻踢、假高踢，用于骗防守和切入距离。
- 巴西战舞柔韧翻转：翻身绕背、倒立脱锁、低身旋转切入下盘。

### 战斗路线

```text
轻打诱导 → 手部扰乱 → 抓腕缠臂 → 柔道摔投 → 地面锁技/关节终结
```

### 典型铺垫逻辑

- 芭乐用蔡拳密集拍打逼对方抬手，顺势抓腕转身过肩摔。
- 芭乐假高踢骗对方举臂，落地时身体下潜抱腰，接内股摔。
- 芭乐被击倒后不急起身，顺势翻滚夹臂，转入十字固或三角绞。

### 禁止偏移

- 禁止写成纯花瓣火焰打击型。
- 禁止巴西战舞比例过高抢白鸽定位。
- 禁止柔术只出现在终结，前段动作必须为锁技铺垫。

## 5. 凛羽：小体型灵活借力 / 2躲1抗 / 要害快打

### 核心定位

```text
小体型灵活借力型。身体偏小、胳膊腿短，不靠力量和大开大合；被攻击时2躲1抗，利用八卦走位、太极小架借力和短打快速命中要害。
```

### 技法比例

```text
主战40%：八卦掌
借力25%：太极小架/推手借力
要害快打20%：截拳道 + 咏春短打
脱身15%：合气道/柔术小关节
```

### 技法职责

- 八卦掌：绕背、走斜门、贴身换位、绕开正面力量，从侧后方打要害。
- 太极小架/推手借力：黏、卸、引、转、借力，不做大开大合太极拳展示。
- 截拳道/咏春短打：标指、掌根、短肘、日字冲拳、拍手直击，用于快速命中喉线、肋缝、下巴、锁骨等要害。
- 合气道/柔术小关节：扣腕、反肘、转身脱臂、小关节锁，用于被抓或被压制时脱身反制。

### 战斗路线

```text
斜线闪避 → 借力卸劲 → 绕侧贴身 → 快速点打要害 → 小关节反制脱身
```

### 2躲1抗规则

```text
每3次防守中，至少2次必须用闪身、绕位、下潜、侧步避开；最多1次用借力、推手、小关节承接，禁止连续硬抗。
```

### 典型反制逻辑

- 对方重拳冲来，凛羽侧步绕到外门，掌根点下巴后立刻退位。
- 对方扫腿压迫，凛羽后撤避开第一腿，八卦换步绕侧，标指点喉线。
- 对方抓腕，凛羽不拔河，顺势转腕借力，合气道小关节反折脱身。

### 禁止偏移

- 禁止写成重型形意硬打角色。
- 禁止连续硬抗，凛羽最多“2躲1抗”。
- 禁止霜雾写成冰女硬冰，凛羽是霜雾、薄霜、寒气微粒。

## 6. 雷电：极速快打 / 零前摇截击 / 折线瞬闪

### 核心定位

```text
速度强支撑型。所有招式必须服务速度，强调零前摇、最短路径、截击、快打和折线瞬闪；偶尔可用蓄势前摇，但出手速度必须明显快于凛羽。
```

### 技法比例

```text
主战40%：截拳道
近身25%：咏春快打
突进20%：空手道/跆拳道高速腿
爆发15%：八极速度版
```

### 技法职责

- 截拳道：截拳、截踢、标指、前手直击、低位侧踢、拍手直拳、迎击拳，负责最短路径和先手打断。
- 咏春快打：日字冲拳、黏手、拍手、膀手、摊打、连环冲拳，负责近身一秒多击。
- 空手道/跆拳道高速腿：前蹴、侧踢、回旋踢、后踢、冲步正拳，负责高速突入和高位踢击。
- 八极速度版：瞬步顶肘、短距贴山靠、震脚冲拳、肩撞破防，只保留极短爆发。

### 战斗路线

```text
零前摇截击 → 高速直线突入 → 咏春连环快打 → 折线瞬闪变位 → 八极速度爆发
```

### 高速可读性规则

- 不能每招都写瞬移，必须用电弧残线标出攻击轨迹。
- 快速攻击命中或被格挡时，必须有0.1-0.3秒停帧、慢镜头或电弧断裂反馈。
- 前摇招式允许出现，但前摇时间短，出手速度必须快于凛羽。
- 雷电的快不是乱闪，而是最短路径、高频截击、折线变位。

### 禁止偏移

- 禁止写成重型八极角色。
- 禁止所有动作都变成不可读瞬移。
- 禁止把雷电速度写得弱于凛羽。

## 7. 冰女：基础全面 / 拳腿摔均衡 / 硬冰封锁

### 核心定位

```text
基础全面的冷静压制型。拳、腿、摔都具备，但不在任何单一拳法或腿法上过度偏科；用全面基础建立优势，再用硬冰固定优势。
```

### 技法比例

```text
主战35%：散打
腿法25%：跆拳道
手部20%：空手道
摔控10%：柔道/摔跤基础
封锁10%：擒拿冰锁
```

### 技法职责

- 散打：直摆勾、鞭腿、接腿摔、拳腿组合、中距离压制，是综合基础。
- 跆拳道：侧踢、横踢、后踢、下劈、高位腿，提供腿法观赏性，但不过量。
- 空手道：正拳、手刀、前蹴、逆突、格挡反击，提供清晰直线打击。
- 柔道/摔跤基础：接腿摔、抱摔、扫腿、压制倒地，只做基础摔控。
- 擒拿冰锁：反腕、锁肘、肩锁、冰环封关节，作为专属封杀机制。

### 战斗路线

```text
拳腿均衡试探 → 接腿摔控 → 硬冰固定关节 → 空手道直线破防 → 擒拿冰锁终结
```

### 硬冰封锁逻辑

- 基础打击命中后，硬冰固定被命中的部位。
- 接腿摔后，硬冰从脚踝或膝关节蔓延，限制起身。
- 擒拿成功后，冰环锁住腕、肘、肩等关节，形成“打→冻→锁”。

### 禁止偏移

- 禁止写成红茶式膝肘猛攻。
- 禁止写成凛羽式霜雾灵动。
- 禁止某一拳法或腿法占比过高；冰女必须保持全面基础型。

## 8. 女帝：高位腿法凌厉压制 / 腿长控距 / 精准闪避即反击

### 核心定位

```text
高位腿法凌厉压制型。利用腿长优势，以大开大合的腿法全程压制对手；面对胸部及以上攻击时以精准后仰、侧偏、下腰闪避，同拍起腿打断对方攻势。她不屑近身缠斗，手部只用于拍开、格挡、撑地，主视觉必须保持腿法优雅、凌厉、高傲。
```

### 技法比例

```text
主战65%：36路腿法 + 散打腿法
高位终结15%：跆拳道高位踢 + 下劈
截击破招15%：谭腿
空间变化5%：巴西战舞限定低位反击
```

### 技法职责

- 36路腿法：里合腿内弧扫开防线、外摆腿外弧打开角度、边腿横抽肋腰、通肋腿弧线踢肋、窝心腿正弹心窝、低高边腿上下二连、窝心反腿攻防瞬换。
- 散打腿法：快线鞭腿、截线侧踢、侧踹、转身后蹬，负责中距控场、以腿截腿、直线推开和大幅反击。
- 跆拳道：高位横踢、下劈、后踢，只负责高位爆点和终结，不扩展成完整跆拳道体系。
- 谭腿：弹、截、踩、蹬，负责最快出腿、踩脚锁步、截断来腿、破重心。
- 巴西战舞：只取倒立托马斯回旋踢、安哥拉侧旋踢、马尔特洛翻转踢，作为低位反击和空间变化，不走白鸽式弹跳空翻游走。

### 战斗路线

```text
中距大开大合腿法压制 → 对方攻击胸部及以上时精准闪避 → 闪避同时凌厉腿法打断攻势 → 谭腿截击/踩脚破重心创造机会 → 跆拳道下劈/高位横踢/后踢终结 → 必要时倒立托马斯回旋踢低位反击后立刻回站立姿态
```

### 特效规则

```text
女帝特效为粉色，与芭乐同属粉色系；但女帝普通攻防阶段不展示常驻特效，只写腿风、气爆、衣物褶皱、尘土爆开、受击压痕等物理反馈。粉色特效只在终结技阶段展示，用于表现高位压制的终结绽放。
```

### 典型反击逻辑

- 对方直拳打头，女帝后仰闪过拳锋，同时边腿横抽对方肋部，落地不缠斗，立刻外摆腿扫开护架。
- 对方横肘切眉骨，女帝下腰闪避，同时谭腿弹踢对方膝内侧，破重心后接高位横踢抽头侧。
- 对方顶膝撞腹，女帝侧偏让开中线，同时外摆腿扫开对方手臂并横扫耳侧，随后侧踹推开重建腿法距离。
- 对方近身前压，女帝双手撑地进入倒立托马斯回旋踢，身体水平旋转，双腿交替扫腰肋头颈，扫开攻势后翻身回站立。

### 禁止偏移

- 禁止写成拳法主攻；手部只作拍开、格挡、撑地。
- 禁止写成白鸽式弹跳空翻游走型；女帝以站立腿法压制为主。
- 禁止倒立托马斯回旋踢占比过高，它只是低位反击和空间变化手段。
- 禁止近身缠斗；被近身时必须用谭腿弹截、侧踹、倒立托马斯回旋踢重新拉开距离。
- 禁止闪避后不反击；女帝的闪避和腿法打断必须同拍完成。
- 禁止终结技单一；下劈、高位横踢、后踢必须按机会差异轮换。

## 9. 将军：泰拳八极压制 / 膝肘短爆发 / 冷酷贴身靠打

### 核心定位

```text
冷酷军官式近身压制型。由“艾斯德斯”需求改名为“将军”，但当前系统无正式艾斯德斯旧模块，因此作为新角色写入。主战用泰拳+八极拳：泰拳负责膝肘压迫、箍颈、低扫和硬顶；八极拳负责震脚、顶心肘、贴山靠、肩撞、短距离爆发。将军不是火焰狂攻型红茶，而是冷静、命令式、一步一步压缩空间的处刑型压制。
```

### 技法比例

```text
主战55%：泰拳
爆发35%：八极拳
控距破步10%：基础低扫/截腿/军用压步
```

### 技法职责

- 泰拳：横肘、砸肘、顶膝、箍颈膝撞、低扫、提膝硬顶，用于近身压迫、防守反击和连续削弱对手架势。
- 八极拳：震脚冲肘、顶心肘、贴山靠、崩拳、肩撞、沉身靠打，用于破防后短距离兑现重伤害。
- 基础控距：低扫截步、压步逼近、膝线封锁、脚步切角，让对手无法轻松脱离将军的近身压迫圈。

### 战斗路线

```text
冷静压步逼近 → 低扫/提膝封锁下盘 → 横肘砸肘破开护架 → 箍颈顶膝压迫腹胸 → 震脚贴身切入 → 八极顶心肘/贴山靠短爆发兑现 → 肩撞或沉身冲肘终结
```

### 典型压制逻辑

- 对方直拳抢先，将军小幅侧压步，横肘切入拳路外侧，肘尖贴着对方前臂滑入眉骨线，随即顶膝撞腹。
- 对方高位腿踢来，将军提膝硬顶小腿，脚落地同时震脚前压，八极顶心肘撞开胸口。
- 对方试图后撤，将军低扫截住前脚，箍颈把头线拉低，连续膝撞压迫腹胸，再以贴山靠震退。
- 对方近身抱摔，将军沉肘压肩、肩撞破抱，短距崩拳击肋，接砸肘收尾。

### 与红茶的核心差异化

| 维度 | 红茶 | 将军 |
|---|---|---|
| 气质 | 爆裂、灼烧、攻击代防 | 冷酷、纪律、处刑压迫 |
| 主视觉 | 橙红火焰膝肘轰炸 | 冷色军官式短爆发与硬压步 |
| 节奏 | 越打越炸、以攻代守 | 一步一步压缩空间、抓破绽重击 |
| 八极用法 | 贴身核爆辅助 | 与泰拳并列主轴，负责处刑式兑现 |
| 终结 | 膝肘同顶、火力爆发 | 震脚顶心肘、贴山靠、肩撞沉肘 |

### 禁止偏移

- 禁止与雷电将军/梦想一心太刀专项混淆；“将军”默认是徒手泰拳+八极角色，不默认持太刀、不触发梦想一心太刀术。
- 禁止写成红茶复刻；将军不强调橙红火焰狂暴，而强调冷酷压迫、军官式控制和短距处刑。
- 禁止写成灵巧闪避型；将军以压步、硬顶、肘膝、肩靠抢空间。
- 禁止只用泰拳不用八极；破防兑现必须经常出现震脚、顶心肘、贴山靠、肩撞等八极短爆发。
- 禁止只用八极不用泰拳；近身压迫必须有低扫、横肘、砸肘、顶膝、箍颈膝撞。
