# 视频提示词范式（短剧 / 漫剧 / 写实 / 纪实）

> **本文件由 `prompt-style-library` 原第 6 节整体拆出**：那个库专管**图像**提示词（七段结构 /
> 镜头 / 光线 / 调色 / Danbooru tag），本文件专管**中文视频**提示词。
> **画风英文词同样由后端收口，不要自己拼**（判定规则见 `prompt-style-library` 第 0 节）。
> 小节号沿用原 **6.x** 编号，便于与原库对照。

图像提示词词库（七段结构 / 镜头 / 光线 / 调色 / Danbooru tag）见 `prompt-style-library`。本文件是**中文视频提示词**范式，归纳自两批真实出片语料：

- **PromptMart 免费作品**（国内短剧 / 漫剧作者）→ 6.1–6.9，**时间码分段**为特征。
- **Seedance 2 语料**（8755 条平台通用中文提示词，CC BY 4.0）→ 6.10 **散文式多段**，
  以及对 6.1 / 6.2 / 6.3 的实测修正。

### 6.0 30 秒上手：定写法 → 挂通用件 → 填骨架

**第 1 步 · 定写法**（只看一件事：这条镜头**有没有明确的动作节拍**）

| 题材 | 写法 | 去哪节 |
|---|---|---|
| 短剧 / 漫剧 / 打斗 / 变身觉醒 / 特效向（节拍清晰） | **时间码分段** | 6.1 → 6.2 |
| 写实 / 纪实 / 广告 / 情绪向 / 空镜（节拍模糊） | **散文式多段** | 6.10 |
| 拿不准 | 默认散文式（语料里不以时间码组织的占 86%） | 6.10 |

**第 2 步 · 挂通用件**（下列 6 件**两种写法都带**，与题材无关）

| 通用件 | 解决什么 | 去哪节 |
|---|---|---|
| 角色一致性锚定句 | 跨镜头变脸 | 6.3 |
| 画质收口句 | 塑料感 / 不像实拍 | 6.4 |
| 一致性约束块 + `@图N` | 人物消失 / 畸变 / 跳轴 | 6.5 |
| 参考图素材链 | 三视图保一致性 | 6.6 |
| 中文标签词库 | 补镜头与细节 | 6.7 |
| 合规红线 | 审核拦截 | 6.9 |

**第 3 步 · 填骨架**：6.1（时间码向）/ 6.10（散文式）各有一份**可直接填空的骨架**，
照抄后把 `<>` 里换成自己的题材词即可，**不需要从零组织语言**。

> 速记：**先定 A/B 写法 → 再挂 6 个通用件 → 最后挑标签**。
> 6.8「作品摘要」是**剧集 / 分镜级**元信息，不写进单条提示词。

### 6.1 视频提示词的三段骨架（时间码向入口）

> **适用范围**：本节是 **6.2 时间码分段**用的容器骨架；走散文式的题材直接跳到 **6.10**。

单条 15 秒内的长镜头，成熟作者统一用**三段式骨架**，顺序固定：

```
核心主题：<风格> | <美学> | <母题> | <类型>丨<场景>

【人物与基础设定】
面部：参照上传图片，五官、脸型、发型百分百还原，杜绝美化。<表情/伤痕一致性要求>
服装：<材质 + 款式 + 关键配件 + 色彩>
场景：<地点 + 天气 + 时间 + 环境光 + 氛围元素>

【氛围与画质】
视觉基调：<摄影机/镜头模拟 + 焦段 + 光圈>
色彩与影调：<主色调 + 饱和度 + 暗部处理 + 颗粒/柔焦>
风格核心：<一句话说清要 copy 的美学来源>

【运镜规则】
镜头结构：<一镜到底｜多机位分切，二选一，**不要默认写一镜到底**>
角度：<开场机位> → <中段环绕/推进> → <收尾机位>
呼吸感：手持拍摄，全程保持极其轻微的、如呼吸般的镜头浮动，增强临场感。
```

**要点**：

- `【人物与基础设定】` 与 `【氛围与画质】` 只写**不随时间变化**的常量；
  凡是会动的，一律放进 6.2 的时间码段落。
- `【运镜规则】` 描述的是**整条镜头的机位轨迹**，不是某个瞬间的景别。
- **「一镜到底」不是默认项**：实测 8755 条中文视频语料中仅 323 次提及（≈4%）。
  真正高频的是可动机位词 —— `旋转 / 手持 / 环绕 / 推进 / 定格 / 跟随`。
  需要连续动作节拍（打斗、变身）才用一镜到底，否则写分切更稳。

### 6.2 时间码段落化（短剧 / 漫剧向主力写法）

> **适用范围**：只用于**有明确动作节拍**的题材（写法判定见 6.0，其余题材走 6.10）。
> 实测 8755 条中文视频语料中，真正用时间码分段的仅 **14%**（作分段标题的仅 3%）——
> 时间码是**短剧圈的圈内写法**，不是视频提示词的通用主流。

把 15 秒切成 4–5 段，每段用 `起-止秒 · 段落名` 作小标题，
段内按 **动作 / 镜头 / 特效 /（声音）** 分键写。段落名走**情绪递进**：

```
0-3秒 · 凝视
动作：主角略微低头，目光锁定腰带，脊背紧绷。右手缓慢抬起，握住腰带主体。
镜头：极缓向前推进，捕捉身体因呼吸产生的微幅起伏。
特效：整颗眼球骤然亮起白金色光芒，眼眶周围皲裂。眼睛亮起的炫光使画面镜头产生光斑。

3-6秒 · 启动
声音：低语：「HENSHIN」。
动作：话音刚落，手掌用力按压腰带核心……启动装置后慢慢松开手。
特效：金属机械装置被暴力唤醒……身体周围水平震荡出一圈半透明的脉冲波动。
镜头：低频嗡鸣由远及近，镜头随之一同产生应激性的 0.1 秒微颤。
```

**可复用的段落名谱**：

- 变身/觉醒类：`凝视 → 启动 → 撕裂 → 生长 → 完成`
- 打斗类：`蓄力 → 爆发 → 命中 → 反扑 → 终结`

**为什么有效**：视频模型对「秒数 + 小标题」的响应远好于一段连续长句；
分键写法让模型知道**哪个词管动作、哪个词管镜头**，不会把镜头描述当成动作去演。

### 6.3 角色一致性锚定句

跨镜头要保住同一个人，开头必须钉死这两句：

```
面部：参照上传图片，五官、脸型、发型百分百还原，杜绝美化。
面部伤口，纱布，血渍保持一致。刘海覆额，表情全程阴郁。
```

- `参照上传图片……百分百还原，杜绝美化` —— **反美化**是关键；
  不写这句模型会自动磨皮美化，几段之间就变成两张脸。
- 有伤 / 战损 / 特殊妆造的，必须逐个点名「保持一致」。

### 6.4 画质收口固定句

下面这句在多组**互不相干的作者**的写实向作品里逐字复用，可直接作为写实向画质收口：

```
色彩与影调：低饱和灰蓝主调。暗部信息压缩，保留细节。
边缘添加轻微柔焦与适度的胶片颗粒感。
```

- `暗部信息压缩，保留细节` 与 `边缘添加轻微柔焦` 是让画面「像实拍」的两大关键，
  比堆 `8k, ultra detailed` 有效得多。
- 主色调按题材替换（`低饱和灰蓝` / `灰蓝冷调` / `好莱坞青橙色调`），
  后半句「暗部信息压缩，保留细节。边缘添加轻微柔焦与适度的胶片颗粒感。」**原样保留**。

### 6.5 一致性约束块 + 多参考图占位

视频模型最容易出的问题是**人物中途消失、肢体畸变、左右手互换、镜头跳轴**。
在**最开头**先写一段约束，再写正文：

```
要求：生成的视频人物不要出现人物突然消失或人物出现畸形等情况，
要保持人物身体朝向连贯统一，肢体逻辑正常，手部左右方位不变，
镜头过渡自然，人体骨骼合理，动作连贯，无突兀角度跳转。
```

多参考图用 `@图N（文件名）` 分工绑定，**名称与文件名一起写**，换图按编号替换：

```
本片段场景设定在：赵家别墅庭院 @图1（庭院镜头.png） 夜晚
@图2（慕雪.png） 慕雪白衣胜雪，赤手空拳……
```

另一种等价的「关键元素」写法（**本项目更推荐**，便于与角色/场景/武器库对接）：

```
关键元素：
主角：参考【图片】。
武器：参考【图片】。
敌人：参考【图片】。
场景：参考【图片】。
```

### 6.6 参考图素材链（三视图 → 视频）

成熟作者的产图流程 —— **角色一致性靠三视图，不靠提示词反复描述**：

1. MJ / Seedream 生**场景、怪物、武器、装甲**等单件资产图
2. Flux 优化材质与真实感
3. **出三视图**：「正面、侧面、背面三视图，保持不同角度主体统一性，每个角度均展示全身」
4. 参考图 + 提示词一起给视频模型；**不用分镜图**，长镜头拆两段生成再剪辑

MJ 参数尾巴（仅图像模型用）：`--ar 16:9 --v 6 --style raw`

**拆段生成策略**：一条 25 秒的打斗拆成「武器充能 10–15s」+「打斗 15s」
两段分别生成再剪辑，成功率远高于硬凑一条长镜头。

**声音**：统一写 `声音：不要配乐，仅保留同期声。` —— 与项目「后期统一配乐」一致。

| **节奏 / 时间** | 一镜到底、慢动作、慢镜、定格、卡点、子弹时间、呼吸感 |
| **特效 / 物理** | 冲击波、残影、动态模糊、运动模糊、速度线、粒子特效、体积光、丁达尔光、光柱、空间扭曲、蘑菇云、碎石飞溅、烟尘、雷暴、极光、剑气、电弧、冰爆 |
| **动作 / 招式** | 蓄力、格挡、突进、旋身、转身、跃起、腾空、悬浮、回旋踢、拔剑、挥剑、收势、瞬移、近身格斗、单膝跪地 |
| **武学门派** | 咏春、洪拳、谭腿、泰拳 |
| **质感 / 影调** | 胶片颗粒、胶片质感、高对比光影、电影感、超写实、3D 渲染、3D 国漫 |
| **情绪 / 张力** | 压迫感、高燃、史诗感、视觉震撼、视觉冲击 |
| **纪实 / 都市（非动作向）** | 自然光与实用光源混合、真实环境杂乱、压缩背景透视、部分遮挡构图、长焦偷拍感 |
| **画幅 / 构图（全题材）** | 垂直 9:16、横向 16:9、偏心构图、三分构图、前景遮挡、低机位 |

**用法**：一次镜头从**每个组各取 1–2 个**即可，不要同组堆叠
（`仰拍 + 低角度 + 俯拍` 互相矛盾，模型会随机二选一）。

**按题材取组**（本表同时覆盖动作向与纪实向，**不是每类都要用**）：

| 题材 | 取这几组 |
|---|---|
| 打斗 / 特效 / 漫剧 | 镜头机位 + 节奏时间 + 特效物理 + 动作招式 + 情绪张力 |
| 写实 / 纪实 / 广告 / 情绪向 | 纪实都市 + 质感影调 + 画幅构图（**不用**动作招式 / 武学门派） |
| 古风 / 武侠 | 动作招式 + 武学门派 + 质感影调 |
| 任意题材都可加 | 镜头机位 + 画幅构图 |

### 6.8 三段式作品摘要

短剧作者普遍给作品写三段式元信息，可作为**分镜与剧集的摘要模板**：

```
作品风格：<美学风格 + 影调 + 质感>
技术参数：<镜头 / 光线 / 物理特效 / 渲染 技术点>
作品摘要：<一段完整叙事：场景 → 人物 → 动作 → 转折 → 收尾>
```

**「作品摘要」的写法值得学**：它把一条几十秒的视频写成一段**有起承转合**的文字 ——
这正是拆镜时要产出的东西。

### 6.9 合规红线

站外作品皆为作者原创投稿。**只提炼范式，不得搬运他人提示词正文**：

- ✅ 借鉴：三段骨架、时间码段落名、锚定句、收口句、标签词汇、摘要三段式
- ❌ 搬运：整段复制某条作品的 promptText 作为本项目资产
- 版权红线：参考图必须**自己用 AI 生成或用本项目自有资产**，不得直接使用他人成图
- 该类站点部分作品需「灵感豆」付费解锁（精选 25/条）；**只取免费与公开信息，不要为取词付费**
- 实测：站内**免费作品（`freeUnlock`）中确有成体系的完整范式**，取词优先走免费区

### 6.10 散文式多段模板（平台通用向主力写法）

6.1–6.9 的骨架源自**国内短剧 / 漫剧作者**。另一大群体 —— 平台通用短视频（纪实、广告、
Vlog、内容创作）—— 的主流写法是**散文式多段**：不分时间码，按「语义职能」切 8–10 段，
每段一到三句（写法判定见 6.0，本写法即其中「散文式」一档；语料里不以时间码组织的是绝大多数）。

**十段模板**（段名即职能，按需增删，顺序基本固定）：

```
① 身份锚定  作为严格锁定的身份引用。保持准确的面部比例、眼型、下颌线、嘴唇、
            发型轮廓、发色分布和逼真的皮肤质感。保持面部的完整一致性和真实感。
            没有风格化、美化或人工增强。
② 画面类型  超写实的<题材>照片/短片，拍摄<主体>在<地点><时间><动作>。
            这张画面必须像是<真实来源>——而不是<要排除的错误方向>。
③ 摄影美学  原始的<流派>美学，不完美的自然构图，扎实的现实主义，轻微手持不稳，
            自动对焦不完美，逼真的环境瑕疵。
④ 主体外形  <面容 + 眼神 + 发色发型 + 皮肤质感>。<服装材质 + 款式 + 配件 + 色彩>。
⑤ 动作姿态  <身体姿态 + 视线 + 手部位置 + 与环境的关系>。
⑥ 镜头器材  使用<具体焦段>（如 200mm–400mm 视角）、压缩背景透视、浅层自动对焦不一致、
            轻微运动模糊、自然高 ISO 颗粒、自动对焦呼吸。
⑦ 环境光线  <环境元素清单>。自然光与实用光源的混合，逼真的阴影衰减，物理逼真的光照表现。
⑧ 情绪定调  《Mood》是<一句话情绪命名>——<一句补充画面感>。
⑨ 构图画幅  构图：<画幅比例>，<构图法>，<前景处理>。
⑩ 负面提示  负面提示：<反例A>、<反例B>、……
```

**四条可直接复用的关键手法**：

1. **部位清单式锚定** 优于笼统的「五官脸型发型」。
   逐部位点名（面部比例 / 眼型 / 下颌线 / 嘴唇 / 发型轮廓 / 发色分布 / 皮肤质感），
   模型漏项的机会更小。6.3 的「杜绝美化」仍是必要补充（它对抗的是模型默认磨皮）。
2. **反 AI 感词族**（让画面「像实拍」的关键，与 6.4 的胶片收口句互补）：
   `不完美的自然构图`、`自动对焦不完美`、`逼真的环境瑕疵`、`可信的瑕疵`、`轻微手持不稳`、
   `细微的压缩伪影`、`自然高ISO颗粒`、`细微传感器噪点`、`自动对焦呼吸`。
   —— 这类**可控缺陷**比堆 `8k, ultra detailed` 更能压掉塑料感。
3. **具体焦段 + 器材缺陷** 优于笼统的「电影感」：
   `200mm–400mm 视角` + `浅层自动对焦不一致` + `轻微运动模糊`，可执行性强得多。
4. **独立「负面提示：」末段**：用顿号并列反例，不要散落正文。常见反例族：
   `AI艺术、CGI、美妆滤镜、过度处理的HDR、塑料皮肤、娃娃脸、完美对称、摄影棚摄影、
   假散景、动漫、奇幻灯光、过度锐化、不真实的眼睛`。

**常见误用（务必避免）**：

- 十段**全写满**会导致提示词冗长失焦。情绪向题材可只留 ①②④⑤⑧⑩ 六段。
- 十段模板是**归纳出的骨架，不是逐字模板** —— 段内用词必须按题材替换。
- **长镜头拆多段**时，要在段尾显式写明衔接声明（如「与 Image 1 完美衔接」，或中文
  「与上一镜末尾画面完美衔接」），并同步更新 6.5 的 `@图N` 编号，否则模型会当成无关新画面。

---

## 7. 硬性禁止项

以下内容一旦写进提示词，轻则浪费额度，重则触发审核拦截：

1. **不要写真人姓名 / 在世导演姓名**（如「某某某风格」）——肖像权与版权风险
2. **不要写画面内可读文字**——与项目 `UI_OVERLAY_RULE` 一致：
   手机/电脑/新闻/短信/监控/地图/时间码等屏幕一律**只留白面**，文字后期叠加，防止 AI 生成乱码
3. **不要写画面内背景音乐**——项目统一后期配乐
4. **不要堆无意义质量词**——`masterpiece, best quality, 8k, ultra detailed` 堆超过 3 个收益递减，
   优先把额度花在镜头/光线锚点上
5. **不要在同一句里混用两套体系**——`realistic skin texture, cel shading` 这类自相矛盾的词
   会让模型二选一，输出不稳定

## 8. 自检清单

输出提示词前逐条确认：

- [ ] 主体是否在最前面？
- [ ] 是否**没有**写画风词（第 0 节）？
- [ ] 是否给了具体镜头（景别 + 机位，写实向再加焦段）？
- [ ] 是否给了具体光位或光源？
- [ ] 动漫向是否用了逗号分隔的 tag 而非句子？视角 tag 是否给了？
- [ ] 是否避开了真人姓名 / 画面内文字 / 画面内音乐？
- [ ] 词序是否与当前画风兼容（对照第 0 节矩阵）？
- [ ] **是否先按 6.0 选定写法**（而不是默认套 6.1；6.1 只服务时间码向）？
- [ ] 若走时间码：是否按三段骨架组织、15 秒内切成 3–5 段、段内分「动作/镜头/特效/声音」（第 6.1 / 6.2 节）？
- [ ] 是否**没有默写「一镜到底」**（仅约 4% 语料使用，需连续动作节拍才用）？
- [ ] 若走散文式：是否含**独立「负面提示：」末段**、是否用**具体焦段 + 器材缺陷**而非笼统「电影感」（第 6.10 节）？
- [ ] 跨镜头是否写了角色一致性锚定句「百分百还原，杜绝美化」（第 6.3 节）？
- [ ] 写实向是否带了画质收口句「暗部信息压缩，保留细节…」（第 6.4 节）？
- [ ] 是否补了一致性约束块、多参考图是否绑定清楚（第 6.5 节）？
- [ ] 是否用**自有三视图**而非他人成图做参考（第 6.6 / 6.9 节）？
- [ ] 中文标签是否**每组只取 1–2 个**、没有组内矛盾（第 6.7 节）？
- [ ] 是否只借鉴了范式，没有搬运他人提示词原文（第 6.9 节）？
