# 动作语汇库（通用术语）

来源：`data/playbook/film-expert-bridge/general/动作专题库.md`
（素材原名「动作专题库」，含 13 节、约 340 条）。

**只收通用武术 / 格斗术语**，用来把"打得很激烈"换成能拍的具体动作。素材里的文艺自造名
已在 §九 列出并说明为何不收。受击怎么写、运镜怎么选见 `hit-reaction-and-moves.md`；
镜头规格见 `shot-spec-and-break.md`。

用法：写分镜时**一镜一到两个动作**，从对应类别取词，别把三个动作塞进一个镜头。

## 十六、不收录什么（以及为什么）

| 不收录 | 例 | 理由 |
|---|---|---|
| 高级剑法 25 式 | 天罡横扫 / 九霄凌云 / 万剑归宗 / 天外飞仙 | 素材作者的**世界观产物**，与本剧角色武学体系串味，照抄等于给角色安别人的绝招 |
| 高级枪法 25 式 | 缨舞惊鸿 / 游龙盘柱 / 天女散花 | 同上 |
| 轻功 25 式 | 踏云回风 / 断崖折月 / 霓裳折光 | 同上（其**技术形态**已提炼进 §十三 身法） |
| 高级刀法 25 式 | 风卷残云 / 烈焰焚天 / 日月同辉 | 同上 |
| 高级掌法部分 | 凝成金龙头 / 万象归一 / 终极降龙掌 | 同上（通用部分已收进 §十二） |
| 能量环境 / 击中的**原句** | 「凌厉斩击，银白色剑气撕裂空气…」 | 那是素材作者的提示词**原文句子**，直接搬属照抄；只提炼维度（§十四）、类别词（§十五）与冷暖判据 |
| 15 秒 / 30 秒打戏时长体系 | 一镜 1.5 秒、30 秒必须拆两条提示词 | 那是短视频口径，与本仓「单镜 5 秒」冲突，**不可移植** |
| 七角色武学绑定 / 角色相克矩阵 | 某角色的专属招式与克制表 | 别人家的角色资产，本剧角色由项目设定集定义 |
