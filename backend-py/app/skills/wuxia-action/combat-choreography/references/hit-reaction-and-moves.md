# 受击反馈与招式字典

> 用途：写打斗提示词时，解决两个具体问题 —— ①"一拳打上去像打铁板"；②"招式写得笼统、镜头不知道跟着谁"。
> 来源：2026-11-04 消化原料库《打斗镜头招式组合库》的受击反馈补丁、打斗运镜 15 种与招式字典部分（招式连段范例与图片参考不入仓）。
> 与 SKILL.md 的关系：SKILL.md §一「动作链四拍」管**结构**，本份管**每一拍的落点与可见反应**。

## 一、铁律：任何一击必须写两件事

1. **攻方**：出什么招、打到哪、力度（原本就在写）；
2. **受方**：被打瞬间身体的物理反应（最容易漏，本份就是补它）。

反例（踩坑本体）："他出拳，他肘击" —— 只写动作不写反应，必出打铁板。
正例："精瘦男一记直拳轰在壮汉胸口，壮汉上身被冲击力带得后仰、脚下踉跄半步，胸口布料凹陷，闷哼一声。"

## 二、受击方反应模板（按部位选写）

| 被打部位 | 可见反应 |
|---|---|
| 躯干/腹部 | 上身被冲击力带得前倾或后仰、脚下踉跄半步、腰带/束腹处衣料凹陷、闷哼、双手捂腹 |
| 头部/下颌 | 头部猛地甩动、脖子一歪、眼神瞬间涣散、牙齿磕碰声、发懵踉跄 |
| 腿部 | 膝盖一软、重心晃动、小腿肌肉紧绷凸起、吃痛一瘸 |
| 重击/终结 | 整个人向后飞退或被砸倒、扬起尘土、落地轻微反弹、手臂摊开 |
| 格挡方（没被打中） | 小臂/前臂肌肉绷紧鼓起、格挡处衣料被压出凹痕、稳稳接住或被推退半步 |

镜头配合：重击瞬间镜头微震、命中帧极短停顿、命中点肌肉形变/衣料凹陷要可见。**不要"力直接穿过身体"。**

群斗/多打一时逐个写明每个被打者的反应，别让挨打的人当木桩。

## 三、打斗运镜 15 种

| # | 运镜 | 提示词 | 用在 |
|---|---|---|---|
| 1 | 跟拍跟镜 | 镜头跟随两人近身拳脚互搏，近距离跟拍，运动轨迹记录细节 | 近身缠斗 |
| 2 | 环绕 | 以两人为圆心 360° 慢环绕，展示对峙姿态与发力 | 对峙 |
| 3 | 急速推镜 | 重拳或高扫踢瞬间镜头猛然前冲，聚焦攻击落点 | 重击瞬间 |
| 4 | 急速拉镜 | 腾空飞踢落地瞬间快速后拉，展示站位与场地 | 落地收招 |
| 5 | 低角度仰拍 | 贴地低机位仰拍起手重势或起跳出腿，压迫感 | 起手、压迫 |
| 6 | 高空俯拍 | 高空垂直/斜俯双人缠斗，清晰展示走位线 | 走位展示 |
| 7 | 慢动作跟镜 | 高难动作慢动作跟拍，清晰记录发力细节 | 高难招式 |
| 8 | 摇镜横移 | 水平平稳左右横摇，跟随双方横向移动 | 横向缠斗 |
| 9 | 甩镜闪切 | 破防时镜头急速甩动，轻缓摇回慢镜头，缓冲冲击 | 破防 |
| 10 | 特写切镜 | 拳头蓄力、腿部起势、面部眼神三段局部特写快速切换 | 蓄力三段 |
| 11 | 升降 | 随人物腾空升起、落地下降，贴合动作节奏 | 腾空招式 |
| 12 | 穿梭 | 穿过柱子门框等间隙跟拍，增强临场感 | 场景穿梭 |
| 13 | 反打交替 | 双方贴身交替出拳、闪避、格挡、反击，镜头对位切换 | 攻防交替 |
| 14 | 旋转摇镜 | 旋踢转身时镜头小幅自转，形成联动动感 | 旋踢转身 |
| 15 | 定格定镜 | 命中瞬间画面定格停格，强调重攻击 | 命中定格 |

## 四、招式命名规则（本仓自有，不套外部连段）

招式词只用于**给动作命名**，不是必须照搬的连段模板。命名按"部位 + 形态 + 方向"三段式：

- **拳**：直拳 / 摆拳 / 勾拳 / 刺拳 / 上勾拳 / 鞭拳 / 砸拳 / 劈拳
- **肘**：肘击 / 顶肘 / 横肘 / 砸肘 / 后肘
- **腿**：正蹬 / 侧踹 / 鞭腿 / 扫腿 / 低扫踢 / 高扫踢 / 弹腿 / 截腿
- **膝**：膝撞 / 顶膝 / 飞膝 / 侧膝
- **摔**：抱摔 / 过肩摔 / 背摔 / 抱腿摔 / 绊摔
- **锁**：锁喉 / 裸绞 / 十字固 / 三角锁 / 脚踝锁
- **防御**：格挡 / 拍挡 / 下潜躲闪 / 侧移闪避 / 后撤步闪避
- **反击**：接腿反击 / 连击快打 / 近身缠抱 / 突围挣脱 / 低空扫击

使用约束：
- 一次连段 2–4 招，落点要分散（面/腹/肋/头/肘/膝），别三招都打同一个地方。
- 招式必须有**角色签名**：同一角色重复用同一两招作为标识，别每场换新招。
- 高难招式（720 旋踢、凌空连踢）配"慢动作跟镜"，否则出片必糊。

## 五、距离—节奏对照

| 距离 | 常见动作 | 节奏 | 推荐景别/机位 |
|---|---|---|---|
| 远（>3 步） | 冲刺、腾空、追击 | 快 | 全景/远景，俯瞰或低角度 |
| 中（1–3 步） | 鞭腿、扫腿、飞踢 | 快慢交替 | 中景，侧面或绕正 |
| 近（贴身） | 肘、膝、锁、摔 | 快，短促 | 中近景/特写，越肩或手持 |
| 缠抱/地面 | 压制、挣脱、锁技 | 慢 | 俯拍或极近距离 |

节奏铁律：**不许均匀**。每 1.5 秒左右一个动作节点，重击前留半拍静止（蓄力），命中后给一拍反应（反馈）。

## 六、自检

- 每一击都写了受方反应吗？逐个数一遍，别漏中间那几下。
- 群斗时每个被打者都有反应吗？
- 连段落点是不是太集中？
- 连段里有没有角色签名招式？
- 高难动作配慢镜了吗？
- 命中帧有没有微震/顿帧？
