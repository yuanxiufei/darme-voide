## 一、每镜必须写全五项

一条打戏镜头描述必须同时给出：**景别 + 视角 + 角度 + 运镜 + 跟随目标**。

| 缺哪项 | 后果 |
|---|---|
| 景别 | 出力时不知道人物占多大画面，全身/半身/特写随机 |
| 视角（谁的视角/过谁的肩） | 对位关系丢失，观众分不清谁在哪边 |
| 角度（平视/仰/俯/斜） | 气势与失衡关系丢失 |
| 运镜 | 静帧化，动作变成摆拍 |
| 跟随目标 | 镜头跟着谁走不明确，出力时镜头乱飘 |

- ❌ `两人交手，拳风凌厉，气势逼人`
- ✅ `中景，过肩视角（凌云右肩后），平视，跟拍，镜头跟随凌云上步压入`

**判据**：五项缺任一项，等于把镜头交给模型随机决定，抽三次出三个样。

## 二、镜头目的性四原则

1. 一个镜头只承担一个功能：**给信息 / 给冲击 / 给情绪 / 给节奏**。
2. 说不出功能的镜头删掉——不许靠换景别凑时长。
3. 相邻两镜功能相同即冗余：改角度，或删一个。
4. 转场必须换景别或换角度，**不许同机位硬切**（读起来像剪辑事故）。

---

## 三、中景铁律

- 中景（含双人对招）**机位不许倾斜**。倾斜只留给冲击镜和失衡镜。
- 禁无目的斜俯 / 斜仰：斜角必须对应「弱势方视角」或「身体失衡」，否则回平视。
- 禁无意义全景拉远：拉远必须交代环境或体量差（人多、场地大、落差高），否则留中景。
- 中景侧拍最忌讳拍成"两人站桩互相推手"，解法是加**步法位移**（进半步、退半步、绕侧），让人物在画面里有纵深移动。

---

## 四、有效中景裁切：下沿由「发力链是否可见」决定

不是构图好看决定裁切，是**这一击的力量从哪里来、到哪里去能不能看见**决定。

| 攻击类型 | 画框下沿 | 理由 |
|---|---|---|
| 腿法（低扫 / 鞭腿 / 侧踹） | 到小腿以下 | 必须同时看见起势与落点，否则不知踢没踢中 |
| 长拳 / 直拳 / 摆拳 | 到大腿 | 保留腰胯转动的发力链 |
| 肘 / 膝近身 | 收到胸口以上 | 反而要放大肘尖与膝盖的接触点 |
| 擒拿 / 锁技 | 收到**手部特写** | 全身景看不出关节被别在哪个角度 |
| 摔投 | 必须含双脚与地面 | 不含地面就看不出"被摔"，只见两人抱在一起 |
| 兵器 | 含兵器全长，至多一端出画 | 剑尖出画＝不知道打没打中 |

反例：中景侧拍打一整套拳，手脚全在画面里，但看不出打中哪里——这是"格斗游戏感"的典型成因。

## 五、镜头衔接链：起手 → 攻 → 受 → 反 → 定

一次完整交手给五个镜头，缺哪环观众就在哪环掉线。

1. **攻防因果必须同拍**：出拳与格挡在同镜或紧邻两镜内，拆开就变成"各打各的"。
2. **同方向入镜**：连续两镜里主体的运动方向必须一致（屏幕左→右就一路左→右）。换向必须用**过肩镜头或反打**重新交代，否则观众读成"两人在互相后退"。
3. **过肩镜头的作用是重建对位**：视角一换，得让观众重新知道谁在哪边、谁背对镜头。
4. **受击镜必须含反应**：只拍打人、不拍被打的人怎么倒，力量就落不到观众身上。
5. **收势镜交代结果**：站着 / 跪着 / 兵器脱手 / 退开，四选一，别让上一镜的姿势悬着。

---

## 六、破招放大五条

1. **只放大一次**：一段打戏里"反制成功"的高光只给一个。给两个以上，两个都不值钱。
2. 放大靠**减速 + 切近 + 留白**（动作停 0.3 秒 / 切手部或眼部 / 抽掉环境声），不是靠堆特效。
3. 破招后必须给**结果镜**（对手失衡、兵器脱手、退半步、单膝跪地），否则观众不知道破了什么。
4. 破招前要有 1–2 镜「被压制」铺垫：没有劣势就没有破招的快感。
5. 反制动作要能被单帧读懂：**一个关节、一个方向、一个结果**。三个动作叠在一镜＝看不清。

## 七、八种可复用镜头模式

| 模式 | 用在哪 | 一句话写法 |
|---|---|---|
| 对峙推近 | 开打前 | 双人中景，缓慢推近，镜头随呼吸微颤 |
| 起手低机位 | 第一击之前 | 低角度仰拍，脚与地面入画，起势蓄力 |
| 过肩攻防 | 互相试探 | 过肩视角，一方进半步，另一方格挡在画面内侧 |
| 接触特写 | 击中瞬间 | 特写接触点，短促，前后各留 3 帧 |
| 受击甩镜 | 被击中 | 跟随被打者后退方向甩镜，纳入环境 |
| 环绕制衡 | 势均力敌 | 环绕运镜半周，两人距离不变但背景在转 |
| 破招减速 | 反制 | 减速，切手部特写，环境声抽空 |
| 终结拉远 | 结尾 | 从接触点快速拉远到全景，交代结果与场地 |

---

## 八、冷暖对抗

同色系的两种特效对撞**打不起来**——观众看不出谁压谁。

- 正邪 / 双方特效必须**冷暖对立**：金 vs 幽蓝、赤红 vs 青白、紫 vs 橙黄。
- 判据：两条提示词写的主色若同属暖调或同属冷调，改掉一边。
- 同一角色跨镜头的特效色**不许变**（这是角色识别的一部分，属连续性范畴）。

## 九、执行层净化：成品提示词不许出现元话术

这些词一旦写进提示词就会被模型当画面内容去画，或者把构图指令读成字幕：

`镜头1` `第X个镜头` `时长X秒` `注意` `要求` `必须` `这里要表现` `目的是` `分镜说明`
`（括号注释）` `Seedance` `参考图` `图生视频` `如上所述`

改写方向：把意图换成**可被相机拍到的物理事实**。

| 元话术 | 改成 |
|---|---|
| 这里要表现他很愤怒 | 指节发白，下颌绷紧，颈侧青筋凸起 |
| 目的是显示两人实力差距 | 一方退半步稳住，另一方脚未动、衣角先落 |
| 这段要快 | 三步之内完成，接触帧只留一帧 |
| 参考图里的人物 | （删掉这行，把人物特征直接写进正文） |

**判据**：成品提示词的每一句都必须是物理事实，不是给导演看的备注。

## 十、出稿前自检

- [ ] 每镜都有景别 / 视角 / 角度 / 运镜 / 跟随目标五项
- [ ] 没有功能重复的相邻镜头
- [ ] 中景未倾斜，斜角都有对应理由
- [ ] 裁切下沿按攻击类型定过（腿法见落点、锁技给手部、摔投含地面）
- [ ] 一次交手有起手→攻→受→反→定，攻防因果没拆开
- [ ] 同一段里运动方向连续，换向用了过肩或反打
- [ ] 破招只放大一次，且有铺垫与结果镜
- [ ] 双方特效冷暖对立，同角色跨镜不换色
- [ ] 提示词里没有元话术、没有编号、没有括号备注
