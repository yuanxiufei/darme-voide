# 打戏编排

打戏不好看，九成不是「招式不够酷」，是**没有受力**。观众要的因果是
「这一下打上去，他身体怎么了」。所以本 skill 的核心只有一句：

> **每一个动作都要有一个「反应」跟着，否则它不算发生过。**

## 什么时候用 / 不用

**用**：剧本里有对打／追逐中的缠斗／以武逼供／群战清扫／终结技；
分镜要把「两人打起来」拆成能拍的一格格；导演问「这一场怎么调度」。

**不用**：纯文戏、只提一句「他打了他一拳」就转场的过场戏（那种交给剧本节奏，不要为它建打戏结构）。

## 一、动作链：四拍

一段打斗 = 若干条动作链。一条链四拍，缺一拍观众就读不懂：

| 拍 | 写什么 | 反例（缺这个就废） |
|---|---|---|
| **蓄力** | 重心/握法/呼吸/眼神落在哪，身体先有预兆 | 抬手就打，像剪贴画 |
| **出招** | 用什么打（拳/肘/膝/剑/法术/借物），轨迹是直线还是弧线 | 「发动攻击」——这四个字没法拍 |
| **受击** | 受方**物理**反应：躯干弯折、头偏、膝软、后退半步、护具碎裂 | 「他被打中了」——这是结论不是画面 |
| **反馈** | 镜头反应（微震/顿帧）＋环境反应（石屑/水花/尘埃/窗纸破） | 打完两人原地站定，环境没事 |

**判据（可机检）**：任取一拍，若这一句里找不到「谁的身体动了／什么东西动了」，
这一拍就是空的。空的拍不许进分镜。

### 一条链的写法样板

> 甲右脚蹬地（蓄力）→ 横刀自左肋斜劈而上，刀背压着乙的护臂往上推（出招）
> → 乙左臂被抬开、身体右倾半尺，脚跟蹭出泥痕（受击）
> → 刀背刮过铁片带出一串火星，镜头随刀一抖（反馈）

对照看：四拍都有主语、都有位移、都有可拍的东西。

### 节奏：不许均匀

- **蓄力段留白**（长镜、慢推、环境声），**爆发段短切**（2–3 拍一镜，甚至一拍一镜）。
- 连续三次同长度同景别的出手 = 没有节奏 = 观众开始走神。
- 打斗的「重」来自**停顿**，不来自动作数量：最重的一下之前要有半秒的静。

## 二、空间与轴线

1. **第一镜必须建立方位**：A 在画左、B 在画右、多远的距离、周围有什么可借的物。
   后面所有镜头都按这套方位走，**无理由不左右翻转**（越轴 = 观众瞬间失去空间感）。
2. **正反打标清谁在左**。写分镜时每一镜都标：`（A左/B右）`。
3. **借环境要有据**：竹林借竹、河滩借水、古刹借柱。环境不参与打斗 = 虚空打 = 假。
4. **尾帧接首帧**：前一镜最后一格 = 后一镜第一格的状态，接不上就重排。

## 三、出场前的自检（逐条过，缺一条不出稿）

### 空间与连续性

- [ ] 第一镜已建立两人左右方位、距离、环境锚点
- [ ] 正反打不越轴，每镜标了谁在左／右
- [ ] 走位定了之后，首帧与视频都照同一套走位派生
- [ ] 相邻镜头尾帧接得上首帧

### 分镜质量

- [ ] 每格动作都不同（禁止重复构图／同一姿势摆拍）
- [ ] 角色移动方向与机位运动方向都交代了
- [ ] 因果链完整：蓄力→出招→受击→反馈→结果
- [ ] 每格都在放大某个信息（力量／压迫／速度），不是摆 pose

### 受力反馈

- [ ] 写清了攻方**用什么**打（拳／脚／剑／法术／器物）
- [ ] 写清了受方**怎么吃**这一下（躯干弯／头偏／腿软／后退／格挡）
- [ ] 打击瞬间有镜头反应（微震／顿帧），不是「打铁板」
- [ ] 飞溅／碎石／气浪出现在**击打发生时**，不是镜头开头就有

### 角色一致性

- [ ] 人物脸用参考图锁（纯文生开盲盒必脸崩）
- [ ] 招式按该角色的武学体系出，不串角色
- [ ] 同一组对手，之前用过的招式不重复

### 环境与质感

- [ ] 打斗影响环境（碎石／气流／水波／树叶），不是虚空打
- [ ] 用了场景的空间锚点（可交互物／材质／光色）
- [ ] 负向提示排除了畸形四肢／多手多脚／穿模／僵硬漂浮
- [ ] 皮肤／布料／金属质感符合题材，不塑料

### 台词与时长（本仓口径）

- [ ] 有台词的镜头，时长 ≥ 字数 ÷ 语速（中文 4–5 字/秒）
- [ ] 首帧 = 这段戏时间线第一画面，不拿高潮帧当头帧
- [ ] 时长分配不机械平均：爆发段短切、蓄力段留白

### 大招／终结技（如有）

- [ ] 前摇→聚能→释放→受击→终结，链条不缺环
- [ ] 最后一帧留得住印象，不是打完就切

## 五、边界

- **不改剧本**：本 skill 只决定「怎么拍」，不决定「打成什么样才算赢」。台词、胜负、
  人物动机一律以剧本为准 —— 为了好拍而改台词、并场次、削冲突，是本仓明令禁止的。
- **不写画面**：光位、焦段、画风、负面词属于 `video-prompt-library`；这里只写清动作与受力。
- **素材是参考不是模板**：招式名与连招是别人的设计，照抄会串角色。取的是「受力怎么落、
  环境怎么借、节奏怎么断」，具体招式必须按本项目角色的武学体系重新配。
