# 角色与场景提取指南

> **分工**：「冒号前名字即说话角色」「别名归一」「当前集优先复用」等识别与去重规则
> 已写在系统提示词里，**本文件不重复**。这里只给系统提示词没有量化的**填写标准**。

## 字段填写标准

### 角色

| 字段 | 标准 |
|---|---|
| 姓名 | 角色全名（不用别名 / 昵称） |
| 角色定位 | 主角 / 配角 / 龙套 —— 按戏份与剧情作用判断，拿不准按配角 |
| 外貌描写 | **300-500 字**，覆盖性别、年龄、体型、面部特征、发型、着装；要具体到可作画，避免「很帅」「气质出众」这类不可视化表述 |
| 性格特点 | 2-4 个核心标签，不要罗列式堆砌 |
| 角色描述 | 背景与人物关系，写清「他是谁、为什么在这里」 |

### 场景

| 字段 | 标准 |
|---|---|
| 地点 | 具体场所名（「老宅正厅」优于「室内」） |
| 时间 | 时间段 + 光线条件（「黄昏 / 暖橘侧逆光」优于「晚上」） |
| 氛围 | 环境感受与情绪基调 |
| 提示词 | 英文，**纯背景不含人物**；地点 / 时间 / 光线 / 氛围 / 天气 / 季节 / 风格齐备 |

### 道具

| 字段 | 标准 |
|---|---|
| 名称 | 道具名与剧本用词一致，便于后续引用 |
| 类型 | 日常 / 武器 / 交通 / 装饰 / 信物等 |
| 描述 | 外观与用途；对剧情有作用的要写清「在哪一环起作用」 |
| 图片提示词 | 英文，突出材质与形制 |

## 提取边界

- 只提取**当前集真实出现或被明确提及、且对叙事有效**的条目，不要为凑数而提取
- 龙套角色也要提取（否则分镜无法绑定 `character_ids`），但外貌可精简到 100-150 字
- 场景按「地点 + 时间段」成对提取；同地点不同时段算两个场景
