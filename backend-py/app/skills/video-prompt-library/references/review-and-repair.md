# 成片审片与返修闭环

> 用途：视频生成出来之后，把"感觉假/不对/不好看"翻译成**有时间点、有证据、有改法**的导演意见，再把返修写回提示词重新生成。
> 来源：2026-11-04 消化原料库《导演审片返修库》（原吸收 AI-Director-Video-Review v1.3 方法论）。
> 铁律：不靠"感觉"打分。每个问题都要 **时间范围 + 可见证据 + 严重度 + 可执行改法**；风格化/有意变化先按创作意图解释，不轻易判错。
> 与本仓既有分层的区别：`video-deconstruct-analyzer` 的八维是**拆解别人片子**，`short-drama-screenwriter` 的 P0–P3 是**剧本合规**；本份是**审自己的成片**，轴不同。

## 一、先定模式

| 模式 | 用在哪 | 额外检查 |
|---|---|---|
| single | 一条视频独立质检 | 五维全查 |
| variants | 同一镜头多个候选版比选 | 逐条查完再横向排名，比"谁完成了叙事任务"，不比谁更炫 |
| sequence | 一部连续作品多镜头 | 加查跨镜连续性（屏幕方向/视线/方位/光线） |

## 二、五维质检

1. **人物一致性**：脸型五官比例、发型发色、服装配饰、体型年龄、皮肤特征跨时间是否一致。遮挡/表情/透视/光照造成的合理变化**不判错**。重点：身份漂移、无因换装、局部器官重构、角色互换。
2. **动作连续性**：手脚位置、持物关系、动作起止、重心、碰撞、速度惯性。重点：物体凭空出现消失、肢体跳变穿模、不可能关节、交互断裂。剪辑点两侧结合切镜判断，不要求像长镜头逐帧衔接。
3. **场景一致性**：空间布局、建筑结构、道具数量位置、光源方向、天气时段。反打/视差/景深可改变表象。重点：固定结构漂移、关键道具消失、方位矛盾、无叙事依据的光线突变。
4. **摄影语言**：景别/构图/机位/运镜/焦点/曝光/色彩/节奏是否服务叙事。**不瞎编焦距数值** —— 没元数据就写"广角透视倾向""背景压缩感"，不写"24mm/85mm"。重点：主体不清、视线轴线乱、运镜无动机、焦点漂移、节奏与情绪冲突。
5. **AI 痕迹**：手指五官畸变、文字乱码、反射阴影矛盾、纹理爬行、边缘闪烁、物体融化、重复图案、背景人物变形。单帧错记时间点；闪烁漂移记起止范围；低码率/运动模糊也能造成时，降置信度并注明替代解释。

## 三、严重度四级

- `critical`：主体身份/叙事/可用性损坏，必须返修。单个 critical 可一票否决，哪怕总分高。
- `major`：明显出戏或影响理解，建议返修。
- `minor`：可察觉但不碍核心表达，按发布标准定。
- `note`：优化建议或值得保留的优点，不算缺陷。

## 四、发布结论五种

`ready` 可直接发 / `post_fix` 简单剪辑遮盖后可发 / `regenerate_segment` 需局部重生成或换镜 / `reject` 核心系统性失效、整体重做更划算 / `insufficient_evidence` 素材不可读、暂不下判断。

## 五、评分分三个独立结果（不拿一个总分掩盖）

- **技术质量**（100）：五维各 20 分，从 20 扣 —— critical 扣 12–20、major 扣 5–11、minor 扣 1–4。
- **目标适配 goal_fit**（0–100）：是否达成既定目标与内容类型；没明确目标则为 null，**不拿通用审美当目标**。
- **证据置信度**：high / medium / low，反映素材可读性与上下文充分度。
- 风格/导演诊断**不混入**技术扣分；只有明确破坏叙事时才影响 goal_fit。面部不可见/音频不可用/参考缺失的子项标"未充分检查"，不默认满分。

## 六、返修：从便宜到贵

1. **剪辑规避**：问题在非必要头尾、重复动作、可删停顿。
2. **后期修复**：文字/Logo/局部遮盖/声音/简单调色/稳定。
3. **局部重生成**：短时间的脸、手脚、物体交互、纹理爬行、单一动作坏。
4. **整镜替换**：主体身份/产品结构/空间在大部分时长持续失效。

只有跨全片系统性失效才建议整段重做，否则优先最小范围返修。

## 七、返修包必含六项

1. 目标片段 + 建议保留的前后边界
2. 要锁定的角色/服装/道具/场景/镜头特征
3. 正向约束：明确期望的可观察结果
4. 负向约束：**只针对已观察到的问题**，不堆通用负面词
5. 方法建议：剪辑 / 后期 / 局部重绘 / 首尾帧约束 / 整段生成
6. 验收点：返修后重新确认的 2–4 个可见条件

返修提示词模板：

```
保留：{稳定参考帧中的角色、服装、场景、构图与光线}
动作：{动作起点、接触、运动路径、终点}
约束：{针对问题的稳定结构与连续关系}
避免：{本次实际发生的换脸/粘连/乱码/融化}
首尾：从 {起始状态} 自然过渡到 {结束状态}
```

## 八、防误判

- 区分"观察"与"推断"：素材确认不了的标待确认，不编镜头参数/比例/时间点。
- 区分"视觉效果"与"拍摄参数"：没元数据就描述倾向，不反推焦距光圈。
- 连续性至少比两个时间点；单帧缺陷可依单帧报。
- 风格化发光/变形/拖影/转场/变装**先按创作意图解释**，只有破坏可读性/时序/主体结构才判缺陷。风格本身不是缺陷。
- 不把"85mm 必有情绪""浅景深必有电影感"当定律。
- 无法直接读视频时，不声称已审片；要视频/关键帧/带时间码截图。

## 九、多版本比选

统一按"是否完成同一叙事任务"打分排名，并给最佳版的返修提示词。顺序：先逐条查完，再横向比，禁止先排名后找理由。
