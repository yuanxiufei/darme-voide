# 表演导演层：把情绪翻成可拍的身体指令

> 用途：写视频提示词或分镜首帧时，人物"表情假/僵硬/像摆拍/情绪浮夸"的根因是——只给了情绪词，没给身体。
> 来源：2026-11-04 消化原料库《表演微表情库》《情绪表达提示词库》《台词口播去AI味库》三份，只留可执行判据，不保留课程体例、外部工具名与飞书凭据。
> 铁律：**别写"他很伤心"，写"谁、为什么、用什么方式伤心"** —— 情绪词不是指令，身体反应才是。

## 一、情绪五维公式（缺一即摆拍）

```
情绪 = 表情细节 + 手部动作 + 身体姿态 + 视线方向 + 说话语气
```

五维同时给，AI 的情绪才立体。反例："他很伤心地走开。"正例："他垂着眼，嘴角绷着不说话，手攥着衣角，慢慢往后退半步，声音压得很低：'……我走了。'"

## 二、先给情绪一个发生原因

演员先想"我为什么会这个反应"，不是先想"我做什么表情"。提示词要交代 **触发事件 + 此刻动机/关系**。同样一句"走开"，撒娇/嫌弃/愤怒/害怕/崩溃是完全不同的演法。

## 三、微表情粒度（别用大词）

| 部位 | 指令写法 |
|---|---|
| 眉 | 眉峰轻抬 / 眉心微蹙 / 眉心舒展 |
| 眼 | 眼神聚焦某点 / 眼睑微垂 / 瞳孔先定后移；**眼球动必带眼睑微动**，否则是死鱼眼 |
| 嘴 | 真笑＝嘴角上扬＋上唇提升＋下眼睑上提；假笑只动嘴角；抿嘴＝压抑 |
| 呼吸 | 咽了一下 / 肩膀松下来 / 深吸一口气 |
| 身体 | 紧张攥衣角 / 害羞捂嘴 / 压抑时喉结滚动 / 释然肩膀下沉 |

## 五、逐秒情绪序列（情绪转折必用）

情绪不是一帧到位，是变化的。按秒拆：

```
0-1s 残留痛苦 → 1-2s 眼神放空 → 2-3s 表情收起 → 3-4s 身体停住
```

按秒写状态变化，AI 不会情绪跳帧。一个"大哭到底"是偷懒写法。

## 六、定妆照的"人生状态"

角色不是纸片人。定妆提示词可加状态痕迹：刚经历失败 → 疲惫眼袋、略暗沉、轻微面部不对称；长期焦虑 → 眼下青、嘴角垮。痕迹让人物像活过，不是模特。

注意：状态变体板才写痕迹，**基础定妆板保持中性**，否则跨集漂移。

## 七、台词去 AI 腔

保真第一：**只改"怎么说"，不改"说什么"**，不丢情节、不改关系、不弱化关键台词。

| 症状 | 修法 |
|---|---|
| 每句都完整工整、像念稿 | 拆半句、加打断、答非所问 |
| 结尾必升华/金句 | 删掉金句，用动作或沉默收 |
| 角色说话一个味 | 按人设拉开句长、用词、口头禅 |
| 大词堆砌（赋能/极致/焕新） | 换具体动作和具体场景 |
| 信息靠角色嘴念出来 | 改成冲突中带出、分批揭 |
| 口播太顺太押韵 | 拆短、加碎词、去排比 |

对白四要：**潜台词**（说的≠想的）、**不完整**（打断/半句/停顿）、**声音可辨**（换个名字不能谁都说得出来）、**忌金句收尾**。

口播：每句 4–12 字（长句必然拉低口型准确率）、允许"就是/其实/你懂吧"这类碎词、写"语速偏慢、自然停顿"、说场景不说形容词（"每次挤地铁妆就花了"胜过"持妆效果极佳"）。

古装/正剧保留该有的文气，去 AI 腔 ≠ 口语化到底。

## 八、自检

- 是不是只写了情绪词，没写身体？（五维补齐）
- 眼神有没有落点？眼球动有没有带眼睑微动？
- 转折戏是不是一帧到底？有没有按秒拆？
- 台词有没有为"像人"而加无意义碎碎念？（那是另一个极端）
- 台词有没有顺带改了情节或关系？（保真第一）

## 九、中文对白时长预算（排镜与判超时用）

自然剧情语速按 **2.5–3.2 个有效汉字/秒**估，再叠加标点停顿、思考、呼吸与表演余波：

| 可用说话时间 | 自然剧情对白建议 |
|---|---|
| 5 秒 | 10–14 字 |
| 8 秒 | 18–24 字 |
| 10 秒 | 24–30 字 |
| 15 秒 | 36–42 字 |
| 30 秒 | 72–84 字 |

- 可用时间要**先扣**开场动作、必要停顿、听者反应、收尾动作，剩下的才是说话时间。
- 超了就在标点/换气点/语义转折处分段，**不许提语速、不许删停顿、不许机械按字数截断**。
- 小天才例外：`combat-choreography` §七 里写的「4–5 字/秒」是打戏短促喝令的口径，叙事对白别套用；两者不矛盾，别拿它给长篇对白开绿灯。
