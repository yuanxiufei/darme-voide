# 真人质感与去 AI 味判据（手机实拍 / 口播 / 现代真人镜头）

> 适用：现代题材真人短剧、口播、竖屏种草、生活流镜头。
> **古装 / 仙侠 / 电影感镜头不套本份** —— 那类要的是电影光与骨相（见 `shot-directing.md`
> 的景别与光位判据），手机脏污、果冻效应会把「大片感」直接打掉。
> 判断分界一句话：**观众该觉得「随手拍的」还是「剧组拍的」**。前者用本份，后者不用。

## 一、AI 味有两个来源，要分开治

| 症状 | 叫法 | 根因 |
|---|---|---|
| 塑料皮肤、多指、眼神飘、口型漂、画面冒乱码字 | **一眼 AI** | 模型默认美颜审美 + 欠指定 |
| 三点布光、干净台面、完美居中、过度精致 | **一眼广告** | 影棚默认值 + 构图洁癖 |

两者修法相反：前者要**减**（去掉光滑、去掉完美），后者要**加**（加光位冲突、加使用痕迹、加偏心）。
只做一半必然翻车 —— 皮肤写实了但仍是影棚光，观众只会觉得「假得更清楚」。

## 二、四项必带（缺任一项就退回 AI 味）

### 1. 光：写色温 + 方向 + 质感，禁用通用灯效

- ❌ `三点布光` `柔光箱` `均匀打亮` `专业灯光` —— 这几个词本身就是 AI 味制造机。
- 优先级：**窗边自然光（纪实感最强）＞ 画面内可见的实光源（台灯 / 手机屏 / 屏幕反光）＞ 蓝调时刻·阴天漫射 ＞ 三点布光（最后选）**。
- 成品句：`光从左侧窗户进来冷白日光，右侧一盏暖黄顶灯，色温自然冲突，脸上明暗不均，不打补光`。
- 硬判据：**画面里要么有光源本体，要么能说清方向**；两者都没有，就是「均匀打亮」。

### 2. 场景：写「用过的痕迹」，不写「摆好的道具」

| 假（摆拍感） | 真（生活感） |
|---|---|
| 整齐叠放的毛巾、未拆封包装盒、空咖啡杯、摆正的手机、空白墙面 | 揉皱随手放的纸巾、拆一半胶带翘起的快递袋、喝一半杯壁有水痕的咖啡、屏幕朝下扣着还缠着充电线、贴着便利贴且有电线的墙 |

- 写法：**逐件列出**，例 `半喝剩带杯渍的咖啡、拆开一半的快递袋、揉皱的纸巾、缠在一起的充电线`。
- `干净背景` 在真人镜头里等于死刑，与「古装留白」是两套审美，别混用。

### 3. 皮肤：主动要瑕疵，正负两句都要

- 正向：`皮肤有自然纹理、可见毛孔、脸颊鼻翼轻微泛红、眼下淡青、几颗小痣，不要过度磨皮，不要塑料陶瓷感`。
- 质感正向（必须同时给，否则模型用「另一种光滑」填回来）：`纪实写实风格，不要 AI 绘画质感，不要 3D 渲染感，不要插画感`。

### 4. 镜头：把「手机拍的」写进开头四要素

`手机手持拍摄，带自然轻微晃动感，轻微动态模糊，构图略偏不居中，业余家庭录像质感，竖屏 9:16`

可叠加（择一至二，不要全上）：`轻微镜头脏污` `自动曝光轻微调整` `轻微果冻效应`。

原理：**完美无瑕本身就是 AI 特征**。一点镜头脏、轻微光晕、呼吸感，比任何「更真实」的形容词都有效。

## 三、症状 → 修复对照（补丁句可直接粘）

| 症状 | 补丁句 / 修法 |
|---|---|
| 塑料、过度磨皮 | `皮肤有自然纹理、可见毛孔和细微瑕疵，不是光滑塑料感，不要过度磨皮` |
| AI 绘画玻璃感 | `纪实写实风格贯穿全片，不要 AI 绘画质感，不要 3D 渲染感，不要插画感` |
| 崩手、多指、手粘连 | `手部解剖自然，五指完整、比例正确，手部动作简单（握、放、推近），不做翻转/精细操作` |
| 眼神飘、抖 | `眼神稳定聚焦，无闪烁无抖动` |
| 中文口型漂移 | `口型严格对台词，不说话时嘴闭合静止，对准每个中文音节` |
| 跨段背景漂移 | `与上一段是同一个房间同一处场景` |
| 画面冒乱码字 / logo | 负向轰炸（见下），镜头描述处与结尾各写一次 |
| 拼接处画面跳 | 加「同一段落同一房间」＋ 转场从 0.4 秒加到 **0.6–0.8 秒** |
| 真需要屏幕文字 | **别指望模型写**：外部做好截图当首帧喂入，或后期叠加 |

## 四、负向轰炸：分族写，且每条配一句正向替代

- **去广告感**：影棚布光、柔光箱、三点布光、过度磨皮、完美无瑕、对称居中构图、干净背景、极简布景、3D 渲染、过度饱和、AI 绘画感、塑料皮肤。
- **去文字 / logo**：不要文字、不要汉字、不要英文字、不要数字、不要 logo、不要 UI 元素、不要可识别符号。

两条纪律：

1. **集中列 6 条以上**，并在**镜头描述处与结尾各写一遍** —— 只写一遍时模型会在后半句把它忘掉。
2. **每个重要的「不要」都要配一句「要什么」**，否则模型用变体填回来。例：
   `不要浮字卡片` → 补 `柔和发光的半透明矩形、紫粉蓝渐变、无可识别图案`。

## 五、三段锁定：治跨镜头崩脸

把角色 / 场景 / 声音提到**镜头脚本之前**成独立区块 —— 模型把置顶区块当全局恒真事实，比埋在镜头里有效得多。

```
【角色锁定】姓名：年龄/体型/发型/眼镜/服装/配饰，所有镜头同一套造型；皮肤有毛孔自然纹理，不要塑料感。
【场景锁定】环境+光源方向+色温+关键道具+空间布局，所有镜头同一场景。
【声音锁定】语言/口音/年龄段/音色；口型同步，不说话时嘴静止。
```

系列内容把这三块存成**可复用头部**，下一条视频直接复用 → 人设自动延续，不必每集重写。

## 六、口播 / 带货结构（15–25 秒四段式）

| 段落 | 时长 | 写法 |
|---|---|---|
| 钩子 | 前 2 秒 | 具体数字 / 反常识 / 直接喊人群 / 从动作中段切入 |
| 痛点 | 3–8 秒 | 说场景不说形容词：`每次挤地铁妆就花` 胜过 `持妆不好` |
| 展示 | 8–18 秒 | 手真实拿起产品，可见效果变化 |
| 行动 | 最后 3 秒 | 一句话说清怎么买 |

- 口播句 **4–12 字**，长句必然拉低口型准确率。
- 允许口语碎词（`就是` `其实` `你懂吧`）；**不要排比押韵** —— 那是广告腔。
- 语速偏慢。字数预算按 2.5–3.2 字/秒算（见 `performance-directing.md` §九）。
- 运镜要给量：写**时长**（3 秒慢推近）、**幅度**（轻微 1.05 倍变焦）、**时机**（第 1 秒开始推），别只写「推近」。

## 七、预期对齐：别承诺做不到的事

| 项 | 现实区间 |
|---|---|
| 中文口型同步 | 70–85% |
| 跨镜头角色一致 | 80–90% |
| 多剪辑段整体精度 | 65–80% |

这三条要在**接活与验收时**就说明，不要等出片后拿 100% 当标准去返修 —— 那是拿工具的物理上限当人的失误。

## 八、与电影感那份的分工

| | 本份（真人实拍感） | `shot-directing.md`（电影感） |
|---|---|---|
| 光 | 混合光、色温冲突、不打补光 | 有设计的光位、明暗对比 |
| 场景 | 用过的痕迹、杂物 | 留白、构图经营 |
| 镜头 | 手持、脏污、果冻效应 | 稳定器、轨道、升降 |
| 画幅参数 | 写对角视场角 | 写对角视场角（**都不写 50-85mm 焦段**） |

真人短剧可**两份叠用**：电影感镜头取那份，UGC / 带货段取本份。叠用时别把两套光的话都写进去 —— 会互相抵消，等于没写。
