## 二、进阶复合运镜 7 种

推摇结合 / 拉摇结合 / 跟推结合 / 升降+摇移 / 推轨跟拍 / 变焦推轨 / 环绕推进。

复合 = 两种基础叠加，写法照旧按五要素：**景别 · 视角+角度值 · 运镜 · 跟随目标 · 起止时间**。示例：`中近景 · 微仰 15° · 越肩跟拍 · 跟随女主 · 0–3s`。

**环绕限速**：360° 环绕易眩晕、丢方向感，常规叙事 ≤180°；角色展示/反派登场等高燃段可破例，但必须写明**旋转速度与圈数**，且单镜 ≤5s。

## 三、景别与嵌套公式

景别分级见 `film-shot/references/shot-language.md` §1 与 `../SKILL.md` §6.11（那里管"景别→情绪距离"）。此处补的是**嵌套公式**——一个镜头里同时出现两个景别时怎么排：

```
[主体景别] + [环境景别] + [过渡关系]
例：前景人物近景 + 背景环境全景 + 焦点由背景拉回人物
```

三种常用嵌套：
- **大框套小框**：全景里框住一个人，人再被门框/窗框二次框住（空间纵深 + 压迫）
- **景别递进**：同一动作按 远→全→中→近→特 五级切，用于情绪升级（不是平均分配时长，越往后越短）
- **景别反差**：极远景切极特写，制造惊愕（一集用一两次足够）

## 四、转场四法（AI 视频好实现）

| 转场 | 怎么做 | 提示词写法 |
|---|---|---|
| 遮挡 | 门/墙/路人/树从镜头前划过，全黑瞬间切 | "前景一人从左向右完全掠过画面遮住镜头，画面全黑瞬间切到下一场景" |
| 甩镜 | 快速横摇，运动模糊最糊那一帧切 | "镜头快速向右甩动产生运动模糊，模糊中切到下一镜，方向一致" |
| 动作匹配 | 两个时空用同一动作接：抬到最高点切 | "角色抬手推窗，手臂抬到最高点切；新场景同方向继续抬手接住落下的纸" |
| 相似构图 | 下一镜主体在相似位置/形状，观众当作连续 | "新镜头主体仍在画面中心同一位置，承接上一镜构图" |

补充：空镜匹配、推近/拉远揭示、闪白、焦点虚化、声画延续（下一场声音早半秒起，切点藏在声音里）。

**别用的情况**：同场景对话与动作连续戏硬切最干净；转场不能抢戏（观众注意到"这转场好炫"就过了）；一条短片两三种足够。

## 五、三锁（防跨镜漂移）

把三件事提到镜头脚本**之前**成独立区块，模型把置顶区块当全局恒真事实：

```
【人物锁】年龄/体型/发型/服装/配饰/皮肤质感；所有镜头同一套造型
【场景锁】环境+光源方向+色温+关键道具+空间布局；所有镜头同一场景
【尾帧锁】本镜结束状态 = 下一镜起始状态；写出尾帧可见的姿势/持物/朝向
```

系列内容把这三块存成可复用头部，第二条直接复用同一锁定块，人设自动延续。**人物长相靠参考图锁，表演靠提示词写，别用提示词重描长相**（重描会打架）。

尾帧锁与分镜自检同源：`start_state` 必须等于上镜 `end_state`，且首尾帧要有可见差异（否则等于没动）。

## 六、静图微动三态（成品图要"动起来"时）

先定态，再写动作。**动效必须从图片本身长出来**：

1. 主体固有的动作（风吹头发、旗动、水流、火焰、眨眼、呼吸起伏）
2. 这个动作带来的物理反应（头发动带起草屑、水花反溅）
3. 前两者都不合适，才用环境/观察层效果

**禁止默认动作**：扫描光、漂浮呼吸纸、视差、粒子、镜头推近、通用电影感运镜。别让标本/石头/档案/安静物件硬演活物。**一个有效答案可能是"这张图不该动"。**

| 态 | 含义 | 什么时候选 |
|---|---|---|
| motion | 一个明确的克制动作 | 主体本身有运动合法性（人物、水、火、风、旗、车流） |
| micro-motion | 几乎不动，只一点环境痕迹 | 版式/海报/档案，只需呼吸感（树叶轻晃、尘粒飘、光缓移） |
| static | 干脆不动 | 静物标本、档案、已凝固的瞬间；说明为什么静止更对 |

**动作配额**：最多 1 个主动作 + 1 个物理伴随动作 + 1 个可选观察层效果。不准一次塞三个运动。

必须锁死（防漂移）：文字、数字、标签、手写注释、纸张质感、边框、画框、网格、拼贴几何；主体数量/身份/剪影/服装/比例；绳、把手、关节、柄、四肢的连续性。海报/拼贴/档案类**默认不要镜头运动**。不要重复描述原图已有的风格，多余风格词会诱导重绘。

一组图时：先总结共同视觉系统 → 列可共用约束 → 每张单独定态 → 每张单独写。主体行为不同时，不准说"一条通用提示词全包"。

## 七、自检

- 运镜写了时长、幅度、时机吗？还是只写"推近"？
- 复合运镜有没有超过两种叠加？
- 环绕写明速度与圈数了吗？
- 转场是藏在动作里，还是后期硬加？
- 三锁有没有提到置顶端？尾帧锁写了可见状态吗？
- 静图微动是不是一个主动作？脆弱元素都锁了吗？"不动"是否被考虑过？
