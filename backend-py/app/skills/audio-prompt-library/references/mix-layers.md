# 声音三层与混音让位

> 用途：写 `bgm_prompt` / `sound_effect` / 配音时，把"声音空、BGM 不搭、人声和音乐打架、没氛围"按层拆开。
> 来源：2026-11-04 消化原料库《声音配乐库》，只留可执行口径。
> 铁律：声音分三层 —— **人声配音 / 环境音效 / 背景音乐**，各管各的，别糊成一团。
> 与本仓既有分层的关系：`audio-prompt-library/SKILL.md` 的 `sound_effect` 取材顺序管**单个音效怎么写**；本份管**三层怎么配平**。

## 一、三层结构

| 层 | 管什么 | 要点 |
|---|---|---|
| 人声/配音 | 台词、旁白 | 情绪与停顿按表演导演层；别平读 |
| 环境音效 | 场景真实感 | 每个场景配独立环境音：雨声 / 街市电流声 / 低频嗡鸣，让画面"有空气" |
| BGM | 情绪线 | 不铺满，按情绪分段；有人声时必须让位 |

## 二、BGM 怎么写

提示词结构：**风格 + 情绪 + 速度（BPM）**。例：`环境电子乐，慢板，柔和铺底 pad，神秘安宁，BPM 65`。

| 段落类型 | BPM |
|---|---|
| 慢抒情 | 60–70 |
| 日常叙事 | 80–95 |
| 紧张动作 | 100+ |

- 别一首铺到底：按段落换，转场处交叉淡化。
- **分镜阶段就把音乐关键词提出来**，别等画面做完才找乐。

## 三、让位（关键）

- 人声/对白一出，BGM 自动压低 **6–12 dB**（ducking），让人声清楚。
- 环境音垫底，音量最小，别抢戏。
- 转场/情绪切换点：BGM 可骤停（激烈→寂静，只留一个尾音）制造冲击。

## 四、衔接

- 声画延续：下一场的环境音/BGM 早半秒起，切点就藏在声音里。
- 场景之间用一小段短音乐过渡，保全片情绪连贯。
- 多人配音：同一角色全程同一音色/同一设定，别一段一个声。

## 五、症状→修法

| 症状 | 修法 |
|---|---|
| 干巴巴没氛围 | 先加环境音效，不是先加 BGM |
| 人声听不清 | BGM 没压低，做 ducking 6–12 dB |
| BGM 土/不搭 | 按"风格+情绪+BPM"重新生成，别硬套曲库 |

## 六、自检

- 三层是不是分开写的？还是只写了一条 BGM？
- 环境音是否逐场景配了？
- 有人声的段落，BGM 让位写了吗？
- BPM 与段落情绪对得上吗？
