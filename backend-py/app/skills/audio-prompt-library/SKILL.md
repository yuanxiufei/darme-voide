# 音频字段写法（sound_effect / bgm_prompt）

> **分工**：这两个字段的**定义、取值与「静场」这类硬要求由系统提示词给出，本文件不重复**；
> 这里只写落到具体镜头时**怎么判断、怎么选词**。
> 视频提示词里那句「声音：不要配乐，仅保留同期声」是**提示词正文**的写法（见 `video-prompt-library` 6.6），
> 本文件管的是**分镜字段**，两者不是一回事，别混着改。

## 一、先分清两个字段（最容易写反的地方）

| 字段 | 它是什么 | 谁消费 | 因此不能写什么 |
|---|---|---|---|
| `sound_effect` | 画面内**要真的听见**的声音（同期声 / 动作声 / 环境声） | **会进视频生成提示词**：入队时被追加为 `[background_audio] …`，成片同步合成音轨 | ❌ 不写配乐 / 曲风 / 乐器（会被烧进画面音轨，与「后期统一配乐」直接冲突）❌ 不写台词与解说（归 `dialogue`） |
| `bgm_prompt` | 该镜的**配乐方向**，给后期选曲用 | **不进任何生成链路**，只入库供后期 / 剪辑读 | ❌ 不写具体曲名、歌手、在世作曲家 ❌ 不写时长（时长由 `duration` 决定） |

一句话记法：**`sound_effect` 是「要让模型真的发出这个声音」，`bgm_prompt` 是「给后期找曲的便条」。**

## 二、`sound_effect` 细化公式

**公式：材质 + 动作 + 力度 + 空间 + 尾音** —— 五要素不必写全，但至少要落到**材质**或**空间**之一。

| 写不出来（❌） | 细化后（✅） | 缺的是什么 |
|---|---|---|
| 有脚步声 | 皮鞋踩在积水石板上，由远及近 | 材质 + 空间 |
| 很安静 | 静场，只有远处电梯运行的嗡鸣 | 无声源时必须显式写「静场」，再补一点底噪 |
| 很恐怖 | 低频轰鸣垫底，夹杂不规则呼吸声与远处脚步 | 换成**听得见的具体声音** |

**取材顺序**（同一镜 2–4 个就够，多了会互相掩蔽）：

1. **主体动作声**：脚步、衣料摩擦、门轴响、拔剑出鞘、纸张翻动、手机震动、杯子磕上桌面
2. **环境底噪**：雨打窗、风穿巷、远处车流、蝉鸣、电流嗡鸣、人群嘈杂 —— **只在该镜真需要氛围时写**
3. **主观情绪音**：心跳、耳鸣、呼吸、金属共振 —— 只在**角色主观镜头**里用

**无声源就写「静场」**：这不是省略，而是明确告诉模型「这条镜头不要生成环境音」，比留空可控。

## 三、`bgm_prompt` 细化公式

**公式：情绪基调 + 节奏 + 主要乐器/音色 + 空间感 + 忌用**

```
隐忍压抑 / 缓慢无鼓点 / 单音符钢琴 + 低频弦乐铺垫 / 干声少混响 / 不要打击乐
```

- **粒度**：写到「后期拿着这句话能找到同类型曲子」为止，不停在「很好听 / 很燃」
- **一镜一句**，不要写段落；同一场戏的连续镜头保持**同一体系 + 变化量**
  （如「同上，进一层弦乐」），否则后期会在一条场次里拼出互不相干的曲子
- **不写时长、曲名、歌手、在世作曲家**（版权风险，同 `video-prompt-library` 7.1 / 7.3）

**情绪档位速查**（想不清就先落档，再补乐器与节奏）：

| 情绪 | 基调与节奏 | 常用音色 |
|---|---|---|
| 压抑 / 悬疑 | 缓慢、无鼓点、留白多 | 低频嗡鸣、单音符钢琴、大提琴长音 |
| 紧张 / 追逐 | 中快速、脉冲式 | 心跳式低鼓、弦乐震音、金属敲击 |
| 悲伤 / 告别 | 慢速、自由速度 | 钢琴独奏、二胡 / 小提琴长弓、气声哼鸣 |
| 温情 / 日常 | 中速、轻律动 | 木吉他分解、口琴、马林巴、轻弦乐拨奏 |
| 热血 / 对抗 | 快速、强拍清晰 | 电子鼓、铜管齐奏、失真吉他 |
| 荒诞 / 黑色幽默 | 中速、节奏错位 | 拨弦贝斯、木琴、不谐和和弦 |
| 恐怖 / 惊悚 | 极慢或失序 | 高频啸叫、低频震动、无调性弦乐、器乐噪音 |
| 史诗 / 觉醒 | 由缓到强、层层叠加 | 大编制弦乐、人声合唱、定音鼓 |

## 四、题材声音体系（挑一套用，不要跨题材混搭）

| 题材 | 环境底噪 | 特征音效 | 配乐方向 |
|---|---|---|---|
| 都市 / 短剧日常 | 车流、空调外机、隔壁电视声 | 手机提示音、咖啡机、电梯到达 | 极简钢琴 / 轻电子，音量压低（对白优先） |
| 悬疑 / 罪案 | 雨声、远处警笛、老楼管道声 | 打火机、玻璃杯落桌、档案袋翻页 | 低频垫底 + 点状单音，克制不加旋律 |
| 恐怖 / 克苏鲁 | 电流嗡鸣、风穿过缝隙 | 不规则呼吸、地板吱呀、湿润粘腻声 | 无调性弦乐 + 低频震动，禁旋律 |
| 古风 / 武侠 | 竹叶沙沙、檐角风铃、市井人声 | 拔剑、衣袂翻飞、灯笼晃动 | 笛箫 / 古琴 + 鼓点，对抗戏加快节奏 |
| 赛博朋克 / 科幻 | 城市低频轰鸣、全息广告杂音 | 机械关节、液压、电弧、数据提示音 | 合成器 pad + 工业节奏，冷色调 |
| 末世 / 废土 | 风沙、空旷回声、金属热胀冷缩 | 收音机杂讯、铁门锈轴、脚步踩碎石 | 单音吉他 + 噪点环境音，极简留白 |
| 战争 / 动作 | 远处爆炸余响、风穿过残骸 | 枪栓、弹壳落地、无线电电流声 | 低鼓 + 弦乐持续音，不用完整旋律 |

## 五、硬性禁止项

1. **`sound_effect` 里不写配乐 / BGM** —— 它会被注入视频提示词并合成成画面音轨
2. **不写真人姓名 / 在世作曲家 / 具体曲名**（同 `video-prompt-library` 7.1 合规红线）
3. **不把台词与解说写进音频字段** —— 台词归 `dialogue`
4. **不堆无关音效** —— 一镜超过 4 个音效会互相掩蔽，听感糊成一团
5. **不留空** —— 无声源写「静场」；`bgm_prompt` 真没方向也要给基调（如「无配乐，仅环境声」）

## 六、自检清单

- [ ] `sound_effect` 里每个音是否**听得见**（而不是「氛围很压抑」这类形容词）？
- [ ] 无声源的镜头是否显式写了「静场」？
- [ ] `sound_effect` 里是否**没有**配乐 / 曲风 / 乐器（那是 `bgm_prompt` 的事）？
- [ ] `bgm_prompt` 是否到了「基调 + 节奏 + 乐器」粒度，而不是只有「紧张」？
- [ ] 同一场戏连续镜头的配乐方向是否连贯（同一体系 + 变化量）？
- [ ] 是否避开了曲名 / 歌手 / 在世作曲家？
