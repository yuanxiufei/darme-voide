# 音色分配指南

> **分工**：一角色一音色、跨集锁定、`speaker_id` 全局唯一等**硬规则**由系统提示词给出，
> **本文件不重复**，只写需要判断力的匹配原则。

## 匹配优先级

按 性别 → 年龄 → 性格 → 角色定位 逐层收窄：

1. **性别**：男性角色用男声，女性角色用女声（反串 / 中性设定按角色描述处理）
2. **年龄**：少年 / 青年 / 中年 / 老年各对应不同音色区间
3. **性格**（在候选里做取舍）：
   - 活泼开朗 → 明亮有活力
   - 沉稳内敛 → 低沉稳重
   - 温柔体贴 → 柔和甜美
   - 威严霸气 → 浑厚有力
   - 阴郁偏执 → 沙哑低沉
4. **角色定位**：主角用辨识度高的音色；配角（尤其龙套）用中性音色，避免抢戏

## 音色角色类型标签（role_tag）

- 每个音色带 `role_tags`（旁白 / 主角 / 反派 / 配角），由 AI 打标并持久化到音色库（无标签时前端回退正则推断）
- `list_voices` 支持传 `role_tag` 按类型筛选，例如给反派找音色时传 `role_tag: '反派'`
- 匹配时优先看 `role_tags`，再用性别 / 性格做最终取舍

## 判断提示

- 同一场景内多个角色的音色**要能听出区别**（过于接近会让观众分不清谁在说话）
- 旁白音色单独选定，且不要与任一主要角色相同
- 拿不准时选更中性的音色 —— 辨识度留给重要的主角
